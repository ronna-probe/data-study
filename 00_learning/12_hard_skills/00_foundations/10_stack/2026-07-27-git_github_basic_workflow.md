# [모두의 깃&깃허브 - 길벗](https://product.kyobobook.co.kr/detail/S000061450151)

## 초기수준

- 깃허브 웹사이트 및 데스크톱 앱을 통해 커밋을 할 줄 아는 수준이었다.
- 협업 과정에서 Git이 어떻게 활용되는지 이해하기 위해 이 책을 읽게 되었다.

---

## 목차

- 깃&깃허브 준비 운동
- 깃&깃허브 익히기
- 명령어로 깃 다루기

---

## 요약

- Commit을 통해 작업 내용을 시점별로 기록하고 이전 상태로 되돌릴 수 있다.
- Branch를 활용하면 하나의 프로젝트 안에서 여러 작업 흐름을 분리하여 관리할 수 있다.
- Pull Request를 통해 코드 변경 사항을 공유하고 검토하며 협업할 수 있다.

---

## 서평

- 초급자를 대상으로 GUI 환경에서 실습하는 구성 덕분에, 버전 관리의 원리와 협업 방식을 이해하는 데 집중할 수 있었다.
- 명령어를 활용하는 단계는 난도가 높다고 느꼈으며, Git을 익히기 위해서는 반복적인 실습이 필요하다고 생각했다.

---

## 활용

- Git을 활용한 프로젝트 관리와 협업 환경에 적응하기 위한 기초를 마련하였다.
