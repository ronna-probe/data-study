# [쏙쏙 들어오는 자료구조](https://product.kyobobook.co.kr/detail/S000217555322)

```text
인용:

이처럼 방대한 정보를 제대로 이해하고 그에 압도당하지 않기 위해서는
정보를 효과적으로 구성하는 방법이 필요하다.
```

## 초기 수준

- 큐, 힙 같은 자료구조를 알고는 있었지만 코드로 다뤄본 경험은 없었다.

## 목차

- 자료구조와 알고리즘 효율성
- 기본 자료구조: 배열, 연결 리스트
- 선형 자료구조: 스택, 큐, 힙
- 비선형 자료구조: 트리, 해시 테이블, 그래프

## 요약

- 자료구조는 단순히 저장 방식이 아니라, 현실의 관계와 구조를 표현하는 모델이다.
- 같은 데이터라도 어떤 구조를 적용하느냐에 따라 데이터 처리 과정과 성능이 달라진다.

## 서평

- 추상 자료형과 자료구조 비교를 통해, 기능과 구현을 분리해서 바라보는 방식을 살펴볼 수 있었다.
- 사용자에게는 필요한 기능만 제공하고 내부 구현을 숨기는 인터페이스의 역할을 알게 되었다.
- 객체지향 프로그래밍 관점에서 객체를 중심으로 프로그램 구조를 구성하는 관점을 익힐 수 있었다.

## 활용

- 문제 해결 과정에서, 문제의 특성에 맞는 자료구조를 먼저 고민해볼 수 있을 것 같다.
