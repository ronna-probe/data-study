## 문제

숫자가 영어로 표현되어 이어진 문자열 `numbers`가 주어진다.  
`numbers`에는 `"zero"`부터 `"nine"`까지의 숫자를 표현한 영어가 공백 없이 이어져 있다.

문자열을 숫자로 변환하여 정수로 반환한다.

---

## 예시

```python
numbers = "sixseven"
```

문자열을 숫자 단위로 나누면

```text
six   → 6
seven → 7
```

따라서 최종 결과는

```python
67
```

이다.

---

## 접근

문자열에는 숫자 사이에 구분자가 없기 때문에 각 숫자가 어디서 끝나는지 확인해야 한다.

따라서 문자를 하나씩 읽으면서 버퍼에 저장한다.  
버퍼에 저장된 문자열이 영어 숫자 단어가 되면 해당 단어를 숫자로 변환한다.

예를 들어 `"one"`을 읽는다면:

```text
o → "o"
n → "on"
e → "one" → 숫자 단어 완성
```

`"one"`이 완성되는 순간 `1`로 변환하고 버퍼를 비운다.

---

## 코드

```python
def convert_number_words(numbers):
    number_map = {
        'zero': '0',
        'one': '1',
        'two': '2',
        'three': '3',
        'four': '4',
        'five': '5',
        'six': '6',
        'seven': '7',
        'eight': '8',
        'nine': '9'
    }

    word_buffer = []
    digit_buffer = []

    for ch in numbers:
        word_buffer.append(ch)
        word = ''.join(word_buffer)

        if word in number_map:
            digit_buffer.append(number_map[word])
            word_buffer.clear()

    return int(''.join(digit_buffer))
```

## 정리

다른 사람의 풀이에 이런 코드가 있었다.

```python
def convert_number_words(numbers):
    for digit, word in enumerate([
        "zero", "one", "two", "three", "four",
        "five", "six", "seven", "eight", "nine"
    ]):
        numbers = numbers.replace(word, str(digit))

    return int(numbers)
```

문자열을 하나씩 읽으며 숫자 단어의 경계를 파악하는 코드를 구현하는 대신,  
`replace()`를 사용하면 단어를 찾고 변경하는 과정을 함수에 맡길 수 있다.

`zero`부터 `nine`까지 순서대로 나열하면 리스트의 인덱스가 숫자와 일치한다.  
따라서 `enumerate()`를 사용하면 별도의 매핑 없이 숫자와 영어를 함께 사용할 수 있다.
