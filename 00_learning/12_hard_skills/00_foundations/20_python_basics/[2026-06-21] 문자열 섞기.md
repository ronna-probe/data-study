## 문제

길이가 같은 두 문자열 `str1`, `str2`가 주어진다.  

두 문자열의 각 문자를 앞에서부터 번갈아가며  
한 번씩 등장하는 문자열을 만들어 반환하는 문제이다.

---

## 예시

| str1   | str2   | result   |
|--------|--------|----------|
| aaa    | bbb    | ababab   |

---

## 접근

```python
str1 = "aaa"
str2 = "bbb"
```

이 문제는 **인덱스 단위**로 보면 구조가 단순하다.

해야 하는 작업은 다음과 같다:

- 같은 위치의 문자끼리 묶는다.
- 순서를 유지하며 번갈아 배치한다.
- 결과 문자열을 만들어낸다.

이 과정을 table 관점으로 보면 다음과 같다:

- zip은 같은 인덱스의 문자들을 튜플로 묶는다.
- 각 튜플의 값을 순차적으로 풀어 하나의 문자열로 합친다.

---

## 코드

### Stateful

리스트에 누적하며 상태를 유지한다.

```python
def interleave_strings(str1, str2):
    merged_chars = []

    for ch1, ch2 in zip(str1, str2):
        merged_chars.append(ch1)
        merged_chars.append(ch2)

    return ''.join(merged_chars)
```

### Stateless

쌍을 즉시 변환해 상태 없이 처리한다.

```python
def interleave_strings(str1, str2):

    return ''.join(f"{ch1}{ch2}" for ch1, ch2 in zip(str1, str2))
```

---

## 정리

- 핵심은 두 문자열을 같은 인덱스로 묶어 순서대로 펼치는 것이다.
- 구조적으로는 2차원 데이터를 flatten 하는 과정이다.
