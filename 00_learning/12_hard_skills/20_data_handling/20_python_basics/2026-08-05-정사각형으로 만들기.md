# [정사각형으로 만들기](https://school.programmers.co.kr/learn/courses/30/lessons/181830)

## 문제

2차원 정수 배열 `arr`이 주어진다.  
`arr`의 행과 열의 개수를 비교하여 정사각형 형태로 만든다.

- 행의 수가 더 많다면 각 행의 끝에 `0`을 추가한다.
- 열의 수가 더 많다면 부족한 행을 `0`으로 채워 추가한다.
- 행과 열의 수가 같다면 그대로 반환한다.

---

## 예시

```python
arr = [
    [1, 2, 3],
    [4, 5, 6],
]
```

행은 2개, 열은 3개이므로 행을 1개 추가하면

```python
[
    [1, 2, 3],
    [4, 5, 6],
    [0, 0, 0],
]
```

이 된다.

---

## 접근

먼저 행과 열의 개수를 구한 뒤 두 값을 비교한다.  
이후 부족한 방향에만 `0`을 추가한다.

---

## 코드

```python
def make_square(arr):
    square = [row.copy() for row in arr]
    row_count = len(square)
    col_count = len(square[0])

    if row_count > col_count:
        for row in square:
            row.extend([0] * (row_count - col_count))

    elif row_count < col_count:
        for _ in range(col_count - row_count):
            square.append([0] * col_count)

    return square
```

---

## 정리

```python
square = arr.copy()
```

`arr.copy()`는 내부 리스트까지 복사하지 않는 얕은 복사이므로,  
`square`의 행을 수정하면 원본 `arr`에도 영향을 줄 수 있다.

따라서 원본을 보존하려면 다음과 같이 각 행까지 복사하는 것이 권장된다.

```python
square = [row.copy() for row in arr]
```

이렇게 하면 바깥 리스트뿐만 아니라 각 행도 별도의 리스트로 복사된다.

## 참고

다른 사람의 풀이를 살펴보니, 부족한 부분에 `0`을 추가하는 대신  
정사각형 크기의 `0` 배열을 초기화한 뒤 기존 배열의 값을 복사하는 방법도 있었다.

```python
def solution(arr):
    row_count = len(arr)
    col_count = len(arr[0])
    size = max(row_count, col_count)

    square = [[0] * size for _ in range(size)]

    for i in range(row_count):
        for j in range(col_count):
            square[i][j] = arr[i][j]

    return square
```

현재 상태를 기준으로 필요한 작업을 찾을 수도 있고,  
목표 상태를 기준으로 필요한 구조를 설계할 수도 있다.
