# [진료 순서 정하기](https://school.programmers.co.kr/learn/courses/30/lessons/120835)

## 문제

응급도를 나타내는 정수 배열 `emergencies`가 주어진다.  
배열에는 환자가 접수된 순서대로 각 환자의 응급도가 저장되어 있다.

응급도가 높은 환자부터 진료 우선순위를 매긴 뒤,  
접수된 순서대로 각 환자의 진료 우선순위를 반환한다.

---

## 예시

```python
emergencies = [6, 8, 7, 9]
```

응급도를 내림차순으로 정렬하면

```python
[9, 8, 7, 6]
```

응급도와 진료 우선순위를 대응시키면 다음과 같다.

```text
6 → 4위
8 → 2위
7 → 3위
9 → 1위
```

우선순위를 접수 순서에 맞게 나열하면

```python
[4, 2, 3, 1]
```

이 된다.

---

## 접근

진료 우선순위는 응급도를 기준으로 결정되지만,  
반환해야 하는 결과는 환자가 접수된 순서를 따라야 한다.

따라서 각 응급도에 대응하는 진료 우선순위를 구한 뒤,  
접수 순서에 맞게 결과를 구성한다.

---

## 코드

### 이중 반복문

```python
def assign_treatment_priority(emergencies):
    sorted_emergencies = sorted(emergencies, reverse=True)
    treatment_priority = []

    for emergency in emergencies:
        for index in range(len(sorted_emergencies)):
            if emergency == sorted_emergencies[index]:
                treatment_priority.append(index + 1)
                break

    return treatment_priority
```

### 딕셔너리

```python
def assign_treatment_priority(emergencies):
    sorted_emergencies = sorted(emergencies, reverse=True)

    emergency_to_rank = {
        emergency: rank
        for rank, emergency in enumerate(sorted_emergencies, start=1)
    }

    treatment_priority = [
        emergency_to_rank[emergency]
        for emergency in emergencies
    ]
    
    return treatment_priority
```

---

## 정리

| 풀이 | 시간 복잡도 | 공간 복잡도 |
|------|------------|------------|
| 이중 반복문 | O(n²) | O(n) |
| 딕셔너리 | O(n log n) | O(n) |

이중 반복문 방식은 각 환자의 순위를 찾기 위해 배열을 반복 탐색하므로  
`O(n²)`의 시간 복잡도가 발생한다.

반면 딕셔너리 방식은 응급도와 우선순위를 미리 매핑하여  
순위 탐색 과정을 제거하고, 정렬 이후 선형 과정만 수행하므로  
전체 시간 복잡도는 `O(n log n)`이다.

단, 딕셔너리 방식은 응급도를 키로 사용하므로  
같은 응급도가 여러 번 등장하면 하나의 키로 처리되어 순위 값이 덮어써지고,  
응급도가 같은 환자를 개별적으로 관리할 수 없다.  
이를 해결하려면 응급도와 환자의 접수 순서(인덱스)를 함께 사용하여 각 환자를 구분해야 한다.

```python
# 응급도 정렬 후에도 접수 순서를 확인할 수 있도록 (인덱스, 응급도) 형태로 변환
sorted_patients = sorted(
    enumerate(emergencies),
    key=lambda patient_info: patient_info[1],
    reverse=True
)

# 접수 순서와 진료 우선순위 매핑
rank_by_index = {
    index: rank
    for rank, (index, _) in enumerate(sorted_patients, start=1)
}
```

## 참고

### enumerate(iterable, start=1)

`enumerate()`는 순회 대상의 인덱스와 값을 함께 반환한다.

인덱스는 기본적으로 0부터 시작하며,  
`start=1` 매개변수를 사용하여 인덱스의 시작 값을 1로 지정할 수 있다.

```python
for idx, val in enumerate(lst, start=1):
```
