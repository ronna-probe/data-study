# [문자열 밀기](https://school.programmers.co.kr/learn/courses/30/lessons/120921)

## 문제

알파벳 소문자로 이루어진 문자열 `A`, `B`가 매개변수로 주어진다.  
문자열 `A`를 오른쪽으로 한 칸씩 밀면 마지막 문자가 맨 앞으로 이동한다.

예를 들어

```text
xyza
 ↓
axyz
```

이 된다.

문자열 `A`를 오른쪽으로 밀어서 `B`를 만들 수 있다면,  
`B`가 되기 위한 최소 이동 횟수를 반환한다.

만들 수 없다면 `-1`을 반환한다.

---

## 예시

```python
A = "oooi"
B = "oioo"
```

`A`를 두 번 밀면

```text
oooi
 ↓
iooo
 ↓
oioo
```

이므로 최소 이동 횟수는

```python
2
```

이다.

반대로

```python
A = "ooi"
B = "iio"
```

이때, `A`를 아무리 밀어도 `B`가 될 수 없으므로 -1을 반환한다.

---

## 접근

문자열은 직접 수정할 수 없으므로, 한 칸씩 이동시키는 과정을 구현하기 위해 리스트로 변환한다.  
오른쪽으로 한 칸씩 직접 밀어보면서 `B`와 같은지 확인한다.

문자열의 길이가 `n`이라면, `n`번 밀었을 때 다시 원래 문자열로 돌아온다.  
따라서 최대 `n`번까지만 확인하면 된다.

---

## 코드

```python
def find_min_shift(A, B):
    shift_count = 0
    current = list(A)
    target = list(B)

    for _ in range(len(A)):
        if current == target:
            return shift_count

        current = [current[-1]] + current[:-1]
        shift_count += 1

    return -1
```

---

## 정리

```python
current[-1] + current[:-1]
```

처음에는 위와 같이 구현하려고 했다.

이때 `current[-1]`은 원소 하나를 반환하고, `current[:-1]`은 리스트를 반환한다.  
따라서 원소의 타입이 리스트가 아니라면, `+` 연산을 시도하면 타입 에러가 발생한다.

한편 `current`의 각 원소가 리스트라면 타입 에러는 발생하지 않겠지만,  
의도한 결과와 다른 값이 나오는 **조용한 오류**일 가능성이 있다.

```python
[current[-1]] + current[:-1]
```

마지막 원소를 리스트로 감싸주면, 의도한 대로 마지막 원소와 나머지 리스트를 연결할 수 있다.

## 참고

다른 사람의 풀이를 살펴보다가, 멋진 알고리즘을 발견하였다.

```python
shift_count = lambda A, B: (B*2).find(A)
```

Python의 `find()`는 문자열에서 특정 문자열이 처음 등장하는 위치를 반환한다.  
find()가 찾지 못하면 자동으로 -1을 반환한다.

관점을 바꾸어, 코드를 직관적으로 개선할 수 있다.

```python
def find_min_shift(A, B):
    return (A + A).find(B)
```

`A + A` 안에는 A를 오른쪽으로 한 칸씩 밀었을 때 만들어지는 문자열들이 부분 문자열로 나타난다.  
따라서 B가 처음 등장하는 위치가 곧 최소 이동 횟수가 된다.
