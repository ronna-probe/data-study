# [프로젝트 성패를 결정짓는 데이터 모델링 이야기](https://product.kyobobook.co.kr/detail/S000001057639)

---

```text
인용:

OLTP와 OLAP는 근본적으로 목적이 다르므로,
각각을 위한 데이터 모델링 역시 다르게 접근해야 한다.

이 책은 비즈니스 트랜잭션 처리를 위해
정규화 이론에 기반한 RDB 모델의 관점을 다룬다.
```

---

## 초기 수준

- 데이터 분석 과정이 모델의 영향을 받을 수 있다는 점은 크게 의식하지 못했다.

---

## 목차

- 데이터 모델링의 본질과 사고방식
- 엔터티, 관계, 식별자를 통한 업무 구조화
- 정규화와 데이터 구조 설계
- 확장성과 표준화를 고려한 모델링
- 관계형 데이터베이스와 데이터 모델링의 역할

---

## 요약

- 데이터 모델링은 업무를 데이터 구조로 추상화하는 과정이다.
- 좋은 모델은, 변하는 요구사항보다 변하지 않는 업무의 본질을 담는다.
- 이러한 모델은 성능과 확장성은 물론, SQL 작성 방식에도 영향을 미친다.

---

## 서평

- 내가 봐왔던 어떤 것들은, **누군가가 보여준 것**일 수 있겠다는 생각이 들었다.

--- 

## 활용

- 특정 OLTP 데이터 모델을 통해, 어떤 분석이 가능하고 어떤 분석은 어려운지까지 함께 생각해보고자 한다.
