# [특별한 이차원 배열1](https://school.programmers.co.kr/learn/courses/30/lessons/181833)

## 문제
정수 `n`이 주어질 때,  
n × n 크기의 2차원 배열 arr를 반환한다.

조건은 다음과 같다:

- arr[i][j] = 1 if i == j
- arr[i][j] = 0 otherwise

즉, 단위행렬을 만든다.

---

## 예시

| n | result |
|---|--------|
| 3 | [[**1**,0,0], [0,**1**,0], [0,0,**1**]] |

---

## 접근

핵심은 “모든 칸을 채울 것인가 vs 필요한 칸만 채울 것인가”의 선택이다.

이 문제는 구조적으로 다음 두 가지 관점으로 볼 수 있다:

### 1. 전체 순회 (Brute Force)
- 모든 (i, j) 쌍을 순회하며 조건 검사
- 연산량: O(n²)

### 2. 구조 파악
- 유효한 값(1)은 오직 i == j일 때만 존재
- 나머지는 전부 0으로 초기화하여 연산량 절감 가능

---

## 코드

### 조건 분기

```python
def create_identity_matrix(n):
    # 일반적으로 row(i) 기준으로 바깥 루프를 두고, col(j)를 내부에서 순회한다
    matrix = [[1 if i == j else 0 for j in range(n)] for i in range(n)]
             
    return matrix
```

### 초기화 + 필요한 위치만 변경

```python
def create_identity_matrix(n):
    # CPython 내부 C 레벨 최적화된 리스트 초기화
    # 불필요한 조건 판단 제거
    matrix = [[0] * n for _ in range(n)]

    # Python 레벨 분기 비용 감소
    for i in range(n):
        matrix[i][i] = 1  # diagonal
    
    return matrix
```

---

## 정리

이 문제의 핵심은 “값을 계산하는 것”이 아니라  
“필요한 위치만 선택하는 구조”로 보는 것이다.

- Brute Force 방식은 모든 (i, j)를 순회하며 Python 레벨에서 조건 분기를 수행한다
- 반면 초기화 + 대각선 할당 방식은
  C 기반의 연속 메모리 초기화를 활용하고,
  Python에서는 필요한 인덱스만 직접 접근한다

이 구조 변화로 인해 불필요한 반복 조건 분기와 비교 연산을 줄일 수 있다.

---

## 참고

Python의 많은 내장 연산과 자료구조 조작은 실제로 C로 최적화되어 있다.

- `list * n` 초기화, `sum()`, `len()`, `min()`, `max()` 같은 연산은
  내부적으로 C 레벨에서 동작한다
- 따라서 Python 레벨의 for-loop로 직접 반복하는 것보다
  내장 함수 호출 1회로 처리되는 방식이 더 효율적인 경우가 많다

즉, 성능 차이는 “Python 코드냐 C 코드냐”의 문제가 아니라  
**“인터프리터 레벨 반복을 줄이고, C 레벨 배치 연산을 어떻게 활용하느냐”의 차이**다

다만 Python으로 직접 구현하는 과정은 문제 구조를 이해하고 논리력을 기르는 데 매우 유효하다.  
따라서 직관적인 방식으로 설계를 완성한 뒤, 이후 반복 구조를 줄이거나  
C 레벨 최적화를 활용하는 방향으로 개선해 나가는 것이 좋다.
