# [세 개의 구분자](https://school.programmers.co.kr/learn/courses/30/lessons/181862)

## 문제

알파벳 소문자로 이루어진 문자열 `myStr`이 주어진다.

문자 'a', 'b', 'c'를 구분자로 사용하여 문자열을 나눈 뒤,  
나누어진 문자열들을 순서대로 저장한 배열을 반환한다.

단,

- 두 구분자 사이에 문자가 없으면 저장하지 않는다.
- 결과가 비어 있으면 `["EMPTY"]`를 반환한다.

---

## 예시

myStr = "one**a**two**b**three**c**four"

이를 구분자 'a', 'b', 'c'를 기준으로 나누면

```python
["one", "two", "three", "four"]
```

가 된다.

---

## 접근

문자열을 한 번 순회하면서 현재까지의 문자를 임시로 누적하고,  
구분자를 만나면 지금까지의 구간을 확정하는 방식으로 해결할 수 있다.  

이때 중요한 것은 "현재 상태를 유지하는 변수(buffer)"와  
"완성된 구간을 저장하는 구조"이다.  

---

## 코드

```python
def split_by_abc(myStr):
    SEPARATORS = ('a', 'b', 'c')
    buffer = []
    chunks = []

    for ch in myStr:
        if ch in SEPARATORS:
            chunks.append(buffer[:])
            buffer.clear()
        else:
            buffer.append(ch)

    chunks.append(buffer)

    split_texts = ["".join(chunk) for chunk in chunks if chunk]

    return split_texts or ["EMPTY"]
```

---

## 정리

이 문제의 본질은 문자열 분리 자체가 아니라  
"상태 기반 스트림 처리(stateful iteration)"이다.  

문자를 즉시 처리하지 않고, 상태(buffer)를 유지하면서  
특정 조건(구분자)을 만날 때만 결과를 확정하는 구조이다.  

---

## 참고

### buffer[:] 를 사용하는 이유

리스트는 가변 객체(mutable)이므로 그대로 추가하면 같은 객체를 참조하게 된다.

```python
buffer = ['o', 'n', 'e']

chunks = []
chunks.append(buffer)  # chunks = ['o', 'n', 'e']

buffer.clear()  # chunks = [[]]
```

이 경우 chunks는 buffer와 동일한 객체를 참조하게 되므로,  
buffer가 변경되면 chunks의 내용도 함께 변경된다.

따라서 현재 상태를 안전하게 저장하려면 복사본을 추가해야 한다.

```python
chunks.append(buffer[:])
```
