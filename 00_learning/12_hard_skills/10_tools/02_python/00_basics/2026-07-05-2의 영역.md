# [2의 영역](https://school.programmers.co.kr/learn/courses/30/lessons/181894)

## 문제

자연수 배열 `arr`가 주어진다.  
배열 안의 2가 모두 포함된 가장 작은 연속 부분 배열을 반환하는 문제이다.

단,

- 배열에 2가 없는 경우 [-1]을 반환한다.
- 2가 하나만 있는 경우 해당 원소만 포함한 배열을 반환한다.

---

## 예시

| arr | result |
|------|--------|
| [1, **2**, 3, **2**, 1] | [**2**, 3, **2**] |
| [5, 4, 3] | [-1] |
| [1, **2**, 3] | [**2**] |
| [50, **2**, 60, **2**, 70, 80, **2**, 90] | [**2**, 60, **2**, 70, 80, **2**] |

---

## 접근

- 첫 번째와 마지막 2의 위치로 구간이 결정된다.
- 구간 내부 값은 결과에 영향을 주지 않는다.

---

## 코드

```python
def slice_by_value(arr):
    NOT_FOUND = -1
    start = end = NOT_FOUND

    for idx, num in enumerate(arr):
        if num == 2:
            if start == NOT_FOUND:
                start = end = idx
            else:
                end = idx

    if start == NOT_FOUND:
        return [-1]

    return arr[start:end + 1]
```

---

## 정리

슬라이싱은 끝 인덱스가 배열 길이를 넘어도 에러가 발생하지 않고, 가능한 범위까지만 잘라낸다.

```python
arr[start:end + 1]
```

배열의 마지막 요소가 2인 경우 end는 마지막 인덱스이며,  
이 경우에도 슬라이싱은 마지막 원소까지만 포함하는 방식으로 정상 동작한다.
