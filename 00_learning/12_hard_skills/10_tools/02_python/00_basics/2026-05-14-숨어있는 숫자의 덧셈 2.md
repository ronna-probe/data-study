# [숨어있는 숫자의 덧셈 2](https://school.programmers.co.kr/learn/courses/30/lessons/120864)

## 문제
문자열 `my_string` 이 매개변수로 주어진다.  

문자열은 소문자, 대문자, 자연수로만 구성되어 있으며,  
문자열 안에 포함된 자연수들의 합을 반환한다.  
연속된 숫자는 하나의 숫자로 간주한다.

---

## 예시

| my_string         | result |
|------------------|--------|
| "**1**X**2**Y  | 3     |
| "a**1**B**2**cd**34**E**5**"  | 42     |

---

## 접근
- 문자열을 한 번은 순회해야하므로 최소 시간복잡도는 O(n)이다.
- 연속된 숫자를 고려하여, 숫자를 만나면 버퍼에 저장한다.
- 문자를 만나면 버퍼에 저장된 (연속된) 수를 누적 합산하는 신호로 해석한다.

---

## 코드

### list 버퍼
```python
def sum_numbers_in_string(my_string):
    total = 0
    buf_list = []
    
    for ch in my_string:
        if ch.isdigit():
            buf_list.append(ch)
        else:
            if buf_list:
                total += int(''.join(buf_list))
                buf_list = []

    # 마지막 문자가 숫자로 끝나는 경우를 고려하여, 반복문 종료 후 한 번 더 처리한다.
    if buf_list:
        total += int(''.join(buf_list))
        
    return total
```

### num 버퍼
```python
def sum_numbers_in_string(my_string):
    total = 0
    num_buf = 0
    
    for ch in my_string:
        if ch.isdigit():
            num_buf = num_buf * 10 + int(ch)
        else:
            total += num_buf
            num_buf = 0
    
    total += num_buf
    return total
```

---

## 정리
- 두 방식 모두 문자열을 한 번만 순회(1-pass)하므로 시간 복잡도는 O(n)이다.
- list 버퍼 방식은 문자열을 직접 이어붙이는 구조라 직관적이다.
- num 버퍼 방식은:
  - 문자열 join 과정이 필요 없고
  - 추가 리스트 메모리 사용이 없으며
  - 숫자를 즉시 계산할 수 있어 더 효율적이다.
- 따라서 num 버퍼 방식이 더 깔끔하고 성능상 유리하다.
