# [중복된 문자 제거](https://school.programmers.co.kr/learn/courses/30/lessons/120888)

## 문제

문자열 `my_string`이 주어진다.  
중복된 문자를 제거하고 하나의 문자만 남긴 문자열을 반환하는 문제이다.

- 대문자 / 소문자 / 공백 모두 구분
- 같은 문자가 여러 번 등장하면 가장 먼저 등장한 것만 유지

---

## 예시

| my_string | result |
|----------|--------|
| "an**a**lysi**s**" | "anlysi" |
| "Just Do I**t**" | "Just DoI" |

---

## 접근

이 문제의 핵심은 다음 한 줄로 정리된다:

- “처음 등장한 문자만 남기고 이후 중복은 제거”

즉, 필요한 것은:

- 문자 중복 여부
- 등장 순서 유지

---

## 코드

### 1. set 기반 방문 체크 (직관적 풀이)

- 이미 등장한 문자는 set으로 관리
- 처음 등장한 문자만 결과에 추가

```python
def deduplicate_keep_order(my_string):
    seen = set()
    output = []

    for ch in my_string:
        if ch not in seen:
            seen.add(ch)
            output.append(ch)

    return ''.join(output)
```

### 2. dict.fromkeys 활용 (가장 파이썬다운 풀이)

- dict.fromkeys(): 주어진 iterable(리스트, 문자열 등)을 key로 해서 딕셔너리를 만드는 함수
- Python 3.7+에서 dict는 insertion order 유지
- 키 중복이 자동 제거됨

```python
def deduplicate_keep_order(my_string):
    return ''.join(dict.fromkeys(my_string))
```

## 정리

- 제거가 아니라 **추가하지 않는 방식**으로 사고를 전환한다.
