하지만 문법은 익혀갔음에도  
개별 문법이 사용되는 맥락을 이해하기 어려웠다.

이 공간은 SQL 문법 이해 뿐만 아니라  
데이터베이스와 SQL을 관통하는 원리 및  
사고방식을 이해하기 위한 학습 기록을 정리한다.
