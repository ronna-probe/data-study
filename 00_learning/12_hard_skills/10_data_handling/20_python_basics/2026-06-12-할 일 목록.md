# [할 일 목록](https://school.programmers.co.kr/learn/courses/30/lessons/181885)

## 문제

오늘 해야 할 일이 담긴 문자열 배열 `todo_list`와  
각각의 일을 지금 마쳤는지를 나타내는 boolean 배열 `finished`가 매개변수로 주어진다.

todo_list에서 아직 마치지 못한 일들을 순서대로 담은 문자열 배열을 반환하는 함수를 작성한다.

---

## 예시

|  |  |
|--|--|
| todo_list | ["swim", "study", "guitar"] |
| finished  | [**False**, True, **False**] |
| result    | ["swim", "guitar"] |

---

## 접근

이 문제는 boolean 배열을 기준으로 원본 배열을 필터링하는 마스킹(masking) 문제이다.

핵심은 두 배열의 같은 인덱스가 서로 대응된다는 점이다.  
예를 들어 `todo_list[i]`의 완료 여부는 `finished[i]`에 저장되어 있다.  

따라서 두 배열을 함께 순회하면서 완료되지 않은 항목만 선택하면 된다.

---

## 코드

```python
def get_pending_tasks(todo_list, finished):
    pending_tasks = [todo for todo, done in zip(todo_list, finished) if not done]

    return pending_tasks
```

---

## 정리

이 문제는 두 배열의 같은 인덱스끼리 서로 연결되어 있다는 구조를 파악하는 것이 핵심이다.

- `zip()`으로 두 배열을 함께 순회
- `finished`가 `False`인 항목만 선택
- 리스트 컴프리헨션으로 간결하게 구현

따라서 한 번의 순회만으로 효율적으로 해결할 수 있다.

---

## 복잡도

모든 작업의 완료 여부를 확인해야 하므로 시간 복잡도는 `O(n)`이다.  

추가 공간은 완료되지 않은 작업을 저장하는 결과 리스트뿐이므로 공간 복잡도는 `O(k)`이다.  
(k = 완료되지 않은 작업 수)
