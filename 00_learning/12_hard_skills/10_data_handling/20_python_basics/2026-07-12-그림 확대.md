# [그림 확대](https://school.programmers.co.kr/learn/courses/30/lessons/181836)

## 문제

직사각형 형태의 그림 파일을 나타낸 문자열 배열 `picture`, 자연수 `k`가 주어진다.  
이 그림 파일은 1 × 1 정사각형 크기의 픽셀로 이루어져 있다.

이때, `picture`를 가로 세로로 `k`배 확대한 그림 파일을 반환한다.

---

## 예시

```python
picture = [
    "x.x",
    ".x.",
    "x.x"
]

k = 3
```

이를 3배 확대한 그림은 아래와 같다.

```text
xxx...xxx
xxx...xxx
xxx...xxx
...xxx...
...xxx...
...xxx...
xxx...xxx
xxx...xxx
xxx...xxx
```

---

## 접근

그림을 확대하는 과정을 가로 확대와 세로 확대로 **나누어 생각**한다.

- 먼저 한 행의 각 문자를 `k`번 반복하여 가로를 늘린다.
- 이후 완성된 행을 `k`번 반복하여 세로를 늘린다.

---

## 코드

```python
def enlarge_picture(picture, k):
    enlarged_picture = []

    for row in picture:
        enlarged_row = ''.join(pixel * k for pixel in row)

        for _ in range(k):
            enlarged_picture.append(enlarged_row)

    return enlarged_picture
```

---

## 정리

- 가로를 먼저 완성한 뒤 같은 문자열을 재사용하면 구현이 간단하다.
- 문자열의 곱셈을 이용하면 각 픽셀을 쉽게 가로로 확대할 수 있다.
