# [문자열 여러 번 뒤집기](https://school.programmers.co.kr/learn/courses/30/lessons/181913)

---

## 문제

문자열 `my_string`과 구간 정보가 담긴 `queries`가 주어진다.

각 query는 [s, e] 형태이며,

- 인덱스 s부터 e까지의 부분 문자열을 뒤집는다.
- 모든 query를 순서대로 적용한 최종 문자열을 반환한다.

---

## 예시

```python
my_string = "poyhtn"

queries = [
    [1, 2],
    [2, 4]
]
```

첫 번째 query: [1, 2]

```text
poyhtn
 ↓↓
pyohtn
```

두 번째 query: [2, 4]

```text
pyohtn
  ↓↓↓
python
```

---

## 접근

문자열은 immutable(불변 객체)이므로 특정 구간만 직접 수정할 수 없다.

따라서 먼저 문자열을 가변 객체인 리스트로 변환한 뒤,  
각 query 구간마다 뒤집는 과정을 반복한다.

모든 query를 처리한 뒤 문자열로 합쳐 반환한다.

---

## 코드

```python
def reverse_substrings(my_string, queries):
    characters = list(my_string)

    for query in queries:
        start, end = query[0], query[1]
        characters[start:end + 1] = characters[start:end + 1][::-1]

    return ''.join(characters)
```

---

## 정리

리스트의 슬라이싱은 선택한 구간을 새로운 시퀀스로 치환할 수 있다.

```python
lst[i:j] = replacement
```

이때 대입되는 시퀀스의 길이에 따라 리스트의 크기도 함께 변경될 수 있다.  
즉 교체, 삽입, 삭제 모두 가능하다.

따라서 리스트의 특정 범위를 수정하는 상황에서는 개별 원소 단위로 처리하는 것보다  
슬라이싱 대입을 활용하는 편이 더 간결할 수 있다.

---

## 참고

처음에는 음수 step을 이용해 아래와 같이 시도하였다.

```python
characters[start:end + 1] = characters[start:end + 1:-1]
```

하지만 step이 음수인 슬라이싱으로 구현하려면, 논리적으로 시작 인덱스가 종료 인덱스보다 커야 한다.  
`start < end` 인 상태에서 `step = -1`을 사용하면 유효한 슬라이스가 생성되지 않으므로 빈 리스트를 반환한다.

한편, 아래와 같은 형태로 구현하는 것도 가능하다.

```python
characters[start:end + 1] = characters[end:start - 1:-1]
```

다만 가독성 측면에서는 본문과 같은 구현이 더 직관적이다.

```python
characters[start:end + 1] = characters[start:end + 1][::-1]
```
