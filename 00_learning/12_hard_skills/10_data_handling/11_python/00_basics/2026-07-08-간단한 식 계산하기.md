# [간단한 식 계산하기](https://school.programmers.co.kr/learn/courses/30/lessons/181865)

## 문제

문자열 `binomial`이 주어진다.

```text
binomial은 "a operator b" 형태의 이항식이다.

- operator는 +, -, * 중 하나
- a, b는 음이 아닌 정수
```

주어진 이항식을 계산한 결과를 반환한다.

---

## 예시

| binomial | a | operator | b | 결과 |
|---|---|---|---|---|
| "12 + 3" | 12 | + | 3 | 15 |

---

## 접근

split()을 사용해 식을 구성 요소로 분리하여 처리한다.  

eval()을 사용하면 문자열 식을 바로 계산할 수 있지만,  
이는 예상하지 못한 코드 실행 위험이 있어 사용을 지양한다.

---

## 코드

```python
def calculate_binomial(binomial):
    a, operator, b = binomial.split()
    a, b = int(a), int(b)

    results = {
        '+': a + b,
        '-': a - b,
        '*': a * b,
    }

    return results[operator]
```

---

## 정리

이 문제는 문자열 파싱과 연산자 매핑 문제이다.

- `a`와 `b`는 숫자를 표현하는 문자열이므로, 숫자 타입으로 변환하여 연산에 사용할 수 있다.  
- `operator`는 연산 종류를 나타내는 문자열 값이며, 문자열 값인 "+"를 Python의 덧셈 연산자로 변환할 수 없다.

따라서 `operator`를 연산자로 변환하려 하지 않고,  
어떤 연산을 수행할지 결정하는 **조건 분기 신호**로 활용한다.

---

## 참고

### 1. 결과 매핑

결과 매핑은 연산 결과를 저장하는 방식이다.

```python
results = {
    '+': a + b,
}

result = results[operator]
```

딕셔너리를 생성하는 순간 이미 계산이 완료되고,  
operator를 기준으로 저장된 결과값을 선택한다.

### 2. 함수 매핑

함수 매핑 방식은 연산 로직을 저장하는 방식이다.

```python
functions = {
    '+': lambda x, y: x + y,
}

result = functions[operator](a, b)
```

operator를 선택한 뒤 해당 함수를 실행하여 결과를 계산한다.  
함수 매핑은 같은 연산 로직을 여러 입력값에 반복 적용할 때 유용하다.
