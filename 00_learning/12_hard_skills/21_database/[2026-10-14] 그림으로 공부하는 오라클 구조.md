## 목차

- I/O와 디스크, 데이터 접근 구조
- 오라클의 프로세스와 메모리 구조
- SQL 분석과 실행 계획
- 동시성 제어와 트랜잭션
- 백업·복구와 데이터베이스 운영

---

## 요약

- SQL은 실행 계획과 데이터베이스 내부 구조를 통해 실제 작업으로 처리된다.
  - 사용자가 작성한 SQL을 데이터베이스가 분석하고 실행 계획을 결정한다.
  - 공유 풀은 SQL 처리에 필요한 정보를 공유해 반복적인 분석 비용을 줄이는 데 활용된다.
  - 쿼리 성능을 이해하기 위해 데이터 접근 방식과 실행 과정을 살펴볼 수 있다.

- 데이터베이스는 여러 작업을 동시에 처리하면서 데이터의 일관성과 안정성을 유지해야 한다.
  - Lock과 대기는 동시 작업이 서로에게 미치는 영향을 이해하는 데 중요한 개념이다.
  - REDO는 변경 사항을 재현할 수 있도록 기록하며, UNDO는 변경 전 상태를 제공해 롤백과 읽기 일관성 등을 지원한다.
  - 백업과 복구, 백그라운드 프로세스는 데이터베이스의 지속적인 운영과 장애 대응을 뒷받침한다.
