『모두의 깃&깃허브』를 통해 Git의 기본 개념과 버전 관리 및 협업 방식을 이해하고,  
GitHub 웹사이트와 데스크톱 앱을 활용해 커밋하는 방법을 익힌 상태였다.

이후 Git 명령어에 대한 이해를 높이기 위해 Coddy의 Git & Version Control 코스를 학습하였다.

---

## 학습 내용
- **버전 관리:** Repository, Staging Area, Commit 및 변경 이력 관리
- **브랜치 관리:** Branch 생성, Merge 및 충돌 해결
- **변경 사항 관리:** Reset, Revert 등을 활용한 변경 사항 복구
- **원격 저장소 관리:** Remote Repository, Clone, Push, Pull 및 GitHub CLI 활용

---

## 학습 결과
Coddy의 Git & Version Control 58개 레슨을 완료하고, GitHub CLI를 추가로 학습하였다.  
기존의 GUI 중심 작업 방식에서 벗어나 Git 명령어와 터미널을 통해 버전 관리 및 GitHub 기능을 다뤄보았다.
