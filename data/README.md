# 데이터 분석

데이터를 기반으로 문제를 정의하고 탐색하며, 분석 결과를 하나의 프로젝트로 완성하는 공간이다.  
비즈니스 문제를 데이터 관점에서 해석하고 해결하는 전 과정을 기록한다.

---

## 구성

- 01_Thinking: 문제 정의 및 분석 방향 설계
- 02_Analysis: 데이터 기반 탐색 및 분석 수행
- 99_Project: Thinking + Analysis를 통합한 최종 분석 결과

---

## 목적

문제를 정의하고 데이터를 탐색하여 하나의 흐름으로 완성된 분석 결과를 만들어내는 역량을 기르는 것을 목표로 한다.
