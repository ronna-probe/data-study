# Meta Portfolio v1

Date: 2026-06-02 ~ 2026-06-15

## Overview

v1은 포트폴리오를 이해하기 위한 초기 탐색 단계이다.

프로젝트는 데이터 분석 포트폴리오가 무엇인지 명확히 이해하지 못한 상태에서 시작되었다.

당시의 관심사는

> 현재 나는 포트폴리오에 대해 얼마나 알게 되었는가?

를 측정하는 것이었다.

따라서 프로젝트는 질문 로그를 데이터로 수집하고,
이를 기반으로 학습 상태를 정량적으로 추정하는 방향으로 설계하였다.

---

## Core Question

> 포트폴리오 이해도를 측정할 수 있는가?

---

## Analysis Target

프로젝트의 분석 대상은

> 사용자의 학습 상태

이다.

질문은 이해도의 신호(signal)로 해석되며,

프로젝트는 질문 데이터를 통해

``` text

현재 수준

↓

변화량

↓

학습 상태

```

를 추정하려고 한다.

---

## Main Concepts

### 1. QCI

질문의 복잡도 및 품질을 측정하기 위한 지표

### 2. PUL

포트폴리오 이해 수준을 추정하기 위한 지표

### 3. MMTL

학습 상태를 표현하기 위한 모델

---

## Assumptions

v1은 다음과 같은 가설을 탐색하고자 한다.

### H1

질문의 수준이 높아질수록 이해 수준도 높아질 것이다.

### H2

이해도는 누적적으로 증가할 것이다.

### H3

학습 상태는 정량적 지표를 통해 추정할 수 있을 것이다.
