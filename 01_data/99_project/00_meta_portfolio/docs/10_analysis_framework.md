# Analysis Framework

본 프로젝트는 질문과 의사결정 과정을 통해

개념 상태(Concept State)가 어떻게 변화하는지를 분석한다.

---

## Analysis Flow

```text
Question Event

↓

Concept State

↓

State Transition

↓

Concept Evolution
```

질문은 분석 대상이 아니라 이벤트(event)이며,

프로젝트는 개념 상태가 시간에 따라 어떻게 변화하는지를 관찰한다.

---

## Stage 1. Question Events

개념 상태 변화의 원인이 되는 질문 이벤트를 분석한다.

### Analysis

- 질문 발생 시점
- 질문 유형 변화
- 질문 클러스터 형성
- 상태 전이 유발 질문 탐색

### Research Question

> 어떤 질문이 개념 상태 변화를 유발하는가?

---

## Stage 2. Concept State Definition

각 시점에서 정의된 개념 상태를 기록한다.

### Analysis

- 현재 정의
- 핵심 관점
- 분석 대상
- 측정 대상
- 관측 단위

### Research Question

> 현재 무엇을 정의하고 있는가?

---

## Stage 3. State Transition

개념 상태가 어떻게 변화하는지를 분석한다.

```text
State A

↓

State B
```

### Analysis

- 정의 수정
- 정의 재구성
- 프레임 전환
- 전환 이벤트 추적

### Research Question

> 어떤 조건에서 정의가 변경되는가?

---

## Stage 4. Concept Evolution

상태 전이들이 모여 어떤 진화 과정을 만드는지 분석한다.

```text
State 1

↓

State 2

↓

State 3

↓

...
```

### Analysis

- 개념 진화 경로
- 주요 마일스톤
- 버전 전환(v1 → v2)
- 개념 변화 패턴

### Research Question

> 개념은 어떤 과정을 통해 재정의되는가?

---

## Output

본 프로젝트의 최종 결과물은

정량 지표 자체가 아니라,

개념 상태의 변화 과정을 설명하는 구조이다.

즉,

```text
질문 로그

↓

상태 기록

↓

상태 전이

↓

개념 진화 스토리
```

를 재구성하는 것을 목표로 한다.
