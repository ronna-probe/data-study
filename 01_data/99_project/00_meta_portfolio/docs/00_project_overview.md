# Project Overview

이 프로젝트는 질문 기반 사고 과정을 데이터로 구조화하고, 그 변화 상태를 지표로 측정하는 시스템이다.

---

## Problem

기존에는 질문과 사고 과정의 변화가 기록되지 않아,
성장이나 이해 수준을 객관적으로 판단하기 어려웠다.

---

## Objective

이 프로젝트의 목표는 다음과 같다.

- 질문 로그를 구조화하여 저장
- 사고 과정을 상태(State)로 모델링
- 상태 변화를 지표로 수치화
- 성장 과정을 시간 기반으로 추적 가능하게 만들기

---

## Key Idea

핵심 개념은 “질문 = 사고 상태의 입력”이라는 관점이다.

- 질문은 단순 기록이 아니라 사고의 상태를 반영한다
- 답변 과정은 상태 변화를 발생시킨다
- 이 변화는 데이터로 추적 가능하다

---

## Metrics

- QCI: 질문의 구조적 품질
- PUL: 사고 이해의 누적 상태
- MMTL: 상태 변화량

---

## Difference from Traditional Approach

기존 방식:
- 노트 정리 중심
- 주관적 성장 판단
- 비정형 기록

현재 방식:
- 로그 기반 구조화
- 상태 변화 추적
- 지표 기반 비교 가능

---

## Summary

이 프로젝트는 질문 기반 사고 과정을 로그화하고,
그 변화를 지표로 측정하여 “사고 상태를 관측 가능한 데이터로 만드는 시스템”이다.
