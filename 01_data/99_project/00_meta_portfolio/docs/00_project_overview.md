# Project Overview

Date: 2026-06-16

본 프로젝트는 질문과 의사결정 과정을 데이터로 기록하고,

그 과정에서 특정 개념이 어떻게 재정의되는지를 관찰하기 위한 실험이다.

---

## Problem

데이터 분석 포트폴리오가 무엇인지 이해하고자 하였지만,

대부분의 자료는 결과물 중심으로 설명되어 있었다.

하지만 실제로는 결과물보다

무엇을 분석 대상으로 보는지,

무엇을 측정해야 하는지,

어떤 관점으로 문제를 해석하는지가

지속적으로 변화하고 있었다.

따라서 본 프로젝트는 결과물이 아닌

개념이 형성되고 수정되는 과정 자체를 분석 대상으로 설정하였다.

---

## Objective

이 프로젝트의 목표는 다음과 같다.

- 질문 로그를 구조화하여 기록
- 질문과 의사결정 과정을 이벤트로 저장
- 개념 상태(Concept State)를 정의
- 상태 전이(State Transition)를 추적
- 개념 변화 과정을 설명 가능한 형태로 모델링

---

## Key Idea

핵심 개념은

> 질문은 개념 상태를 변화시키는 이벤트이다.

라는 관점이다.

- 질문은 단순한 기록이 아니다
- 질문은 현재의 정의를 드러낸다
- 질문은 정의의 수정 또는 재구성을 유발한다
- 개념 변화 과정은 데이터로 추적 가능하다

---

## Analysis Target

본 프로젝트의 분석 대상은

> 포트폴리오의 개념 상태 (Concept State)

이다.

개별 질문이나 답변을 분석하는 것이 아니라,

각 시점에서 정의된 개념이

어떤 과정을 거쳐 변화하는지를 관찰한다.

---

## Difference from Traditional Portfolio

일반적인 데이터 분석 포트폴리오는

특정 문제를 해결한 결과를 보여준다.

본 프로젝트는

문제를 정의하는 방식 자체가

어떻게 변화하는지를 분석 대상으로 삼는다.

즉,

결과물이 아니라

정의의 변화 과정을 분석한다.

---

## Summary

본 프로젝트는 질문 로그를 기반으로

포트폴리오라는 개념이

어떻게 생성되고,

어떻게 수정되며,

어떻게 재구성되는지를 관찰하는

Meta Portfolio 프로젝트이다.
