# Hypothesis

본 문서는 현재 프로젝트에서 탐색하고자 하는 가설을 기록한다.

가설은 고정된 결론이 아니며,
질문 로그와 State Record가 축적됨에 따라 수정, 추가 또는 제거될 수 있다.

---

## H1

개념 변화는 정보의 누적보다 정의의 재구성을 통해 발생할 것이다.

### Background

새로운 정보를 획득하는 것만으로는
개념 상태가 크게 변화하지 않을 수 있다.

오히려

- 분석 대상 재정의
- 관측 단위 변경
- 측정 대상 변경
- 분석 프레임 전환

과 같은 정의 수준의 변화가
상태 전이를 유발할 것으로 예상한다.

### Observation

- State Record 발생 시점 분석
- 전환 직전 질문 패턴 분석
- Definition / Evolution 이벤트 비율 분석

---

## H2

주요 상태 전이는 단일 질문보다 연속적인 질문 묶음(question cluster)에 의해 발생할 것이다.

### Background

개념 변화는 하나의 질문으로 발생하기보다

```text
질문

↓

재질문

↓

재해석

↓

재정의
```

의 과정을 거쳐 발생할 가능성이 높다.

따라서 상태 전이는 특정 질문이 아니라
질문 클러스터의 결과일 것으로 예상한다.

### Observation

- State Record와 연결된 Question IDs 분석
- 전환 직전 질문 수 분석
- Question Cluster 길이 분포 분석

---

## H3

개념 변화는 선형적 축적보다 비선형적 전이 형태를 보일 것이다.

### Background

이해가 증가한다고 해서
개념 상태가 조금씩 변화하는 것은 아닐 수 있다.

오랜 기간 변화가 없다가

특정 질문 또는 관점 전환을 계기로

```text
State A

↓

State B
```

로 급격하게 이동할 가능성이 존재한다.

### Observation

- State Transition 빈도 분석
- 상태 유지 기간 분석
- 마일스톤 간 간격 분석

---

## H4

상위 수준의 질문일수록 개념 상태의 재정의를 유발할 가능성이 높을 것이다.

### Background

프로젝트 진행 과정에서 질문은

```text
포트폴리오란 무엇인가?

↓

무엇을 측정해야 하는가?

↓

무엇을 관측 단위로 볼 것인가?

↓

정의는 어떻게 만들어지는가?
```

와 같이 점차 상위 수준으로 이동하였다.

따라서 사실 확인이나 정보 탐색 질문보다

정의, 관점, 프레임을 다루는 질문이
상태 전이를 더 자주 유발할 것으로 예상한다.

### Observation

- 질문 유형 분류
- 질문 유형별 State Record 발생 빈도 비교
- 전환 이벤트 유발 질문 분석

---

## H5

개념 상태의 변화는 버전 단위의 마일스톤으로 구조화될 수 있을 것이다.

### Background

모든 질문이 동일한 수준의 변화를 만드는 것은 아니다.

일부 변화는 단순 수정에 그치지만,

일부 변화는 프로젝트 전체의 관점을 재구성한다.

따라서 상태 전이 중 일부는

```text
v1

↓

v2

↓

v3
```

와 같은 마일스톤으로 구분될 수 있을 것으로 예상한다.

### Observation

- Evolution Record 분석
- 버전 전환 이벤트 추적
- 주요 개념 변화 스토리 정리
