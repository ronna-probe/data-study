# portfolio_states

이 폴더는 '포트폴리오 정의 상태'의 시계열 기록이다.

---

## Naming

```text
yyyy-mm-dd_<label>.md
```

---

## Structure

- Current State: 현재 시점의 포트폴리오 인식
- State Transition: 이전 상태 대비 변화
- Open Questions: 아직 해결되지 않은 질문

---

## Note

인식은 고정된 값이 아니라 시간에 따라 변화하는 '상태'이다.  
따라서 그 변화 과정 또한 분석 가능한 데이터로 간주한다.
