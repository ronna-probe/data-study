# State Records

이 폴더는 프로젝트 진행 과정에서 발생한 상태 변화(State Transition)를 기록한다.

본 프로젝트는 결과뿐 아니라,
그 결과에 도달하기까지의 사고와 인식의 변화 또한 분석 가능한 데이터로 간주한다.

---

## Scope

### Reflection (rfl)

프로젝트 내부 객체에 대한 인식 변화 기록

대상:

- 핵심 지표
- Learning State Model
- 데이터 구조
- 분석 프레임워크

예시:

- PUL 정의 수정
- QCI 해석 변화

---

### Experiment (exp)

지표 및 모델 검증 기록

대상:

- 수식 실험
- 파라미터 튜닝

예시:

- PUL decay 조정
- QCI 계산식 실험

---

### Evolution (evo)

프로젝트 자체에 대한 인식 변화 기록

대상:

- 프로젝트 목적
- 문제 정의
- 분석 관점
- 설계 철학
- 프로젝트 발전 방향

예시:

- 포트폴리오에 대한 관점 변화
- 분석가 역할에 대한 재정의
- 핵심 지표 설계 과정에 대한 이해
- 프로젝트 성장 단계 발견

## Interpretation

State Records는

- 모델이 어떻게 변했는가
- 어떤 실험이 수행되었는가
- 프로젝트가 어떻게 진화했는가

를 모두 기록한다.

따라서 State Records는

프로젝트의 결과물이 아니라

프로젝트가 성장한 과정 자체를 저장하는 공간이다.
