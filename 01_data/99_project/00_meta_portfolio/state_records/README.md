# State Records

이 폴더는 프로젝트 진행 과정에서 발생한 사고 변화와 의사결정 과정을 기록한다.

결과뿐 아니라, 결과에 도달하기까지의 상태 변화 또한 분석 가능한 데이터로 간주한다.

---

## Scope

### Reflection

개념과 인식의 변화 기록

- 포트폴리오 정의 변화
- 데이터 분석 관점 변화

### Experiment

지표 및 모델 실험 기록

- PUL 가중치 조정
- 지표 검증

---

## Naming

```text
yyyy-mm-dd_<type>_<label>.md
```

---

## Philosophy

인식은 고정된 결과가 아니라 시간에 따라 변화하는 상태(State)이다.

따라서 그 변화 과정 또한 기록하고 관찰 가능한 데이터로 취급한다.
