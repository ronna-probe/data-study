# HTML/CSS가 보이는 그림책 - 성안당

예전에 Python 기반 웹 크롤링을 학습하던 시기에 이 책을 읽게 되었다.  
당시에는 데이터 추출을 위한 웹 구조 이해가 주요 목적이었다.

최근 데이터 로깅 개념을 정리하는 과정에서 이 책을 떠올리게 되었고,  
다시 한 번 읽어보게 되었다.

---

## 당시 학습 과정에서의 이해(웹 크롤링 이해)
- HTML은 웹 페이지 구조를 구성하는 기본 단위라는 점을 이해하게 되었다.
- CSS 박스 레이아웃을 통해 HTML 요소가 화면에서 영역 단위로 배치되는 구조를 이해하였다.
- DOM 구조와 id/class를 활용해 원하는 요소를 선택하는 개념을 이해하였다.
- CSS 캐스케이드를 통해 스타일이 클래스 단위로 재사용되며 코드 중복이 줄어드는 구조를 이해하였다.
- JavaScript를 통해 웹이 단순 문서가 아니라 사용자 행동에 반응하는 구조임을 이해하였다.
- 이후 <바닐라 자바스크립트> 책을 통해 관련 학습을 추가로 진행하였다.

---

## 이후 경험 및 확장
- Webflow, FlutterFlow를 활용해 간단한 앱 화면을 구성해보는 정도의 경험을 해보았다.
- FlutterFlow에서는 UI 구성과 함께 간단한 데이터 흐름(상태, 바인딩)을 일부 다뤄보며 구조를 이해해보았다.
- JavaScript 학습을 바탕으로 Google Apps Script(GAS)를 활용해 스케줄링 기반 자동화를 간단히 구현해보았다.

---

## 현재 관점 (데이터 로깅 이해)
- 현재는 웹/앱 구조가 데이터 생성과 로깅의 출발점이라는 관점으로 확장되었다.
- 사용자 행동(클릭, 페이지 이동 등)이 이벤트로 기록되어 데이터로 저장되는 흐름을 이해하였다.
- 또한 데이터로 기록 가능한 정보의 범위와 그렇지 않은 영역이 구분된다는 점을 이해하였다.
