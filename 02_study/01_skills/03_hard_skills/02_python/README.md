# Python

---

## 1. 목적

핵심 목표는 다음과 같다:

- 문제를 구조적으로 분해하는 능력
- 데이터를 코드로 모델링하는 사고
- Python 라이브러리 학습
- 반복 가능한 분석 패턴 구축
