## 데이터에 대한 관점의 변화

Pandas를 배우면서 가장 큰 변화는  
“데이터를 다루는 방식”이 아니라 **데이터를 보는 방식 자체**였다.

이전에는 데이터를 “값의 집합”으로 봤다면  
이후에는 데이터를 “상태를 가진 구조”로 보게 되었다.

> DataFrame = 고정된 표가 아니라 변화하는 데이터 상태

---

## 데이터 사고의 기본 흐름

데이터 작업은 하나의 흐름으로 수렴한다:

- Observe: 데이터를 이해한다
- Select: 필요한 구조만 남긴다
- Transform: 데이터 상태를 변경한다
- Combine: 여러 데이터를 하나로 통합한다

즉,

> 모든 데이터 작업은 “상태 → 다른 상태로의 변환”이다.

---

## SQL과의 연결된 사고

SQL과 Pandas는 도구는 다르지만 사고 구조는 동일하다.

- WHERE → 데이터를 선택하는 방식
- GROUP BY → 데이터를 압축하는 방식
- JOIN → 데이터를 확장하는 방식

이 과정에서 중요한 것은:

> 데이터를 어떤 기준으로 자르고 / 묶고 / 합칠 것인가
