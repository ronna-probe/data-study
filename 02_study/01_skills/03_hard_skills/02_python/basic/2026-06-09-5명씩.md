## 문제

최대 5명씩 탑승 가능한 놀이기구를 타기 위해 줄을 서 있는 사람들의 이름이 담긴 문자열 리스트 names가 주어진다.

앞에서부터 5명씩 묶은 각 그룹에서 가장 앞에 서 있는 사람들의 이름을 담은 리스트를 반환한다.

단, 마지막 그룹의 인원이 5명이 되지 않더라도 가장 앞 사람의 이름은 포함한다.

---

## 접근

핵심은 "5명씩 그룹을 실제로 만들 것인가, 아니면 필요한 위치만 선택할 것인가" 이다.

이 문제는 다음 두 가지 관점으로 볼 수 있다.

### 1. 그룹 생성 후 추출

- 5명 단위로 슬라이싱하여 그룹 생성
- 각 그룹의 첫 번째 원소 선택

### 2. 구조 파악

- 필요한 사람은 인덱스 기준으로 0, 5, 10, 15 ... 위치에 존재
- 실제 그룹을 만들 필요 없이 5칸 간격으로 바로 선택 가능

---

## 코드

### 1. 그룹 생성 후 첫 번째 원소 추출

```python
def get_group_leaders(names):
    groups = [names[i:i+5] for i in range(0, len(names), 5)]
    leaders = [group[0] for group in groups]

    return leaders
```

### 2-1. 슬라이싱

```python
def get_group_leaders(names):
    leaders = names[::5]

    return leaders
```

### 2-2. enumerate

```python
def get_group_leaders(names):
    leaders = [name for i, name in enumerate(names) if i % 5 == 0]

    return leaders
```

## 정리

구현에 앞서 결과 데이터의 규칙을 파악하면 불필요한 과정을 줄일 수 있다.

이 문제에서는 5칸 간격이라는 규칙을 이용해 원하는 값을 직접 선택할 수 있다.

---

## 참고

### 1. iterator

Python의 iterator는 컬렉션을 처음부터 끝까지 순차적으로 접근하기 위한 객체이다.

```python 
it = iter(names)
next(it)
```

를 호출하면 현재 위치의 원소를 반환하고 내부 위치를 다음 원소로 이동시킨다.

이는 Python의 순차 접근 구조를 이해하는 관점에서 참고할 만한 개념이다.

### 2. generator

Python은 yield 키워드를 통해 iterator를 간편하게 생성할 수 있는 generator를 제공한다.

```python
def group_leaders(names):
    for i, name in enumerate(names):
        if i % 5 == 0:
            yield name
```

generator는 값을 한 번에 모두 생성하지 않고, 필요할 때마다 하나씩 반환한다.

```python
gen = group_leaders(names)

next(gen)
next(gen)
```

와 같이 사용할 수 있으며, 내부적으로 iterator 프로토콜을 구현하고 있다.

다만 이 문제에서는 최종 결과를 리스트로 반환해야 하고,
5칸 간격으로 선택하는 규칙이 명확하므로 슬라이싱 방식이 더 직관적이고 간결하다.

### 3. 보충

iterator와 generator는 Python의 순차 처리와 지연 평가(lazy evaluation) 구조를 이해하는 관점에서 참고할 만한 개념이다.

- 즉시 평가(Eager Evaluation): 값을 요청하기 전에 결과를 미리 계산
- 지연 평가(Lazy Evaluation): 값이 필요할 때마다 하나씩 계산
