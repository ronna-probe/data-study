# Analysis

정의된 문제와 가설을 실제 데이터에 적용하여  
검증하고 패턴을 발견하는 실험적 분석 공간이다.

이 단계에서는 SQL, Python 등을 활용하여  
데이터를 직접 다루고 구조를 확인한다.

---

## 주요 내용

- 데이터 수집 및 정제
- SQL 기반 데이터 탐색
- Python 기반 분석
- 탐색적 데이터 분석(EDA)
- 패턴 및 이상치 탐색
- 패턴 및 구조적 관계 발견

---

## 목적

이론적으로 정의된 문제와 가설이  
실제 데이터에서 어떻게 나타나는지 검증하고,

데이터 기반 사고력과 분석적 추론 능력을 기르는 것을 목표로 한다.
