# 기술적 역량

데이터를 추출·처리·분석하고 구현하기 위한 기술 기반 역량을 학습하는 공간이다.

## 구성

### Tools
- 01_sql: 데이터 추출과 가공을 위한 SQL 활용
- 02_python: 데이터 분석 및 자동화를 위한 Python 활용
- 03_visualization: 데이터 시각화 및 결과 표현

### Engineering
- 04_engineering_basics: 시스템과 개발 구조에 대한 기초 이해

### Analysis
- 05_machine_learning: 머신러닝 모델과 분석 방법 이해
- 06_mathematics: 수학·통계 기반 분석 이론 이해

## 목적
데이터를 실제로 다루고 분석할 수 있는 기술적 기반과 구현 역량을 기르는 것을 목표로 한다.
