# 여러 그룹의 차이는 어떻게 검증할까?

두 그룹의 차이를 검증하는 방법을 배웠다면, 이번에는 여러 그룹을 동시에 비교하는 상황을 살펴보자.  
예를 들어 캠페인 A, B, C에 참여한 고객들의 만족도가 서로 다른지 확인하고 싶을 수 있다.  
그룹이 두 개일 때는 t-test를 활용할 수 있지만, 그룹이 세 개 이상이라면 여러 그룹의 평균을 동시에 비교할 수 있는 방법이 필요하다.

> 세 개 이상의 그룹에서 관찰한 차이는 어떻게 검증할 수 있을까?

이번에는 그룹별 평균을 비교하고, 전체 그룹 사이에 차이가 있는지 검증한 뒤,  
**어떤 그룹 사이에서 실제 차이가 나타나는지** 확인하는 방법을 살펴본다.

---

## 질문

- 그룹별 평균은 얼마나 차이 날까?
- 세 그룹 이상의 평균 차이는 어떻게 검증할까?
- 차이가 있다면 어떤 그룹 사이에서 나타날까?
- 검정 결과를 해석할 때 무엇을 주의해야 할까?

## 1. 그룹별 평균은 얼마나 차이 날까?

<details>
<summary>⋯</summary>

먼저 각 캠페인의 만족도를 요약해보자.

```python
customers.groupby("campaign")["satisfaction"].agg(
    ["count", "mean", "std"]
)
```

그룹별 평균은 다음과 같다.

| 캠페인 | 고객 수 | 평균 만족도 |
|---|---:|---:|
| A | 10 | 54.5 |
| B | 10 | 62.0 |
| C | 10 | 32.4 |

이번 데이터에서는 B 캠페인의 평균 만족도가 가장 높고, C 캠페인의 평균 만족도가 가장 낮다.

그룹별 평균을 그래프로 비교해보자.

```python
customers.groupby("campaign")["satisfaction"].mean().plot(
    kind="bar"
)

import matplotlib.pyplot as plt

plt.xlabel("Campaign")
plt.ylabel("Mean Satisfaction")
plt.title("Mean Satisfaction by Campaign")
plt.xticks(rotation=0)
plt.show()
```

여기서 주의해야 할 점이 있다.  
평균이 서로 다르다는 사실만으로 모집단에서도 실제 차이가 있다고 결론 내릴 수는 없다.  
표본을 추출하는 과정에서 자연스럽게 발생한 차이일 수도 있기 때문이다.

따라서 관찰한 차이가 우연한 변동만으로 설명될 수 있는지 통계적으로 검증해야 한다.

## 2. 세 그룹 이상의 평균 차이는 어떻게 검증할까?

<details>
<summary>⋯</summary>

세 그룹 이상의 평균을 동시에 비교할 때는 **분산분석(ANOVA, Analysis of Variance)** 을 사용할 수 있다.  
분산분석은 그룹 간 평균 차이가 그룹 내부의 변동에 비해 얼마나 큰지 평가하는 방법이다.

먼저 두 가지 가설을 설정한다.  
- **귀무가설**: 모든 그룹의 모집단 평균은 같다.
- **대립가설**: 적어도 한 그룹의 모집단 평균은 다르다.

scipy의 `f_oneway()`를 사용하면 일원분산분석(One-way ANOVA)을 수행할 수 있다.

```python
group_a = customers.loc[
    customers["campaign"] == "A",
    "satisfaction"
]

group_b = customers.loc[
    customers["campaign"] == "B",
    "satisfaction"
]

group_c = customers.loc[
    customers["campaign"] == "C",
    "satisfaction"
]

result = stats.f_oneway(
    group_a,
    group_b,
    group_c
)

result
```

검정 결과에서 F 통계량과 p-value를 확인할 수 있다.

```python
print("F 통계량:", result.statistic)
print("p-value:", result.pvalue)
```

이번 데이터에서는 p-value가 0.05보다 작게 나타난다.  
유의수준을 0.05로 설정하면 귀무가설을 기각할 수 있다.  
즉, 세 그룹의 모집단 평균이 모두 같다고 보기 어렵다는 통계적 근거가 나타난 것이다.

여기서 중요한 특징이 있다.  
ANOVA 결과만으로는 어떤 그룹과 어떤 그룹 사이에 차이가 있는지 알 수 없다.  
예를 들어 A와 B가 다른 것인지, B와 C가 다른 것인지, 아니면 세 그룹 모두 서로 다른 것인지는 아직 알 수 없다.

**ANOVA는 전체 그룹에 평균 차이가 존재하는지 먼저 확인하는 검정이다.**

</details>

## 3. 차이가 있다면 어떤 그룹 사이에서 나타날까?

<details>
<summary>⋯</summary>

ANOVA에서 통계적으로 유의한 차이가 발견되었다면 다음으로 어떤 그룹 사이에서 차이가 나타나는지 확인해야 한다.  
이때 사용하는 방법이 **사후검정(Post-hoc Test)** 이다.

대표적인 방법 중 하나는 Tukey HSD 검정이다.  
Tukey HSD는 여러 그룹을 두 개씩 비교하면서 전체 비교 과정에서 발생할 수 있는 제1종 오류를 통제한다.

```python
from statsmodels.stats.multicomp import pairwise_tukeyhsd

tukey_result = pairwise_tukeyhsd(
    endog=customers["satisfaction"],
    groups=customers["campaign"],
    alpha=0.05
)

print(tukey_result)
```

결과에서는 다음과 같은 정보를 확인할 수 있다.

| 항목 | 의미 |
|---|---|
| group1, group2 | 비교하는 두 그룹 |
| meandiff | 두 그룹 평균의 차이 |
| p-adj | 다중비교를 고려한 조정 p-value |
| lower, upper | 평균 차이의 신뢰구간 |
| reject | 유의수준에서 차이가 유의한지 여부 |

이번 데이터에서는 A-B, A-C, B-C의 모든 비교에서 통계적으로 유의한 차이가 나타난다.  
즉, 세 그룹이 모두 서로 다른 평균을 보인다는 근거를 확인할 수 있다.  
이처럼 ANOVA로 전체적인 차이가 있는지 확인하고, 사후검정으로 구체적으로 어떤 그룹 사이에서 차이가 있는지 확인할 수 있다.

</details>

## 4. 검정 결과를 해석할 때 무엇을 주의해야 할까?

<details>
<summary>⋯</summary>

ANOVA와 사후검정 결과를 해석할 때는 몇 가지 조건과 주의사항을 함께 고려해야 한다.

### 분산분석의 주요 가정

일반적인 일원분산분석은 다음과 같은 조건을 가정한다.

- **독립성:** 각 관측값은 서로 독립적이어야 한다.
- **정규성:** 각 그룹의 모집단 또는 모형의 잔차가 대체로 정규분포를 따라야 한다.
- **등분산성:** 각 그룹의 모집단 분산이 같아야 한다.

등분산성은 Levene 검정으로 확인할 수 있다.

```python
levene_result = stats.levene(
    group_a,
    group_b,
    group_c
)

print("Levene p-value:", levene_result.pvalue)
```

Levene 검정의 귀무가설은 그룹 간 분산이 같다는 것이다.  
p-value가 유의수준보다 작다면 등분산 가정에 문제가 있을 가능성을 고려해야 한다.

등분산 가정이 적절하지 않다면 Welch ANOVA를 고려할 수 있다.  
그룹 간 분산이 다를 수 있는 상황에 사용하는 분산분석 방법이다.

또한 독립성은 검정 결과만으로 확인할 수 있는 조건이 아니다.  
실제 데이터가 어떻게 수집되었는지 분석 설계를 통해 판단해야 한다.

### 통계적 차이와 실제 중요성은 다르다

통계적으로 유의한 차이가 있다고 해서 그 차이가 반드시 실무적으로 중요한 것은 아니다.  
예를 들어 만족도 평균이 0.1점 차이 나더라도 표본이 매우 크다면 통계적으로 유의할 수 있다.  
반대로 실제로 큰 차이가 있어도 표본이 너무 적으면 유의한 결과를 발견하지 못할 수 있다.

따라서 검정 결과를 해석할 때는 다음을 함께 살펴봐야 한다.

- 그룹 간 평균 차이는 실제로 얼마나 큰가?
- 표본 크기와 데이터의 변동성은 적절한가?
- 통계적으로 유의한 차이가 업무적으로도 의미 있는가?
- 분석에 사용한 검정 방법의 가정은 적절한가?

**통계적 유의성만으로 그룹의 우열이나 실제 효과를 단정해서는 안 된다.**

</details>

## 정리

<details open>
<summary>⋯</summary>

| 확인할 내용 | 핵심 개념 |
|---|---|
| 여러 그룹의 평균 비교 | 일원분산분석(ANOVA) |
| 전체 그룹의 차이 검증 | F 통계량, p-value |
| 그룹별 차이 확인 | 사후검정 |
| 모든 쌍의 평균 비교 | Tukey HSD |
| 분산의 동질성 확인 | Levene 검정 |
| 등분산 가정이 어려운 경우 | Welch ANOVA |

핵심은 **여러 그룹을 비교할 때 전체적인 차이와 구체적인 그룹 간 차이를 구분해서 검증하는 것**이다.  
ANOVA로 전체적인 차이를 확인하고, 사후검정으로 어떤 그룹 사이에서 차이가 나타나는지 살펴본다.

> 통계에서는 여러 그룹의 평균을 한 번에 비교한 뒤, 필요한 경우 사후검정을 통해 구체적인 차이를 확인한다.

</details>
