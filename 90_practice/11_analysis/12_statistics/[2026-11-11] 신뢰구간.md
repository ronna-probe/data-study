# 추정한 값은 얼마나 믿을만할까?

표본을 통해 모집단의 평균을 추정할 수 있지만, 표본에서 계산한 평균이 모집단의 실제 평균과 정확히 일치한다고 보장할 수는 없다.  
예를 들어 고객 12명의 주문 금액을 조사해 평균을 계산했다면, 이 값이 전체 고객의 평균 주문 금액과 얼마나 차이가 날 수 있을까?

앞에서 살펴본 것처럼 표본을 다시 추출하면 평균도 달라진다.  
그렇다면 표본에서 계산한 값만 제시하는 것이 아니라, 그 값이 어느 정도 범위에 있을지 함께 표현할 수 있지 않을까?

> 표본에서 계산한 값으로 전체를 추정할 때, 그 결과의 불확실성을 어떻게 표현할 수 있을까?

이번에는 **점추정, 표준오차, 신뢰구간, 신뢰수준**을 통해 추정값의 불확실성을 살펴본다.

---

## 질문

- 표본에서 계산한 값으로 모집단의 값을 어떻게 추정할까?
- 추정값의 불확실성은 어떻게 표현할 수 있을까?
- 신뢰구간은 어떻게 계산하고 해석할까?
- 신뢰수준에 따라 구간은 어떻게 달라질까?

단위는 천 원이다.

import pandas as pd

sample = pd.DataFrame({

## 1. 표본에서 계산한 값으로 모집단의 값을 어떻게 추정할까?

<details>
<summary>⋯</summary>

모집단의 실제 평균을 알 수 없다면, 표본에서 계산한 평균을 이용해 추정할 수 있다.  
먼저 표본의 평균을 계산해보자.

```python
sample_mean = sample["amount"].mean()

sample_mean
```

결과는 14.25천 원이다.  
이처럼 표본에서 계산한 하나의 값으로 모집단의 모수를 추정하는 방법을 **점추정(Point Estimation)** 이라고 한다.

이번 예시에서는 표본 평균인 14.25천 원을 모집단 평균의 점추정값으로 사용한다.  
하지만 이 값은 표본에서 계산한 결과이므로 실제 모집단 평균과 차이가 있을 수 있다.  
따라서 평균 하나만 제시하는 것보다 추정값의 불확실성도 함께 살펴볼 필요가 있다.

</details>

## 2. 추정값의 불확실성은 어떻게 표현할 수 있을까?

<details>
<summary>⋯</summary>

앞에서 표본평균의 변동성을 표준오차로 살펴봤다.  
표준오차는 표본을 반복해서 추출했을 때 표본평균이 얼마나 달라지는지를 나타낸다.  
모집단의 표준편차를 모르는 일반적인 상황에서는 표본의 표준편차를 이용해 평균의 표준오차를 추정할 수 있다.

표준오차는 다음과 같이 계산한다.  
표본 표준편차를 s, 표본 크기를 n이라고 하면,

SE = s / sqrt(n)

pandas로 계산해보자.

```python
sample_std = sample["amount"].std(ddof=1)

standard_error = sample_std / np.sqrt(
    len(sample)
)

standard_error
```

표준오차를 통해 표본평균의 변동성을 파악할 수 있다.  
하지만 표준오차만으로는 모집단 평균이 어느 범위에 있을지 직접 표현하기 어렵다.  
이때 사용하는 것이 **신뢰구간(Confidence Interval)** 이다.

신뢰구간은 표본에서 계산한 추정값을 바탕으로 모집단의 모수가 있을 것으로 추정하는 범위를 제공한다.  
즉, 점추정이 하나의 값을 제시한다면 신뢰구간은 추정값 주변의 불확실성을 범위로 표현한다.

</details>

---

## 3. 신뢰구간은 어떻게 계산하고 해석할까?

<details>
<summary>⋯</summary>

신뢰구간은 점추정값에 오차범위를 더하고 빼서 계산할 수 있다.  
모집단의 표준편차를 모르는 경우에는 일반적으로 t분포를 이용한다.

95% 신뢰구간을 계산해보자.

```python
from scipy import stats

n = len(sample)
confidence_level = 0.95

sample_mean = sample["amount"].mean()
sample_std = sample["amount"].std(ddof=1)

standard_error = sample_std / np.sqrt(n)

t_value = stats.t.ppf(
    (1 + confidence_level) / 2,
    df=n - 1
)

margin_of_error = t_value * standard_error

lower = sample_mean - margin_of_error
upper = sample_mean + margin_of_error

pd.Series({
    "표본 평균": sample_mean,
    "표준오차": standard_error,
    "오차범위": margin_of_error,
    "신뢰구간 하한": lower,
    "신뢰구간 상한": upper
})
```

이번 데이터에서 계산한 95% 신뢰구간은 약 12.71천 원에서 15.79천 원이다.  
즉, 표본 평균은 14.25천 원이지만 모집단 평균을 추정할 때는 12.71천 원에서 15.79천 원이라는 범위로 표현할 수 있다.

그렇다면 95% 신뢰구간은 정확히 무엇을 의미할까?  
모집단의 실제 평균이 이번에 계산한 구간 안에 있을 확률이 95%라는 뜻은 아니다.  
모집단의 평균은 고정된 값이고, 표본을 추출할 때마다 계산되는 신뢰구간이 달라진다.  
같은 방법으로 표본을 반복해서 추출하고 신뢰구간을 계속 계산한다면, 그렇게 만들어진 구간 중 약 95%가 모집단의 실제 평균을 포함한다는 의미다.

**신뢰구간은 추정값 자체의 확실성을 보장하는 것이 아니라, 추정 방법의 장기적인 포괄 비율을 나타낸다.**

</details>

## 4. 신뢰수준에 따라 구간은 어떻게 달라질까?

<details>
<summary>⋯</summary>

신뢰구간은 신뢰수준에 따라 범위가 달라진다.  
일반적으로 90%, 95%, 99% 신뢰수준을 자주 사용한다.  
같은 표본을 사용하더라도 신뢰수준을 높이려면 실제 모집단 평균을 포함하도록 더 넓은 구간을 만들어야 한다.

각 신뢰수준에 따른 구간을 비교해보자.

```python
confidence_levels = [0.90, 0.95, 0.99]

intervals = []

for level in confidence_levels:
    t_value = stats.t.ppf(
        (1 + level) / 2,
        df=n - 1
    )

    margin = t_value * standard_error

    intervals.append({
        "신뢰수준": f"{level:.0%}",
        "하한": sample_mean - margin,
        "상한": sample_mean + margin,
        "구간 너비": margin * 2
    })

pd.DataFrame(intervals)
```

또한 신뢰구간의 너비는 신뢰수준뿐 아니라 다음 요인에도 영향을 받는다.

- **표본 크기:** 표본이 커질수록 일반적으로 신뢰구간이 좁아진다.
- **데이터의 변동성:** 데이터가 많이 퍼져 있을수록 신뢰구간이 넓어진다.
- **신뢰수준:** 신뢰수준을 높일수록 신뢰구간이 넓어진다.

따라서 신뢰구간을 해석할 때는 단순히 구간만 확인하는 것이 아니라 어떤 조건에서 계산되었는지도 함께 살펴봐야 한다.

</details>

## 정리

<details open>
<summary>⋯</summary>

| 확인할 내용 | 핵심 개념 |
|---|---|
| 하나의 값으로 추정 | 점추정 |
| 추정값의 변동성 | 표준오차 |
| 추정값의 불확실성 표현 | 신뢰구간 |
| 구간의 장기적인 포괄 비율 | 신뢰수준 |
| 신뢰구간 계산 | t분포 |

핵심은 **표본에서 계산한 하나의 값을 모집단의 실제 값처럼 받아들이지 않는 것**이다.  
표본 평균은 모집단 평균을 추정하는 출발점이고, 표준오차와 신뢰구간은 그 추정값이 얼마나 불확실한지 이해하는 데 도움을 준다.

> 통계에서는 하나의 추정값만 제시하는 것이 아니라, 그 값의 불확실성까지 함께 고려해야 한다.

</details>
