# 관찰한 차이는 우연일까?

데이터를 분석하다 보면 예상과 다른 결과나 그룹 간 차이를 발견할 수 있다.

예를 들어 동전을 100번 던졌는데 앞면이 60번 나왔다고 해보자.  
동전이 공정하다면 앞면과 뒷면이 각각 절반 정도 나올 것으로 예상할 수 있다.

그렇다면 앞면이 60번 나온 결과는 동전이 공정하지 않다는 증거일까?  
아니면 공정한 동전을 던지더라도 우연히 나타날 수 있는 결과일까?

> 관찰한 결과가 우연한 변동만으로도 나타날 수 있을까?

이번에는 가설을 세우고, 관찰한 결과가 우연으로 설명될 수 있는지 평가하면서 **가설검정, p-value, 유의수준**을 살펴본다.

---

## 질문

- 어떤 가설을 세우고 검증해야 할까?
- 가설이 참이라고 가정하면 관찰한 결과는 얼마나 드물게 나타날까?
- p-value는 무엇을 의미할까?
- 어떤 기준으로 가설을 기각하거나 유지할까?

---

## 데이터

공정한 동전을 100번 던졌다고 가정해보자.

관찰한 결과는 다음과 같다.

```python
import pandas as pd

results = pd.DataFrame({
    "result": ["앞면"] * 60 + ["뒷면"] * 40
})

results["result"].value_counts()
```

| 결과 | 횟수 |
|---|---:|
| 앞면 | 60 |
| 뒷면 | 40 |
| 합계 | 100 |

동전이 공정하다면 앞면이 나올 확률은 0.5라고 예상할 수 있다.  
이번에는 관찰한 결과가 우연한 변동으로 설명될 수 있는지 확인해보자.

---

## 1. 어떤 가설을 세우고 검증해야 할까?

<details>
<summary>⋯</summary>

관찰한 결과를 검증하려면 먼저 어떤 주장을 확인할 것인지 가설을 세워야 한다.

통계적 가설검정에서는 일반적으로 두 가지 가설을 설정한다.

- **귀무가설(Null Hypothesis)**  
기본적으로 참이라고 가정하고 검증을 시작하는 가설이다.  
이번 예시에서는 동전이 공정하다는 가정이다.

\[
H_0: p = 0.5
\]

- **대립가설(Alternative Hypothesis)**  
귀무가설과 반대되는 방향으로 검증하려는 가설이다.  
이번 예시에서는 앞면이 나올 확률이 0.5와 다르다는 주장이다.

\[
H_1: p != 0.5
\]

여기서 \(p\)는 동전을 던졌을 때 앞면이 나올 확률이다.

두 가설을 정리하면 다음과 같다.

| 구분 | 가설 |
|---|---|
| 귀무가설 | 앞면이 나올 확률은 0.5이다. |
| 대립가설 | 앞면이 나올 확률은 0.5가 아니다. |

이처럼 검증하려는 주장을 가설로 명확하게 정의하는 것이 가설검정의 출발점이다.

</details>

## 2. 가설이 참이라고 가정하면 관찰한 결과는 얼마나 드물게 나타날까?

<details>
<summary>⋯</summary>

귀무가설이 참이라고 가정해보자.  
즉, 동전이 공정하고 앞면이 나올 확률이 0.5라고 가정하는 것이다.  
그렇다면 100번 던졌을 때 앞면이 반드시 50번 나와야 할까?  

그렇지는 않다.  
무작위로 동전을 던지기 때문에 앞면이 45번, 55번 또는 60번 나오는 결과도 발생할 수 있다.

이러한 변동이 얼마나 자주 나타나는지 시뮬레이션으로 확인해보자.

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)

simulated_heads = rng.binomial(
    n=100,
    p=0.5,
    size=10000
)

plt.hist(
    simulated_heads,
    bins=np.arange(24.5, 76.5, 1),
    edgecolor="black"
)

plt.axvline(
    60,
    color="red",
    linestyle="--",
    label="Observed: 60"
)

plt.axvline(
    40,
    color="red",
    linestyle=":",
    label="Equally Extreme: 40"
)

plt.xlabel("Number of Heads")
plt.ylabel("Frequency")
plt.title("Number of Heads in 100 Fair Coin Tosses")
plt.legend()

plt.show()
```

이 그래프는 공정한 동전을 100번 던지는 실험을 10,000번 반복했을 때 앞면이 나온 횟수의 분포를 보여준다.  
대부분의 결과는 50회 주변에 모이지만, 그보다 훨씬 많거나 적게 나오는 경우도 발생한다.  
이번에 관찰한 결과는 앞면 60회다.

양측 검정을 기준으로 하면 앞면이 60회 이상 나오거나 40회 이하 나오는 결과가 관찰값만큼 극단적인 결과에 해당한다.  
즉, 귀무가설이 참이더라도 관찰한 결과와 같거나 더 극단적인 결과가 나타날 가능성이 존재한다.

**가설검정은 이러한 결과가 얼마나 드물게 나타나는지 평가하는 과정이다.**

</details>

## 3. p-value는 무엇을 의미할까?

<details>
<summary>⋯</summary>

가설이 참이라고 가정했을 때 관찰한 결과와 같거나 더 극단적인 결과가 나타날 확률을 **p-value**라고 한다.

이번 예시에서는 다음 조건을 가정한다.

- 귀무가설: 앞면이 나올 확률은 0.5이다.
- 관찰 결과: 앞면 60회, 뒷면 40회
- 검정 방향: 앞면이 나올 확률이 0.5와 다른지 확인하는 양측 검정

scipy의 `binomtest()`를 사용하면 이 확률을 계산할 수 있다.

```python
from scipy import stats

test_result = stats.binomtest(
    k=60,
    n=100,
    p=0.5,
    alternative="two-sided"
)

test_result.pvalue
```

계산 결과는 약 0.0569이다.  
즉, 공정한 동전이라는 가정하에서 앞면이 60회 이상 또는 40회 이하 나오는 것처럼 관찰 결과와 같거나 더 극단적인 결과가 나타날 확률은 약 5.69%라는 의미다.

여기서 주의할 점이 있다.  
p-value가 0.0569라고 해서 동전이 공정할 확률이 5.69%라는 뜻은 아니다.  
또한 관찰한 결과가 단순히 우연일 확률을 의미하는 것도 아니다.

p-value는 반드시 **귀무가설이 참이라는 가정 아래** 해석해야 한다.

| p-value | 해석 |
|---|---|
| 작음 | 귀무가설이 참일 때 관찰 결과가 드물게 나타남 |
| 큼 | 귀무가설이 참일 때 관찰 결과가 비교적 자주 나타날 수 있음 |

따라서 p-value가 작을수록 귀무가설과 관찰 결과 사이의 불일치가 크다고 판단할 근거가 된다.

</details>

## 4. 어떤 기준으로 가설을 기각하거나 유지할까?

<details>
<summary>⋯</summary>

p-value를 계산했다면 이제 어떤 기준으로 판단할지 정해야 한다.  
이때 사용하는 것이 **유의수준(Significance Level)** 이다.  
유의수준은 귀무가설을 기각할지 결정하기 위해 미리 정하는 기준이다.  
일반적으로 0.05를 많이 사용한다.

이번 예시에서 유의수준을 0.05로 설정해보자.

```python
alpha = 0.05
p_value = test_result.pvalue

if p_value < alpha:
    print("귀무가설 기각")
else:
    print("귀무가설을 기각하지 못함")
```

이번 결과에서는 다음과 같이 판단한다.

| 항목 | 값 |
|---|---:|
| p-value | 0.0569 |
| 유의수준 | 0.05 |
| 판단 | 귀무가설을 기각하지 못함 |

p-value가 유의수준보다 크기 때문에 귀무가설을 기각할 만큼 충분한 통계적 근거를 확보하지 못했다.  
그렇다면 동전이 반드시 공정하다는 뜻일까?

그렇지는 않다.  
귀무가설을 기각하지 못했다는 것은 동전이 공정하다는 사실을 증명한 것이 아니라, 관찰한 데이터만으로는 공정하지 않다고 판단할 근거가 충분하지 않다는 의미다.

반대로 p-value가 유의수준보다 작다면 귀무가설을 기각하고 대립가설을 뒷받침하는 통계적 근거가 있다고 판단한다.  
여기서 중요한 것은 유의수준을 결과를 확인하기 전에 정해야 한다는 점이다.

**통계적 판단 기준을 미리 정해두면 관찰한 결과에 맞춰 판단 기준을 바꾸는 문제를 줄일 수 있다.**

</details>

## 정리

<details open>
<summary>⋯</summary>

| 확인할 내용 | 핵심 개념 |
|---|---|
| 검증할 기본 가정 | 귀무가설 |
| 확인하려는 주장 | 대립가설 |
| 귀무가설 아래에서 관찰 결과가 얼마나 극단적인지 | p-value |
| 가설을 기각할 판단 기준 | 유의수준 |
| 가설을 검증하는 과정 | 가설검정 |

핵심은 **관찰한 차이가 있다는 사실만으로 의미 있는 차이라고 판단하지 않는 것**이다.  
먼저 가설을 설정하고, 귀무가설이 참이라는 가정 아래 관찰한 결과가 얼마나 드물게 나타나는지 평가해야 한다.

다만 통계적으로 유의한 결과가 반드시 실무적으로 중요한 결과라는 뜻은 아니다.  
차이의 크기와 실제 의미도 함께 살펴봐야 한다.

> 통계에서는 관찰한 패턴이 우연한 변동만으로 설명될 수 있는지 가설검정을 통해 평가한다.

</details>
