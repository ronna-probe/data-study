# 표본에서 계산한 값은 얼마나 흔들릴까?

같은 모집단에서 표본을 여러 번 추출하면 매번 계산되는 평균이 조금씩 달라진다.  
그렇다면 이 차이는 어느 정도까지 발생할 수 있을까?

표본을 반복해서 추출하고 평균을 계산하면, 각각의 표본평균도 하나의 분포를 만들게 된다.  
이 분포를 살펴보면 표본 평균이 얼마나 달라지는지, 표본 크기가 커질수록 결과가 어떻게 변하는지 이해할 수 있다.

> 표본에서 계산한 값은 얼마나 흔들리며, 그 흔들림을 어떻게 측정할 수 있을까?

이번에는 여러 표본에서 계산한 평균을 비교하면서 **표본분포, 표준오차, 중심극한정리**를 살펴본다.

---

## 질문

- 여러 표본에서 계산한 평균은 어떤 분포를 만들까?
- 표본 평균의 흔들림을 어떻게 숫자로 나타낼 수 있을까?
- 표본 크기가 커지면 평균의 흔들림은 어떻게 달라질까?
- 표본 크기가 커지면 표본 평균의 분포 모양도 달라질까?

---

## 데이터

한 쇼핑몰의 고객 100명을 모집단으로 가정하고, 고객별 주문 금액을 살펴보자.

```python
import pandas as pd
import numpy as np

population = pd.Series(
    [10] * 70 +
    [20] * 20 +
    [30] * 7 +
    [100] * 3,
    name="order_amount"
)

population
```

주문 금액의 단위는 천 원이다.

| 주문 금액 | 고객 수 |
|---:|---:|
| 10 | 70 |
| 20 | 20 |
| 30 | 7 |
| 100 | 3 |
| **합계** | **100** |

모집단의 평균과 표준편차를 확인해보자.

```python
population.mean()
population.std(ddof=0)
```

모집단 평균은 16.1이고, 표준편차는 약 15.91이다.

## 1. 여러 표본에서 계산한 평균은 어떤 분포를 만들까?

<details>
<summary>⋯</summary>

동일한 모집단에서 10명씩 표본을 1,000번 추출한다고 가정해보자.  
각 표본에서 평균을 계산하면 1,000개의 표본 평균을 얻을 수 있다.

```python
rng = np.random.default_rng(42)

sample_means = []

for _ in range(1000):
    sample = rng.choice(
        population,
        size=10,
        replace=False
    )

    sample_means.append(sample.mean())

sample_means = pd.Series(sample_means)

sample_means.head()
```

이제 여러 표본에서 계산한 평균의 분포를 확인해보자.

```python
import matplotlib.pyplot as plt

plt.hist(
    sample_means,
    bins=25,
    edgecolor="black"
)

plt.axvline(
    population.mean(),
    color="red",
    linestyle="--",
    label="Population Mean"
)

plt.xlabel("Sample Mean")
plt.ylabel("Frequency")
plt.title("Distribution of Sample Means")
plt.legend()

plt.show()
```

그래프에서는 표본마다 계산한 평균이 서로 다른 값으로 나타나는 것을 확인할 수 있다.

어떤 표본의 평균은 모집단 평균보다 높고, 다른 표본의 평균은 낮을 수 있다.  
이처럼 **동일한 크기의 표본을 반복해서 추출하고, 매번 계산한 통계량으로 만든 분포**를 표본분포(Sampling Distribution)라고 한다.

여기서는 표본에서 계산한 평균을 모았으므로 정확히는 표본평균의 표본분포라고 한다.

구분해야 할 개념이 있다.

- 모집단 분포: 개별 고객의 주문 금액이 어떻게 분포하는가?
- 표본분포: 여러 표본에서 계산한 평균이 어떻게 분포하는가?

표본분포를 살펴보면 하나의 표본에서 계산한 평균이 어느 정도 달라질 수 있는지 이해할 수 있다.

</details>

## 2. 표본 평균의 흔들림을 어떻게 숫자로 나타낼 수 있을까?

<details>
<summary>⋯</summary>

표본평균의 분포를 확인했다면, 이번에는 그 분포가 얼마나 퍼져 있는지 숫자로 표현해보자.  
표본평균의 표본분포에서 표준편차를 계산하면 다음과 같다.

```python
standard_error = sample_means.std()

standard_error
```

이 값은 여러 표본에서 계산한 평균이 얼마나 흩어져 있는지를 나타낸다.  
이처럼 **표본분포의 표준편차를 표준오차(Standard Error)** 라고 한다.  
표준편차와 표준오차는 비슷한 개념이지만 무엇의 변동성을 측정하는지 다르다.

| 구분 | 설명 |
|---|---|
| 표준편차 | 개별 데이터 값이 평균 주변에서 얼마나 퍼져 있는가? |
| 표준오차 | 표본에서 계산한 통계량이 표본마다 얼마나 달라지는가? |

예를 들어 고객 주문 금액의 표준편차는 개별 주문 금액의 차이를 나타낸다.  
반면 주문 금액의 표본평균에 대한 표준오차는 표본을 다시 추출했을 때 평균이 얼마나 달라지는지를 나타낸다.

- 표준편차는 데이터의 변동성을 측정한다.
- 표준오차는 표본을 통해 추정한 값의 변동성을 측정한다.

표준오차가 작을수록 표본을 반복해서 추출했을 때 계산되는 평균이 비교적 일정하게 나타난다고 볼 수 있다.

## 3. 표본 크기가 커지면 평균의 흔들림은 어떻게 달라질까?

<details>
<summary>⋯</summary>

표본 크기가 달라지면 표본평균의 표본분포도 달라질 수 있다.  
이번에는 5명, 10명, 30명을 각각 표본으로 추출하고, 매번 평균을 계산하는 과정을 1,000번 반복해보자.

```python
def simulate_sample_means(sample_size, repetitions=1000):
    rng = np.random.default_rng(42)

    means = []

    for _ in range(repetitions):
        sample = rng.choice(
            population,
            size=sample_size,
            replace=False
        )

        means.append(sample.mean())

    return pd.Series(means)


results = {
    5: simulate_sample_means(5),
    10: simulate_sample_means(10),
    30: simulate_sample_means(30)
}
```

표본 크기별로 표준오차를 비교해보자.

```python
summary = pd.DataFrame({
    sample_size: {
        "표본평균": means.mean(),
        "표준오차": means.std()
    }
    for sample_size, means in results.items()
}).T

summary.index.name = "표본 크기"

summary
```

표본 크기별 표준오차를 그래프로 비교해보자.

```python
summary["표준오차"].plot(
    kind="bar",
    rot=0
)

plt.xlabel("Sample Size")
plt.ylabel("Standard Error")
plt.title("Standard Error by Sample Size")

plt.show()
```

일반적으로 표본 크기가 커질수록 표준오차는 작아진다.  
표본에 포함되는 데이터가 많아지면 개별 데이터의 영향이 상대적으로 줄어들기 때문이다.

다만 표본 크기가 커졌다고 해서 모든 표본의 평균이 반드시 모집단 평균에 가까워지는 것은 아니다.  
중요한 것은 반복해서 표본을 추출했을 때 **평균의 변동성이 전반적으로 줄어드는 경향**이다.

</details>

## 4. 표본 크기가 커지면 표본 평균의 분포 모양도 달라질까?

<details>
<summary>⋯</summary>

표본 크기는 표본평균의 변동성뿐 아니라 표본분포의 모양에도 영향을 준다.

앞에서 사용한 주문 금액 데이터는 일부 고객이 큰 금액을 주문하기 때문에 오른쪽으로 치우친 분포를 가지고 있다.  
이 모집단에서 표본 크기를 다르게 설정하고, 표본평균의 분포를 비교해보자.

```python
fig, axes = plt.subplots(1, 3, figsize=(14, 4))

for ax, sample_size in zip(axes, [5, 10, 30]):
    ax.hist(
        results[sample_size],
        bins=20,
        edgecolor="black"
    )

    ax.axvline(
        population.mean(),
        color="red",
        linestyle="--"
    )

    ax.set_title(f"Sample Size = {sample_size}")
    ax.set_xlabel("Sample Mean")
    ax.set_ylabel("Frequency")

plt.tight_layout()
plt.show()
```

표본 크기가 증가하면 표본평균의 분포가 점차 종 모양의 정규분포에 가까워지는 경향을 확인할 수 있다.  
이러한 현상을 설명하는 개념이 **중심극한정리(Central Limit Theorem)** 다.  
중심극한정리에 따르면 일정한 조건에서 표본 크기가 충분히 커질수록 표본평균의 분포는 정규분포에 가까워진다.  
여기서 중요한 것은 모집단 자체가 정규분포일 필요는 없다는 점이다.

다만 표본 크기가 커지면 무조건 정규분포가 된다는 의미는 아니다.

- 표본이 독립적이고 적절하게 추출되어야 한다.
- 모집단의 분산이 유한해야 한다.
- 모집단의 분포가 심하게 치우쳐 있다면 더 큰 표본이 필요할 수 있다.

중심극한정리는 표본평균의 분포를 이해하고, 이후 신뢰구간이나 가설검정 같은 통계적 추론을 활용하는 데 중요한 기초가 된다.

</details>

## 정리

<details open>
<summary>⋯</summary>

| 확인할 내용 | 핵심 개념 |
|---|---|
| 여러 표본에서 계산한 통계량의 분포 | 표본분포 |
| 표본분포의 표준편차 | 표준오차 |
| 표본 크기와 평균의 변동성 | 표준오차의 변화 |
| 표본평균 분포의 정규분포 근사 | 중심극한정리 |

핵심은 **표본에서 계산한 값 하나만 보는 것이 아니라, 여러 표본에서 계산한 값들이 얼마나 달라지는지 이해하는 것**이다.  
표본분포와 표준오차를 이해하면 표본으로 추정한 값이 얼마나 불확실한지 판단할 수 있는 기초가 생긴다.

> 통계에서는 표본평균의 흔들림을 이해하고, 그 변동성을 고려해 모집단의 특징을 추정한다.

</details>
