# 하나의 모집단에서 여러 표본을 뽑으면 결과는 항상 같을까?

모집단에서 표본을 추출하면 전체 데이터를 조사하지 않고도 모집단의 특징을 추정할 수 있다.

그런데 같은 모집단에서 표본을 다시 추출하면 어떨까?  
매번 선택되는 데이터가 다르기 때문에 표본에서 계산한 평균이나 비율도 달라질 수 있다.

이번에는 동일한 모집단에서 여러 표본을 추출하면서 **표본에 따라 결과가 얼마나 달라지는지, 그 차이가 왜 발생하는지** 살펴본다.

---

## 질문

- 같은 모집단에서 표본을 다시 뽑으면 결과가 같을까?
- 표본마다 계산한 값은 얼마나 달라질까?
- 표본 크기가 달라지면 결과의 흔들림도 달라질까?
- 표본마다 다른 결과를 어떻게 이해해야 할까?

---

## 데이터

한 쇼핑몰의 고객 100명을 모집단으로 가정하고, 고객 만족도를 조사한다고 해보자.

```python
import pandas as pd
import numpy as np

population = pd.Series(
    [1] * 10 +
    [2] * 15 +
    [3] * 30 +
    [4] * 30 +
    [5] * 15,
    name="satisfaction"
)

population
```

모집단의 만족도 분포를 확인해보자.

```python
population.value_counts().sort_index()
```

| 만족도 | 고객 수 |
|---:|---:|
| 1 | 10 |
| 2 | 15 |
| 3 | 30 |
| 4 | 30 |
| 5 | 15 |
| **합계** | **100** |

모집단의 실제 평균은 3.25점이다.

```python
population.mean()
```

## 1. 같은 모집단에서 표본을 다시 뽑으면 결과가 같을까?

<details>
<summary>⋯</summary>

이번에는 모집단 전체를 알고 있다는 가정하에 여러 표본을 추출하고, 표본에서 계산한 평균이 어떻게 달라지는지 살펴본다.

같은 모집단에서 각각 10명의 고객을 무작위로 선택해보자.  
두 표본은 같은 모집단에서 추출했지만 선택된 고객과 만족도 구성은 서로 다를 수 있다.

```python
sample_a = population.sample(
    n=10,
    random_state=1
)

sample_b = population.sample(
    n=10,
    random_state=2
)

samples = pd.DataFrame({
    "sample_A": sample_a.reset_index(drop=True),
    "sample_B": sample_b.reset_index(drop=True)
})

samples
```

표본별 평균도 비교해보자.

```python
samples.mean()
```

표본 구성에 따라 통계량이 다르게 나타나는 현상을 **표본 변동성(Sampling Variability)** 이라고 한다.

</details>

## 2. 표본마다 계산한 값은 얼마나 달라질까?

<details>
<summary>⋯</summary>

표본 몇 개를 비교해보면 표본에 따라 결과가 달라진다는 사실을 알 수 있다.

그렇다면 여러 번 표본을 추출하면 어떨까?  
동일한 모집단에서 10명씩 1,000번 추출하고, 매번 평균을 계산해보자.

```python
values = population.to_numpy()

rng = np.random.default_rng(42)

sample_means = [
    rng.choice(
        values,
        size=10,
        replace=False
    ).mean()
    for _ in range(1000)
]

sample_results = pd.DataFrame({
    "sample_mean": sample_means
})

sample_results.head()
```

각 표본에서 계산한 평균을 분포로 살펴보자.

```python
import matplotlib.pyplot as plt

plt.hist(
    sample_results["sample_mean"],
    bins=20,
    edgecolor="black"
)

plt.axvline(
    population.mean(),
    linestyle="--",
    label="Population Mean"
)

plt.xlabel("Sample Mean")
plt.ylabel("Frequency")
plt.title("Distribution of Sample Means")
plt.legend()

plt.show()
```

그래프에서는 표본 평균이 여러 값으로 나타나는 것을 확인할 수 있다.  
일부 표본은 모집단 평균인 3.25보다 높고, 다른 표본은 낮게 나타난다.

하지만 여러 표본의 평균을 살펴보면 모집단 평균 주변에 모이는 경향을 볼 수 있다.  
즉, 개별 표본의 결과는 서로 다르지만 무작위 표본 추출을 반복하면 전체적으로 일정한 경향이 나타난다.

**표본 하나의 결과만으로 전체의 특징을 판단하기 어려운 이유가 여기에 있다.**

</details>

## 3. 표본 크기가 달라지면 결과의 흔들림도 달라질까?

<details>
<summary>⋯</summary>

이번에는 표본에 포함되는 고객 수를 다르게 설정해보자.  
5명, 10명, 30명을 각각 표본으로 추출하고, 각 표본의 평균을 1,000번씩 계산해본다.

```python
def simulate_sample_means(sample_size, repetitions=1000):
    rng = np.random.default_rng(42)

    return [
        rng.choice(
            values,
            size=sample_size,
            replace=False
        ).mean()
        for _ in range(repetitions)
    ]


simulation_results = pd.DataFrame({
    "5명": simulate_sample_means(5),
    "10명": simulate_sample_means(10),
    "30명": simulate_sample_means(30)
})

simulation_results.head()
```

표본 크기에 따른 결과의 차이를 상자그림으로 비교해보자.

```python
simulation_results.boxplot()

plt.axhline(
    population.mean(),
    linestyle="--",
    label="Population Mean"
)

plt.ylabel("Sample Mean")
plt.title("Sample Mean by Sample Size")
plt.legend()

plt.show()
```

그래프를 비교하면 표본 크기에 따라 표본 평균이 퍼져 있는 정도가 달라지는 것을 확인할 수 있다.  
일반적으로 표본 크기가 커질수록 표본 평균은 모집단 평균 주변에 더 안정적으로 모이는 경향이 있다.  
그 이유는 표본에 포함되는 데이터가 많아질수록 일부 값의 영향이 상대적으로 줄어들기 때문이다.

다만 표본 크기가 커졌다고 해서 모든 표본의 평균이 반드시 모집단 평균에 더 가까워지는 것은 아니다.  
**개별 표본의 결과가 아니라 여러 번 추출했을 때 나타나는 결과의 변동성을 비교해야 한다.**

</details>

## 4. 표본마다 다른 결과를 어떻게 이해해야 할까?

<details>
<summary>⋯</summary>

같은 모집단에서 표본을 반복해서 추출하더라도 결과가 매번 똑같지는 않다.  
이것은 반드시 표본 추출에 문제가 있다는 뜻은 아니다.  
무작위로 표본을 추출한다면 자연스럽게 발생할 수 있는 차이다.

이때 중요한 것은 두 가지를 구분하는 것이다.

**표본 변동성**

- 같은 모집단에서도 표본에 따라 결과가 달라질 수 있다.
- 표본 크기가 커지면 일반적으로 결과의 변동성이 줄어든다.
- 무작위 표본 추출 과정에서 자연스럽게 발생한다.

**표본 추출 편향**

- 특정 그룹이나 조건에 데이터가 치우쳐 선택되는 문제다.
- 표본의 구성이 모집단을 제대로 반영하지 못할 수 있다.
- 표본 크기를 늘리는 것만으로 해결되지 않는다.

결과가 달라지는 이유가 무작위 표본 추출에 따른 자연스러운 변동인지, 표본을 선택하는 과정에서 발생한 편향인지 구분해야 한다.  
다음으로는 여러 표본에서 계산한 값들의 분포와, 이를 통해 표본 결과의 불확실성을 어떻게 이해할 수 있는지 살펴볼 필요가 있다.

</details>
