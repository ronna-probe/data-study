# 두 그룹의 차이는 어떻게 검증할까?

데이터를 분석하다 보면 두 그룹 사이에 차이가 있는지 궁금해지는 경우가 많다.  
예를 들어 온라인 고객과 오프라인 고객의 만족도가 다른지, 마케팅 캠페인 A와 B의 구매 전환율에 차이가 있는지 비교할 수 있다.

하지만 한 그룹의 평균이나 비율이 더 높게 나타났다고 해서 실제로 두 그룹에 차이가 있다고 단정할 수는 없다.  
표본을 추출하는 과정에서 자연스럽게 발생한 변동일 수도 있기 때문이다.

> 두 그룹에서 관찰한 차이가 우연한 변동으로 설명될 수 있을까?

이번에는 비교하려는 데이터의 형태와 그룹의 관계에 따라 적절한 검정 방법을 선택하고,  
**두 그룹 사이의 차이를 통계적으로 검증하는 방법**을 살펴본다.

---

## 질문

- 비교하려는 두 그룹은 서로 독립적일까, 같은 대상일까?
- 두 그룹의 평균 차이가 우연한 변동으로 설명될까?
- 같은 대상의 전후 차이는 어떻게 검증할까?
- 평균이 아니라 비율을 비교한다면 어떤 방법을 사용할까?

## 1. 비교하려는 두 그룹은 서로 독립적일까, 같은 대상일까?

<details>
<summary>⋯</summary>

두 그룹을 비교하기 전에 먼저 확인해야 할 것이 있다.  
바로 두 그룹에 포함된 데이터가 서로 어떤 관계인지 파악하는 것이다.

### 독립적인 두 그룹

서로 다른 대상들로 구성된 그룹을 비교하는 경우다.  
예를 들어 캠페인 A에 참여한 고객과 캠페인 B에 참여한 고객이 서로 다른 사람이라면 독립적인 두 그룹이다.

- 온라인 고객과 오프라인 고객
- 캠페인 A 참여자와 캠페인 B 참여자
- 남성 고객과 여성 고객

이처럼 각 그룹의 관측값이 서로 독립적이라면 독립표본 비교를 고려할 수 있다.

### 대응되는 두 그룹

같은 대상을 두 번 측정하거나, 서로 짝지어진 대상을 비교하는 경우다.  
예를 들어 같은 고객의 캠페인 참여 전후 만족도를 비교한다면 대응되는 데이터다.

- 교육 전과 교육 후의 점수
- 프로모션 적용 전과 적용 후의 구매 금액
- 동일 고객의 개선 전후 만족도

이때는 각 대상의 변화량을 기준으로 비교한다.

## 2. 두 그룹의 평균 차이가 우연한 변동으로 설명될까?

<details>
<summary>⋯</summary>

두 그룹이 서로 다른 대상들로 구성되어 있고, 비교하려는 값이 수치형 데이터라면 평균 차이를 검증할 수 있다.

먼저 각 그룹의 평균을 확인해보자.

```python
customers.groupby("campaign")["satisfaction"].agg(
    ["count", "mean", "std"]
)
```

이번 데이터에서는 B 캠페인의 평균 만족도가 A 캠페인보다 높게 나타난다.  
하지만 평균이 높다는 사실만으로 두 그룹에 통계적으로 유의한 차이가 있다고 판단할 수는 없다.  
이때 사용하는 방법 중 하나가 **독립표본 t-test(Independent Samples t-test)** 다.

먼저 두 가지 가설을 설정한다.  

- **귀무가설**: 두 그룹의 모집단 평균은 같다.  
- **대립가설**: 두 그룹의 모집단 평균은 다르다.

이제 scipy의 `ttest_ind()`를 이용해 검정해보자.

```python
group_a = customers.loc[
    customers["campaign"] == "A",
    "satisfaction"
]

group_b = customers.loc[
    customers["campaign"] == "B",
    "satisfaction"
]

result = stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False,
    alternative="two-sided"
)

result
```

여기서 `equal_var=False`는 두 그룹의 분산이 같다고 가정하지 않는 Welch의 t-test를 적용한다는 의미다.  
Welch의 t-test는 두 그룹의 분산이 서로 다를 수 있는 상황에서도 평균 차이를 검정할 수 있어 독립된 두 그룹의 평균을 비교할 때 유용하다.

검정 결과에서 p-value를 확인해보자.

```python
result.pvalue
```

유의수준을 0.05로 설정하면 다음과 같이 판단할 수 있다.

```python
alpha = 0.05

if result.pvalue < alpha:
    print("두 그룹의 평균에 통계적으로 유의한 차이가 있다.")
else:
    print("두 그룹의 평균에 통계적으로 유의한 차이가 있다고 보기 어렵다.")
```

p-value가 유의수준보다 작다면 귀무가설을 기각한다.  
이는 두 그룹의 평균이 다르다는 통계적 근거를 확보했다는 의미다.

다만 평균 차이의 원인이 캠페인 때문이라고 결론 내릴 수는 없다.  
캠페인의 인과효과를 판단하려면 실험 설계와 다른 영향 요인도 고려해야 한다.

</details>

## 3. 같은 대상의 전후 차이는 어떻게 검증할까?

<details>
<summary>⋯</summary>

같은 고객의 캠페인 참여 전후 만족도를 비교한다고 생각해보자.

이 경우 두 그룹은 서로 독립적이지 않다.  
동일한 고객에게서 두 번 측정한 값이므로 각 고객의 전후 차이를 함께 고려해야 한다.  
이때 사용하는 방법이 **대응표본 t-test(Paired Samples t-test)** 다.

간단한 데이터를 만들어보자.

```python
before = pd.Series(
    [50, 55, 48, 60, 52, 57, 54, 51, 56, 53]
)

after = pd.Series(
    [53, 59, 50, 65, 55, 61, 56, 54, 60, 56]
)

paired_data = pd.DataFrame({
    "before": before,
    "after": after
})

paired_data
```

먼저 고객별 변화량을 확인한다.

```python
paired_data["difference"] = (
    paired_data["after"] -
    paired_data["before"]
)

paired_data
```

그다음 대응표본 t-test를 적용한다.

```python
result_paired = stats.ttest_rel(
    paired_data["after"],
    paired_data["before"]
)

result_paired
```

대응표본 t-test는 두 그룹의 평균을 각각 독립적으로 비교하는 것이 아니라, **각 대상에서 계산한 차이의 평균이 0과 다른지** 검증한다.  
따라서 같은 대상의 전후 변화처럼 데이터 간 연결 관계가 있는 경우에 적합하다.

다만 실제 분석에서는 두 측정값 자체보다 고객별 차이값의 분포와 이상치를 확인하는 것이 중요하다.

</details>

## 4. 평균이 아니라 비율을 비교한다면 어떤 방법을 사용할까?

<details>
<summary>⋯</summary>

모든 분석이 평균 비교인 것은 아니다.  
예를 들어 캠페인 A와 B의 구매 전환율을 비교한다면 평균보다 **구매한 고객의 비율**이 중요하다.

다음과 같은 데이터가 있다고 가정해보자.

| 캠페인 | 방문자 | 구매자 | 구매 비율 |
|---|---:|---:|---:|
| A | 50 | 15 | 30% |
| B | 50 | 25 | 50% |

이 경우 두 캠페인의 구매 비율이 서로 다른지 검증해야 한다.  
이처럼 범주형 데이터 간의 관계를 검증할 때는 **카이제곱 검정(Chi-square Test)** 을 사용할 수 있다.

먼저 구매 여부별 데이터를 구성한다.

```python
conversion = pd.DataFrame(
    {
        "구매": [15, 25],
        "미구매": [35, 25]
    },
    index=["A", "B"]
)

conversion
```

이제 카이제곱 독립성 검정을 적용해보자.  
카이제곱 검정은 캠페인 그룹과 구매 여부가 서로 독립적인지 확인한다.

```python
chi2, p_value, dof, expected = (
    stats.chi2_contingency(conversion)
)

print("카이제곱 통계량:", chi2)
print("p-value:", p_value)
```

이번 사례에서는 다음과 같은 가설을 검증한다.

- 귀무가설: 캠페인 종류와 구매 여부는 독립적이다.
- 대립가설: 캠페인 종류와 구매 여부는 독립적이지 않다.

p-value가 유의수준보다 작다면 두 변수 사이에 통계적으로 유의한 관계가 있다고 판단할 수 있다.  
즉, 두 캠페인의 구매 비율이 같다고 보기 어렵다는 통계적 근거가 생긴다.

</details>

## 정리

<details open>
<summary>⋯</summary>

| 비교 상황 | 검정 방법 |
|---|---|
| 독립적인 두 그룹의 평균 | Welch의 독립표본 t-test |
| 동일 대상의 전후 평균 | 대응표본 t-test |
| 두 그룹의 구매 비율 등 범주형 비율 | 카이제곱 독립성 검정 |

> 통계에서는 분석 질문과 데이터 구조에 맞는 검정 방법을 선택해 관찰한 차이가 우연한 변동만으로 설명될 수 있는지 평가한다.

</details>
