# 통계적으로 유의한 차이는 실제로도 의미 있는 차이일까?

통계 분석을 하다 보면 p-value가 유의수준보다 작다는 결과를 자주 접하게 된다.  
그렇다면 통계적으로 유의한 차이가 발견되었다면 실제로도 중요한 차이라고 볼 수 있을까?

예를 들어 A 캠페인의 구매 전환율이 10%, B 캠페인의 구매 전환율이 11%라고 가정해보자.  
두 캠페인의 차이가 통계적으로 유의하더라도, 실제 사업 성과에 영향을 줄 만큼 큰 차이인지는 별도로 판단해야 한다.

이번에는 관찰한 차이의 크기와 표본 크기, 불확실성, 실제 사업적 영향을 함께 살펴보면서 **효과 크기와 실질적 중요성**을 이해해본다.

---

## 질문

- 관찰한 차이의 크기는 얼마나 될까?
- 표본 크기가 커지면 통계적 유의성도 달라질까?
- 추정한 차이는 얼마나 불확실할까?
- 통계적으로 유의한 결과가 실제로도 중요한지는 어떻게 판단할까?

---

## 데이터

두 캠페인의 구매 전환율을 비교한다고 가정해보자.

```python
import pandas as pd
import numpy as np
from scipy import stats

campaigns = pd.DataFrame({
    "campaign": ["A", "B"],
    "visitors": [100000, 100000],
    "purchases": [10000, 11000]
})

campaigns
```

| campaign | visitors | purchases |
|---|---:|---:|
| A | 100,000 | 10,000 |
| B | 100,000 | 11,000 |

## 1. 관찰한 차이의 크기는 얼마나 될까?

<details>
<summary>⋯</summary>

먼저 캠페인별 구매 전환율을 계산해보자.

```python
campaigns["purchase_rate"] = (
    campaigns["purchases"]
    / campaigns["visitors"]
)

campaigns[["campaign", "purchase_rate"]]
```

| 캠페인 | 구매 전환율 |
|---|---:|
| A | 10% |
| B | 11% |

B 캠페인의 구매 전환율이 A 캠페인보다 1%p 높다.

```python
rate_a = campaigns.loc[
    campaigns["campaign"] == "A",
    "purchase_rate"
].iloc[0]

rate_b = campaigns.loc[
    campaigns["campaign"] == "B",
    "purchase_rate"
].iloc[0]

absolute_difference = rate_b - rate_a

relative_lift = (
    (rate_b / rate_a) - 1
) * 100

print("전환율 차이:", absolute_difference * 100, "%p")
print("상대적 증가율:", relative_lift, "%")
```

같은 결과라도 어떤 기준으로 표현하느냐에 따라 차이를 이해하는 방식이 달라진다.  
이처럼 실제로 관찰된 차이의 크기를 나타내는 개념을 **효과 크기(Effect Size)** 라고 한다.

효과 크기는 분석 대상에 따라 여러 방식으로 표현할 수 있다.

| 비교 대상 | 효과 크기의 예 |
|---|---|
| 두 그룹의 평균 | 평균 차이 |
| 두 그룹의 구매 비율 | 비율 차이, 상대적 증가율 |
| 두 변수의 관계 | 상관계수 |

통계적으로 유의한지 확인하는 것뿐 아니라 실제로 얼마나 차이가 나는지도 함께 확인해야 한다.

</details>

## 2. 표본 크기가 커지면 통계적 유의성도 달라질까?

<details>
<summary>⋯</summary>

같은 1%p 차이라도 표본 크기에 따라 통계적 검정 결과는 달라질 수 있다.  
두 가지 상황을 비교해보자.

**상황 A: 방문자가 많은 경우**

| 캠페인 | 방문자 | 구매자 | 전환율 |
|---|---:|---:|---:|
| A | 100,000 | 10,000 | 10% |
| B | 100,000 | 11,000 | 11% |

**상황 B: 방문자가 적은 경우**

| 캠페인 | 방문자 | 구매자 | 전환율 |
|---|---:|---:|---:|
| A | 1,000 | 100 | 10% |
| B | 1,000 | 110 | 11% |

두 상황 모두 전환율 차이는 1%p로 동일하다.  
하지만 표본 크기는 서로 다르다.

두 상황에서 카이제곱 검정을 적용해보자.

```python
large_sample = pd.DataFrame(
    {
        "구매": [10000, 11000],
        "미구매": [90000, 89000]
    },
    index=["A", "B"]
)

small_sample = pd.DataFrame(
    {
        "구매": [100, 110],
        "미구매": [900, 890]
    },
    index=["A", "B"]
)

large_p = stats.chi2_contingency(
    large_sample,
    correction=False
).pvalue

small_p = stats.chi2_contingency(
    small_sample,
    correction=False
).pvalue

pd.DataFrame({
    "표본 크기": [200000, 2000],
    "전환율 차이": ["1%p", "1%p"],
    "p-value": [large_p, small_p]
}, index=["방문자가 많은 경우", "방문자가 적은 경우"])
```

두 상황 모두 관찰한 전환율 차이는 같지만 p-value는 달라진다.  
방문자가 많은 경우에는 작은 차이도 통계적으로 유의하게 나타날 수 있다.

반면 방문자가 적은 경우에는 동일한 차이가 관찰되어도 통계적으로 유의하다고 판단하기 어려울 수 있다.  
그 이유는 표본 크기가 커질수록 일반적으로 추정의 불확실성이 작아지기 때문이다.

따라서 다음 두 가지는 구분해야 한다.

- **통계적 유의성:** 관찰한 결과가 귀무가설 아래에서 얼마나 이례적인가?
- **효과 크기:** 실제로 관찰한 차이는 얼마나 큰가?

표본 크기가 크면 작은 차이도 통계적으로 유의할 수 있다.  
반대로 실제로 큰 차이가 있더라도 표본이 적으면 유의한 결과를 발견하지 못할 수 있다.

</details>

## 3. 추정한 차이는 얼마나 불확실할까?

<details>
<summary>⋯</summary>

관찰한 차이의 크기를 확인했다면, 그 차이를 얼마나 신뢰할 수 있는지도 살펴봐야 한다.  
앞에서 배운 신뢰구간을 활용하면 두 그룹의 전환율 차이에 대한 불확실성을 범위로 표현할 수 있다.

두 비율의 차이는 다음과 같이 계산한다.

Δp = p̂_B - p̂_A

두 비율 차이의 표준오차는 다음과 같이 근사할 수 있다.

SE  
= √(A 집단의 분산 + B 집단의 분산)  
= √[ p̂_A(1 - p̂_A)/n_A + p̂_B(1 - p̂_B)/n_B ]

이를 이용해 95% 신뢰구간을 계산해보자.

```python
n_a = 100000
n_b = 100000

difference = rate_b - rate_a

standard_error = np.sqrt(
    rate_a * (1 - rate_a) / n_a
    +
    rate_b * (1 - rate_b) / n_b
)

z_value = stats.norm.ppf(0.975)

lower = difference - z_value * standard_error
upper = difference + z_value * standard_error

print("전환율 차이:", difference * 100, "%p")
print("95% 신뢰구간:", lower * 100, "%p ~", upper * 100, "%p")
```

이번 데이터에서는 전환율 차이가 1%p이고, 95% 신뢰구간은 약 0.73%p에서 1.27%p로 나타난다.  
이 결과는 같은 방식으로 표본을 반복 추출해 신뢰구간을 계산한다면, 그렇게 만들어진 구간 중 약 95%가 실제 모집단의 전환율 차이를 포함한다는 의미다.

신뢰구간을 함께 살펴보면 다음을 알 수 있다.

- 실제 차이가 어느 정도 범위에 있을 것으로 추정되는가?
- 차이의 방향이 일관적인가?
- 추정 결과의 불확실성은 어느 정도인가?

다만 신뢰구간이 좁다고 해서 그 차이가 반드시 실무적으로 중요한 것은 아니다.  
**추정의 불확실성과 실제 차이의 중요성은 별도로 판단해야 한다.**

</details>

## 4. 통계적으로 유의한 결과가 실제로도 중요한지는 어떻게 판단할까?

<details>
<summary>⋯</summary>

통계적으로 유의한 차이가 발견되었다면 마지막으로 실제 업무에 어떤 영향을 주는지 살펴봐야 한다.  
이번 데이터에서는 B 캠페인의 구매 전환율이 A 캠페인보다 1%p 높다.

방문자가 각각 100,000명이라면 추가 구매 건수는 다음과 같이 계산할 수 있다.

```python
extra_purchases = (
    campaigns.loc[1, "visitors"]
    * absolute_difference
)

extra_purchases
```

B 캠페인이 A 캠페인보다 약 1,000건의 구매를 추가로 확보한 셈이다.  
그렇다면 이 결과는 실제로도 중요한 성과일까?

예를 들어 다음과 같은 조건을 가정해보자.

- 추가 구매 1건당 기여이익: 2,000원
- B 캠페인의 추가 비용: 3,000,000원
- 추가 구매 건수: 1,000건

추가 구매로 발생하는 기여이익과 캠페인 추가 비용을 비교해보자.

```python
contribution_per_purchase = 2000
additional_campaign_cost = 3000000

additional_contribution = (
    extra_purchases * contribution_per_purchase
)

net_benefit = (
    additional_contribution
    - additional_campaign_cost
)

print("추가 기여이익:", additional_contribution)
print("추가 캠페인 비용:", additional_campaign_cost)
print("추가 순기여:", net_benefit)
```

이번 가정에서는 추가 기여이익이 200만 원이고, 추가 캠페인 비용이 300만 원이므로 추가 순기여는 -100만 원이다.  
즉, B 캠페인의 전환율이 통계적으로 유의하게 높더라도 추가 비용까지 고려하면 사업적으로 유리하지 않을 수 있다.  
물론 실제 의사결정에서는 고객의 장기 구매 가치, 추가 운영 비용, 재구매율 등도 함께 고려해야 한다.  

결국 실질적 중요성은 분석 결과만으로 결정되는 것이 아니다.  
다음과 같은 질문을 함께 검토해야 한다.

- 관찰한 차이가 실제로 얼마나 큰가?
- 그 차이로 추가적인 매출이나 이익이 얼마나 발생하는가?
- 추가로 발생하는 비용보다 효과가 큰가?
- 분석 결과가 실제 의사결정에 영향을 줄 만큼 중요한가?

**통계적 유의성은 판단의 근거 중 하나이고, 최종적인 의사결정에는 실질적인 효과와 비용도 필요하다.**

</details>

## 정리

<details open>
<summary>⋯</summary>

| 확인할 내용 | 핵심 개념 |
|---|---|
| 관찰한 차이의 크기 | 효과 크기(Effect Size) |
| 표본 크기와 유의성 | 표본 크기와 검정력 |
| 추정값의 불확실성 | 신뢰구간 |
| 실제 업무에 미치는 영향 | 실질적 중요성 |
| 비용과 효과 비교 | 비용 대비 효과 |

핵심은 **통계적으로 유의하다는 사실과 실제로 중요한 결과라는 판단을 구분하는 것**이다.  
p-value가 작다고 해서 반드시 큰 효과가 있는 것은 아니며, 반대로 p-value가 크다고 해서 실제 효과가 전혀 없는 것도 아니다.

따라서 효과 크기와 불확실성, 실제 사업적 영향을 함께 고려해야 한다.

> 통계 분석의 목적은 유의한 결과를 찾는 데서 끝나는 것이 아니라, 그 결과가 실제 의사결정에 어떤 의미를 가지는지 이해하는 것이다.

</details>
