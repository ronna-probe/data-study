# 어떤 값이 유난히 많거나 적을까?

범주형 데이터를 살펴볼 때 모든 값이 비슷한 비율로 나타나는 것은 아니다.  
특정 값이 대부분을 차지할 수도 있고, 거의 나타나지 않는 값도 있을 수 있다.

---

## 질문

> 어떤 값이 유난히 많거나 적다면, 데이터에는 어떤 특징이 있는 걸까?

- 어떤 값이 가장 많이 나타날까?
- 값마다 등장 비율은 어떨까?
- 거의 나타나지 않는 값도 있을까?
- 특정 값에 데이터가 지나치게 몰려 있지는 않을까?

---

## 데이터

```python
import pandas as pd

orders = pd.DataFrame({
    "order_id": range(1, 16),
    "product": [
        "A", "A", "A", "A", "A",
        "B", "B", "B",
        "C", "C",
        "D",
        "E",
        "E",
        "E",
        "E"
    ]
})

orders
```

---

## 1. 어떤 값이 가장 많이 나타날까?

<details>
<summary>⋯</summary>

범주형 데이터에서는 먼저 각 값이 몇 번씩 나타나는지 확인할 수 있다.  
pandas의 `value_counts()`를 사용하면 값별 빈도를 쉽게 확인할 수 있다.

```python
orders["product"].value_counts()
```

결과는 다음과 같다.

```text
A    5
B    3
C    2
D    1
E    4
```

`A`가 가장 많이 나타나고 `D`가 가장 적게 나타난다.

</details>

---

## 2. 값마다 등장 비율은 어떨까?

<details>
<summary>⋯</summary>

각 값이 전체 데이터에서 차지하는 비율을 계산해보자.

```python
product_count = orders["product"].value_counts()

product_ratio = (
    product_count
    / len(orders)
    * 100
)

product_ratio
```

결과를 함께 보면 각 상품의 빈도와 비율을 비교할 수 있다.

```python
product_summary = pd.DataFrame({
    "count": product_count,
    "ratio": product_ratio
})

product_summary
```

`A`는 전체 주문의 약 33%를 차지하고, `D`는 약 7%에 불과하다.

</details>

---

## 3. 거의 나타나지 않는 값도 있을까?

<details>
<summary>⋯</summary>

빈도가 낮은 값을 찾아보면 데이터에서 거의 사용되지 않는 범주를 확인할 수 있다.

```python
product_count[product_count <= 2]
```

결과:

```text
C    2
D    1
```

`C`와 `D`는 전체 데이터에서 차지하는 비중이 작다.

이런 값이 있다고 해서 반드시 잘못된 데이터라는 의미는 아니다.  
예를 들어 특정 상품이 실제로 많이 판매되지 않았을 수도 있다.

</details>

---

## 4. 특정 값에 데이터가 지나치게 몰려 있지는 않을까?

<details>
<summary>⋯</summary>

이번에는 빈도 분포를 그래프로 확인해보자.

```python
import matplotlib.pyplot as plt

product_count.plot(kind="bar")

plt.xlabel("product")
plt.ylabel("count")
plt.title("Order Count by Product")

plt.show()
```

</details>

## 정리

<details open>
<summary>⋯</summary>

| 확인할 내용 | pandas |
|---|---|
| 값별 개수 | `value_counts()` |
| 값별 비율 | `value_counts()` + 전체 개수 |
| 적게 나타나는 값 확인 | 조건식으로 필터링 |
| 빈도 시각화 | `plot(kind="bar")` |

특정 값에 데이터가 지나치게 몰려 있거나 일부 값의 빈도가 매우 낮다면, 이후 분석에서도 그 특성을 고려해야 한다.  
하지만 빈도가 많거나 적다는 사실만으로 **좋은 데이터인지 나쁜 데이터인지 판단할 수는 없다.**

</details>
