# 다른 행을 함께 보려면 어떻게 할까요?

데이터를 한 행씩 따로 보면 해당 값만 알 수 있다.

하지만 분석에서는 현재 값만 보는 것보다 이전 값이나 다음 값과 비교하거나,  
주변의 여러 값을 함께 계산하는 경우가 있다.

이전 값과 다음 값을 함께 보거나 일정한 범위의 값을 함께 계산하면  
현재 값만으로는 보이지 않던 **변화와 흐름**을 확인할 수 있다.

---

## 질문

> 현재 값을 기준으로 주변의 값을 함께 보려면 어떻게 할까?

- 이전 값과 다음 값을 어떻게 가져올까?
- 그룹별로 이전 값과 다음 값을 가져오려면 어떻게 할까?
- 일정한 범위의 값이나 지금까지의 값을 함께 계산하려면 어떻게 할까?

## 1. 이전 값과 다음 값을 함께 보려면?

<details>
<summary>⋯</summary>

현재 행을 기준으로 이전 값이나 다음 값을 가져올 수 있다.

예를 들어 일별 매출을 분석한다면 현재 매출과 전날 매출을 함께 확인하거나,  
현재 매출과 다음 날 매출을 함께 확인할 수 있다.

### SQL

```sql
SELECT
    date,
    category,
    amount,
    LAG(amount) OVER (
        PARTITION BY category
        ORDER BY date
    ) AS previous_amount,
    LEAD(amount) OVER (
        PARTITION BY category
        ORDER BY date
    ) AS next_amount
FROM sales
ORDER BY
    category,
    date;
```

### pandas

```python
sales = sales.sort_values(
    ["category", "date"]
)

sales["previous_amount"] = (
    sales
    .groupby("category")["amount"]
    .shift(1)
)

sales["next_amount"] = (
    sales
    .groupby("category")["amount"]
    .shift(-1)
)
```

결과는 다음과 같다.

| date | category | amount | previous_amount | next_amount |
|---|---|---:|---:|---:|
| 2024-01-01 | A | 10000 | NULL | 15000 |
| 2024-01-02 | A | 15000 | 10000 | 12000 |
| 2024-01-03 | A | 12000 | 15000 | 18000 |
| 2024-01-04 | A | 18000 | 12000 | 16000 |
| 2024-01-05 | A | 16000 | 18000 | NULL |
| 2024-01-01 | B | 20000 | NULL | 18000 |
| 2024-01-02 | B | 18000 | 20000 | 22000 |
| 2024-01-03 | B | 22000 | 18000 | 25000 |
| 2024-01-04 | B | 25000 | 22000 | 21000 |
| 2024-01-05 | B | 21000 | 25000 | NULL |

첫 번째 행에는 이전 값이 없고, 마지막 행에는 다음 값이 없기 때문에 `NULL`이 된다.

또한 `category`별로 데이터를 나누었기 때문에 A의 값과 B의 값이 서로 이전 값이나 다음 값으로 섞이지 않는다.

즉, 이전 값과 다음 값을 가져올 때는 **어떤 순서로 비교할지, 어떤 범위 안에서 비교할지** 함께 정해야 한다.

</details>

## 2. 일정한 범위의 값을 함께 계산하려면?

<details>
<summary>⋯</summary>

이전 값 하나만 보는 것이 아니라 **현재 값을 포함한 최근 몇 개의 값**을 함께 계산할 수도 있다.

예를 들어 카테고리별 최근 3일 평균 매출을 구하면 일별 변동을 줄이고 전체적인 흐름을 볼 수 있다.

### SQL

```sql
SELECT
    date,
    category,
    amount,
    AVG(amount) OVER (
        PARTITION BY category
        ORDER BY date
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    ) AS rolling_avg
FROM sales
ORDER BY
    category,
    date;
```

### pandas

```python
sales = sales.sort_values(
    ["category", "date"]
)

sales["rolling_avg"] = (
    sales
    .groupby("category")["amount"]
    .rolling(3)
    .mean()
    .reset_index(level=0, drop=True)
)
```

결과는 다음과 같다.

| date | category | amount | rolling_avg |
|---|---|---:|---:|
| 2024-01-01 | A | 10000 | 10000 |
| 2024-01-02 | A | 15000 | 12500 |
| 2024-01-03 | A | 12000 | 12333.33 |
| 2024-01-04 | A | 18000 | 15000 |
| 2024-01-05 | A | 16000 | 15333.33 |
| 2024-01-01 | B | 20000 | 20000 |
| 2024-01-02 | B | 18000 | 19000 |
| 2024-01-03 | B | 22000 | 20000 |
| 2024-01-04 | B | 25000 | 21666.67 |
| 2024-01-05 | B | 21000 | 22666.67 |

`rolling(3)`은 현재 값을 포함해 최근 3개의 값을 하나의 범위로 보고 계산한다.

따라서 `rolling`은 **일정한 크기의 창(window)을 이동시키면서 계산하는 방법**이라고 이해할 수 있다.

</details>

## 3. 지금까지의 값을 누적해서 계산하려면?

<details>
<summary>⋯</summary>

이번에는 최근 3개처럼 일정한 범위를 보는 것이 아니라, **현재 행까지의 모든 값을 누적해서 계산**해보자.

예를 들어 카테고리별 누적 매출을 확인할 수 있다.

### SQL

```sql
SELECT
    date,
    category,
    amount,
    SUM(amount) OVER (
        PARTITION BY category
        ORDER BY date
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS cumulative_amount
FROM sales
ORDER BY
    category,
    date;
```

### pandas

```python
sales = sales.sort_values(
    ["category", "date"]
)

sales["cumulative_amount"] = (
    sales
    .groupby("category")["amount"]
    .expanding()
    .sum()
    .reset_index(level=0, drop=True)
)
```

결과는 다음과 같다.

| date | category | amount | cumulative_amount |
|---|---|---:|---:|
| 2024-01-01 | A | 10000 | 10000 |
| 2024-01-02 | A | 15000 | 25000 |
| 2024-01-03 | A | 12000 | 37000 |
| 2024-01-04 | A | 18000 | 55000 |
| 2024-01-05 | A | 16000 | 71000 |
| 2024-01-01 | B | 20000 | 20000 |
| 2024-01-02 | B | 18000 | 38000 |
| 2024-01-03 | B | 22000 | 60000 |
| 2024-01-04 | B | 25000 | 85000 |
| 2024-01-05 | B | 21000 | 106000 |

`expanding()`은 첫 번째 값부터 현재 행까지의 범위를 계속 확장하면서 계산한다.

따라서 `rolling`과 `expanding`은 둘 다 여러 행을 함께 계산하지만 범위가 다르다.

- `rolling`: **일정한 크기의 범위**를 이동
- `expanding`: **처음부터 현재까지의 범위**를 누적

</details>

## 정리

<details open>
<summary>⋯</summary>

현재 행을 기준으로 다른 값을 함께 보거나 여러 행을 묶어서 계산하면  
데이터의 **변화와 흐름**을 파악할 수 있다.

| 작업 | SQL | pandas |
|---|---|---|
| 이전 값 | `LAG()` | `.shift(1)` |
| 다음 값 | `LEAD()` | `.shift(-1)` |
| 그룹별 이전/다음 값 | `PARTITION BY` + `LAG()` / `LEAD()` | `.groupby().shift()` |
| 이동 계산 | 윈도우 프레임 | `.rolling()` |
| 누적 계산 | 윈도우 프레임 | `.expanding()` |

각 방법은 바라보는 범위가 다르다.

- `LAG()` / `LEAD()` → 특정 위치의 이전·다음 값을 가져온다.
- `rolling()` → 일정한 범위의 값을 함께 계산한다.
- `expanding()` → 처음부터 현재까지의 값을 누적해서 계산한다.

따라서 분석할 때는 **현재 값을 기준으로 어떤 범위의 데이터를 함께 볼 것인지** 먼저 생각해볼 수 있다.

</details>
