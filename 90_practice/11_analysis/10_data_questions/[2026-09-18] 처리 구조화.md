# 분석이 길어졌는데, 지금 과정을 한 번에 해결하는 게 최선일까요?

데이터 분석을 하다 보면 하나의 질문에 답하기 위해 여러 단계의 계산이 필요할 때가 있다.

처음부터 모든 과정을 하나의 쿼리나 코드로 작성하면 결과는 만들 수 있지만,  
**각 단계가 무엇을 의미하는지 파악하기 어려워질 수 있다.**

복잡한 문제를 여러 단계로 나누어 중간 결과를 만들면 각 단계의 결과를 확인하면서 분석 과정을 관리할 수 있다.

---

## 질문

> 여러 단계가 필요한 분석을 어떻게 나누어 풀 수 있을까?

- 복잡한 계산을 어떻게 여러 단계로 나눌까?
- 중간 결과를 만들어서 확인할 수 있을까?
- 여러 단계의 결과를 하나의 흐름으로 연결하려면 어떻게 할까?

## 1. 복잡한 계산을 어떻게 여러 단계로 나눌까?

<details>
<summary>⋯</summary>

예를 들어 **고객별 총 주문 금액을 계산한 뒤, 총 주문 금액이 20000원 이상인 고객만 확인**한다고 생각해보자.

이 문제는 크게 두 단계로 나눌 수 있다.

1. 고객별 주문 금액을 집계한다.
2. 집계한 결과에서 20000원 이상인 고객을 찾는다.

먼저 고객별 주문 금액을 계산할 수 있다.

### SQL

```sql
SELECT
    customer_id,
    SUM(amount) AS total_amount
FROM orders
GROUP BY customer_id;
```

### pandas

```python
customer_amount = (
    orders
    .groupby("customer_id", as_index=False)["amount"]
    .sum()
    .rename(columns={"amount": "total_amount"})
)

customer_amount
```

중간 결과를 확인하면 다음 단계에서 어떤 데이터를 사용하게 되는지 명확해진다.

</details>

## 2. 중간 결과를 만들어서 확인할 수 있을까?

<details>
<summary>⋯</summary>

앞에서 만든 고객별 주문 금액을 다시 사용하면 된다.

### SQL

```sql
WITH customer_amount AS (
    SELECT
        customer_id,
        SUM(amount) AS total_amount
    FROM orders
    GROUP BY customer_id
)

SELECT *
FROM customer_amount
WHERE total_amount >= 20000;
```

`CTE`를 사용하면 앞에서 만든 결과를 하나의 테이블처럼 사용할 수 있다.

### pandas

```python
customer_amount = (
    orders
    .groupby("customer_id", as_index=False)["amount"]
    .sum()
    .rename(columns={"amount": "total_amount"})
)

result = customer_amount[
    customer_amount["total_amount"] >= 20000
]

result
```

복잡한 문제를 한 번에 해결하기보다 **의미 있는 중간 결과를 먼저 만들고 다음 단계에서 사용하는 방식**으로 생각할 수 있다.

</details>

## 3. 여러 단계의 결과를 하나의 흐름으로 연결하려면 어떻게 할까?

<details>
<summary>⋯</summary>

분석 과정이 더 복잡해지면 중간 결과가 여러 개 필요할 수 있다.

예를 들어 다음과 같은 흐름으로 분석할 수 있다.  
**주문 데이터 → 고객별 집계 → 조건 필터링 → 최종 결과**

### SQL

```sql
WITH customer_amount AS (
    SELECT
        customer_id,
        SUM(amount) AS total_amount
    FROM orders
    GROUP BY customer_id
),
high_value_customer AS (
    SELECT
        customer_id,
        total_amount
    FROM customer_amount
    WHERE total_amount >= 20000
)

SELECT *
FROM high_value_customer
ORDER BY total_amount DESC;
```

pandas에서는 각 단계의 결과를 변수에 저장하면서 같은 흐름을 만들 수 있다.

### pandas

```python
customer_amount = (
    orders
    .groupby("customer_id", as_index=False)["amount"]
    .sum()
    .rename(columns={"amount": "total_amount"})
)

high_value_customer = (
    customer_amount[
        customer_amount["total_amount"] >= 20000
    ]
    .sort_values("total_amount", ascending=False)
)

high_value_customer
```

중요한 것은 단계를 많이 만드는 것 자체가 아니라,  
**복잡한 처리 과정을 이해하기 쉬운 단위로 나누어 구성**하는 것이다.

</details>

## 정리

<details open>
<summary>⋯</summary>

| 작업 | SQL | pandas |
|---|---|---|
| 중간 결과 만들기 | `WITH` | 변수에 저장 |
| 중간 결과 활용 | CTE 이름 사용 | DataFrame 사용 |
| 여러 단계 연결 | 여러 CTE | 여러 DataFrame 연산 |
| 단계별 결과 확인 | `SELECT` | DataFrame 확인 |

**복잡한 분석일수록 한 번에 해결하는 것보다, 문제를 이해할 수 있는 단위로 나누는 것이 중요하다.**

</details>
