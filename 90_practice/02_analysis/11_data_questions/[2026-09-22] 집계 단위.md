# 전체 순위와 그룹 안의 순위가 같을까요?

데이터에서 순위를 구할 때는 단순히 값을 정렬하는 것만으로 끝나지 않는다.

**전체 데이터를 기준으로 비교할 것인지, 특정 그룹 안에서 비교할 것인지**에 따라 순위가 달라질 수 있다.  
또한 같은 데이터를 어떤 단위로 집계하느냐에 따라서도 우리가 발견할 수 있는 차이가 달라진다.

---

## 질문

> 데이터를 비교할 때, 어디까지를 하나의 그룹으로 볼 것인가?

- 전체 데이터에서 순위를 어떻게 구할까?
- 그룹 안에서 순위를 매기면 어떻게 달라질까?
- 집계 단위가 달라지면 결과도 달라질까?

---

## 데이터

| product | category | amount |
|---|---|---:|
| A | 가전 | 50000 |
| B | 가전 | 30000 |
| C | 가전 | 20000 |
| D | 식품 | 45000 |
| E | 식품 | 25000 |
| F | 식품 | 10000 |

---

## 1. 전체 데이터에서 순위를 어떻게 구할까?

<details>
<summary>⋯</summary>

먼저 모든 상품을 하나의 기준으로 보고 매출 순위를 구해보자.  
매출이 높은 상품부터 1위를 부여하면 된다.

### SQL

```sql
SELECT
    product,
    category,
    amount,
    RANK() OVER (
        ORDER BY amount DESC
    ) AS overall_rank
FROM products
ORDER BY overall_rank;
```

### pandas

```python
products["overall_rank"] = (
    products["amount"]
    .rank(method="min", ascending=False)
)

products.sort_values("overall_rank")
```

결과는 다음과 같다.

| product | category | amount | overall_rank |
|---|---|---:|---:|
| A | 가전 | 50000 | 1 |
| D | 식품 | 45000 | 2 |
| B | 가전 | 30000 | 3 |
| E | 식품 | 25000 | 4 |
| C | 가전 | 20000 | 5 |
| F | 식품 | 10000 | 6 |

이 경우 모든 상품을 서로 비교하기 때문에 **전체 데이터에서의 순위**를 구하게 된다.

</details>

---

## 2. 그룹 안에서 순위를 매기면 어떻게 달라질까?

<details>
<summary>⋯</summary>

이번에는 전체 상품이 아니라 **카테고리 안에서 상품을 비교**해보자.  
가전 상품끼리 비교하고, 식품 상품끼리 비교하는 것이다.

### SQL

```sql
SELECT
    product,
    category,
    amount,
    RANK() OVER (
        PARTITION BY category
        ORDER BY amount DESC
    ) AS category_rank
FROM products
ORDER BY
    category,
    category_rank;
```

### pandas

```python
products["category_rank"] = (
    products
    .groupby("category")["amount"]
    .rank(method="min", ascending=False)
)

products.sort_values(["category", "category_rank"])
```

결과는 다음과 같다.

| product | category | amount | category_rank |
|---|---|---:|---:|
| A | 가전 | 50000 | 1 |
| B | 가전 | 30000 | 2 |
| C | 가전 | 20000 | 3 |
| D | 식품 | **45000** | 1 |
| E | 식품 | 25000 | 2 |
| F | 식품 | 10000 | 3 |

전체 순위에서는 D가 2위였지만, 식품 안에서는 1위가 된다.  
이처럼 **비교하는 범위를 어떻게 정하는지에 따라 같은 값의 순위가 달라질 수 있다.**

</details>

---

## 3. 집계 단위가 달라지면 결과도 달라질까?

<details>
<summary>⋯</summary>

순위뿐만 아니라 **집계하는 단위 자체가 달라져도 데이터에서 보이는 모습이 달라질 수 있다.**

예를 들어 상품 데이터를 카테고리별로 집계한다고 생각해보자.  
먼저 카테고리별 전체 매출을 확인할 수 있다.

### SQL

```sql
SELECT
    category,
    SUM(amount) AS total_amount
FROM products
GROUP BY category
ORDER BY total_amount DESC;
```

### pandas

```python
products.groupby("category")["amount"].sum()
```

이번에는 같은 데이터를 카테고리 안의 상품별로 나누어 볼 수 있다.

### SQL

```sql
SELECT
    category,
    product,
    SUM(amount) AS total_amount
FROM products
GROUP BY
    category,
    product
ORDER BY
    category,
    total_amount DESC;
```

### pandas

```python
products.groupby(
    ["category", "product"]
)["amount"].sum()
```

첫 번째 결과에서는 **카테고리 간 차이**가 보이고, 두 번째 결과에서는 **카테고리 내 차이**가 보인다.  
즉, 같은 데이터를 사용하더라도 집계 단위를 어떻게 설정하느냐에 따라 확인할 수 있는 정보가 달라진다.

분석에서 어떤 결과를 얻을 것인지는 계산 방법뿐만 아니라 **어떤 단위로 데이터를 묶을 것인지**에 따라서도 결정된다.

</details>

---

## 정리

<details open>
<summary>⋯</summary>

데이터를 비교하거나 순위를 계산할 때는 먼저 **무엇을 서로 비교할 것인지,  
어느 범위까지 하나의 그룹으로 볼 것인지** 정해야 한다.

> **전체 기준 → 그룹 기준 → 집계 단위 확인**

순서로 생각해볼 수 있다.

| 작업 | SQL | pandas |
|---|---|---|
| 전체 순위 | `RANK() OVER (ORDER BY ...)` | `.rank()` |
| 그룹별 순위 | `RANK() OVER (PARTITION BY ... ORDER BY ...)` | `.groupby().rank()` |
| 그룹별 집계 | `GROUP BY` | `.groupby()` |
| 여러 기준으로 그룹화 | `GROUP BY A, B` | `.groupby(["A", "B"])` |

분석할 때는 다음을 확인해보자.

- 전체 데이터를 비교해야 하는가?
- 특정 그룹 안에서만 비교해야 하는가?
- 어떤 기준으로 그룹을 나눌 것인가?
- 어느 수준까지 세분화해서 봐야 하는가?
- 집계 단위가 달라지면 결과의 해석도 달라지지 않는가?

</details>
