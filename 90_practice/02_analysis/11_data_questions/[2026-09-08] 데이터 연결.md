# 이 두 데이터를 정말 이렇게 연결해도 괜찮을까요?

분석을 하다 보면 하나의 데이터만으로는 답하기 어려운 질문이 있다.

판매 데이터에 상품 정보를 붙이는 것처럼 여러 데이터를 연결해서 새로운 데이터를 만들 수 있다.  
하지만 데이터를 연결한다고 해서 항상 원하는 결과가 만들어지는 것은 아니다.

이때 무엇을 기준으로 연결하는지, 두 데이터가 어떤 관계인지, 연결한 결과가 예상과 같은지 확인해야 한다.

---

## 질문

> 두 데이터를 연결하기 전에 무엇을 확인해야 할까?

- 어떤 값을 기준으로 연결해야 할까?
- 두 데이터는 어떤 관계를 가지고 있을까?
- 연결한 뒤 데이터가 예상과 달라지지는 않을까?

---

## 데이터

### 주문 데이터

| order_id | customer_id | amount |
|---:|---:|---:|
| 1 | 101 | 10000 |
| 2 | 102 | 15000 |
| 3 | 101 | 12000 |
| 4 | 104 | 8000 |
| 5 | 102 | 20000 |

### 고객 데이터

| customer_id | name | grade |
|---:|---|---|
| 101 | Kim | VIP |
| 102 | Lee | GOLD |
| 103 | Park | BASIC |

---

## 1. 어떤 값을 기준으로 연결해야 할까?

<details>
<summary>⋯</summary>

두 데이터를 연결할 때는 **서로 같은 대상을 가리키는 값**을 찾아야 한다.

주문 데이터의 `customer_id`와 고객 데이터의 `customer_id`는 모두 고객을 식별한다.  
따라서 두 데이터를 `customer_id`를 기준으로 연결할 수 있다.

### SQL

```sql
SELECT
    o.order_id,
    o.amount,
    c.name,
    c.grade
FROM orders AS o
JOIN customers AS c
    ON o.customer_id = c.customer_id;
```

### pandas

```python
result = orders.merge(
    customers,
    on="customer_id",
    how="inner"
)
```

</details>

## 2. 두 데이터는 어떤 관계를 가지고 있을까?

<details>
<summary>⋯</summary>

연결 기준을 정했다면 다음으로 **하나의 값이 몇 개의 행과 연결되는지** 확인해야 한다.

주문 데이터에서는 한 고객이 여러 번 주문할 수 있다.  
반면 고객 데이터에서는 `customer_id` 하나가 고객 한 명을 나타낸다.

즉, 두 데이터는

> 고객 1명 → 주문 여러 건

의 관계를 가지고 있다.

이 관계를 확인하지 않고 데이터를 연결하면 JOIN 결과를 잘못 해석할 수 있다.  
특히 고객 데이터에서 `customer_id`가 중복되어 있다면 주문 한 건이 고객 데이터의 여러 행과 연결되면서 행이 늘어날 수 있다.

### SQL

```sql
SELECT
    customer_id,
    COUNT(*) AS cnt
FROM customers
GROUP BY customer_id
HAVING COUNT(*) > 1;
```

### pandas

```python
customers["customer_id"].value_counts()
```

연결 기준이 중복되어 있다면 **실제 데이터의 구조인지, 데이터 오류인지** 먼저 확인해야 한다.

</details>

## 3. 연결한 뒤 데이터가 예상과 달라지지는 않을까?

<details>
<summary>⋯</summary>

주문 데이터에는 `customer_id = 104`가 있지만 고객 데이터에는 104번 고객이 없다.  
반대로 고객 데이터에는 `customer_id = 103`이 있지만 주문 데이터에는 주문이 없다.  
이처럼 두 데이터가 완전히 일치하지 않을 수도 있다.

주문 데이터를 모두 유지하면서 고객 정보를 붙이고 싶다면 `OUTER JOIN`을 사용할 수 있다.

### SQL

```sql
SELECT
    o.order_id,
    o.customer_id,
    o.amount,
    c.name,
    c.grade
FROM orders AS o
LEFT JOIN customers AS c
    ON o.customer_id = c.customer_id;
```

### pandas

```python
result = orders.merge(
    customers,
    on="customer_id",
    how="left"
)
```

</details>

## 정리

<details open>
<summary>⋯</summary>

두 데이터를 연결할 때는 **데이터의 관계를 이해하는 것**이 중요하다.

| 작업 | SQL | pandas |
|---|---|---|
| 데이터 연결 | `JOIN` | `merge()` |
| 다른 컬럼을 기준으로 연결 | `ON` | `left_on`, `right_on` |
| 연결 방식 지정 | `INNER JOIN`, `LEFT JOIN` | `how="inner"`, `how="left"` |
| 연결 기준 중복 확인 | `GROUP BY` + `HAVING` | `value_counts()` |
| 연결 결과 크기 확인 | `COUNT(*)` | `shape` |

</details>
