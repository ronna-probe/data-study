# 날짜는 어떤 기준으로 다뤄야 할까요?

데이터를 분석하다 보면 날짜를 기준으로 데이터를 나누거나 특정 기간을 비교해야 할 때가 많다.  
하지만 날짜를 단순한 값으로만 보면 원하는 결과를 얻기 어렵다.

시간을 대하는 기준에 따라 같은 데이터에서도 다양한 해석이 나올 수 있다.

---

## 질문

> 날짜를 분석할 때 무엇을 기준으로 봐야 할까?

- 날짜에서 어떤 기준을 뽑아야 할까?
- 원하는 기간의 데이터만 어떻게 골라낼까?
- 이 시간은 어느 지역을 기준으로 한 시간일까?

## 1. 날짜에서 어떤 기준을 뽑아야 할까?

<details>
<summary>⋯</summary>

날짜를 분석할 때는 전체 날짜를 그대로 사용하는 것보다  
**연도, 월, 일처럼 분석에 필요한 기준으로 나누어 보는 경우가 많다.**

예를 들어 월별 주문 금액을 확인하려면 `created_at`에서 월을 추출해야 한다.

### SQL

```sql
SELECT
    EXTRACT(MONTH FROM created_at) AS month,
    SUM(amount) AS total_amount
FROM orders
GROUP BY EXTRACT(MONTH FROM created_at)
ORDER BY month;
```

### pandas

```python
orders["created_at"] = pd.to_datetime(orders["created_at"])

orders["month"] = orders["created_at"].dt.month

orders.groupby("month")["amount"].sum()
```

어떤 기준으로 날짜를 나눌지는 **분석하려는 질문에 따라 결정해야 한다.**

</details>

---

## 2. 원하는 기간의 데이터만 어떻게 골라낼까?

<details>
<summary>⋯</summary>

날짜 데이터를 사용할 때는 특정 기간만 골라서 분석해야 하는 경우가 많다.

예를 들어 2024년 2월의 주문만 확인할 수 있다.

### SQL

```sql
SELECT *
FROM orders
WHERE created_at >= '2024-02-01'
  AND created_at < '2024-03-01';
```

### pandas

```python
orders[
    (orders["created_at"] >= "2024-02-01") &
    (orders["created_at"] < "2024-03-01")
]
```

기간을 조건으로 사용할 때는 **시작일과 종료일을 어떻게 포함할 것인지** 명확하게 정해야 한다.

특히 시간까지 포함된 데이터라면 종료일의 마지막 시각을 직접 지정하기보다,  
**다음 기간의 시작 시각보다 작은 조건**으로 표현하는 방법이 안전하다.

</details>

## 3. 날짜와 시간의 기준은 무엇일까?

<details>
<summary>⋯</summary>

`2024-02-01 10:00:00`이라는 값만으로는 실제 시점을 정확하게 알 수 없다.  
이 시간이 **한국 시간인지, 미국 시간인지, UTC인지**에 따라 실제 시점이 달라지기 때문이다.

여러 지역에서 발생한 데이터를 함께 분석한다면 **타임존을 확인하고 하나의 기준으로 통일하는 과정**이 필요하다.  
예를 들어 UTC 기준으로 저장된 시간을 한국 시간으로 변환할 수 있다.

### SQL

```sql
SELECT
    created_at,
    DATETIME(created_at, 'Asia/Seoul') AS created_at_kst
FROM orders;
```

### pandas

```python
orders["created_at"] = pd.to_datetime(
    orders["created_at"],
    utc=True
)

orders["created_at_kst"] = (
    orders["created_at"]
    .dt.tz_convert("Asia/Seoul")
)
```

특히 여러 국가의 데이터를 비교하거나 하루 단위로 집계할 때는  
**어느 지역의 날짜를 기준으로 하루를 나눌 것인지**도 확인해야 한다.

</details>

## 정리

<details open>
<summary>⋯</summary>

날짜를 분석할 때는 날짜 자체보다 **어떤 시간 기준으로 데이터를 바라볼 것인지** 먼저 정해야 한다.

> 날짜 기준 추출 → 기간 필터링 → 시간대 확인

순서로 생각해볼 수 있다.

| 작업 | SQL | pandas |
|---|---|---|
| 날짜 기준 추출 | `EXTRACT()` | `.dt` |
| 기간 필터링 | `WHERE` | 조건식 |
| 타임존 변환 | `DATETIME()` | `.dt.tz_convert()` |
| 날짜 타입 변환 | `CAST()` | `pd.to_datetime()` |

특히 날짜·시간 데이터에서는 다음을 확인해보자.

- 연도, 월, 일 중 어떤 기준이 필요한가?
- 기간의 시작과 끝을 어떻게 정의할 것인가?
- 날짜와 시간이 함께 있다면 시간까지 고려해야 하는가?
- 데이터의 타임존은 무엇인가?
- 여러 지역의 데이터를 비교한다면 어떤 타임존을 기준으로 할 것인가?

</details>
