# 날짜는 어떤 기준으로 다뤄야 할까요?

데이터를 분석하다 보면 날짜를 기준으로 데이터를 나누거나 기간을 비교해야 할 때가 많다.

하지만 날짜를 단순한 값으로만 보면 원하는 결과를 얻기 어렵다.

같은 날짜 데이터라도 **연도별로 볼 것인지, 월별로 볼 것인지, 특정 기간을 비교할 것인지**에 따라 분석 방법이 달라진다.

---

## 질문

> 날짜를 분석할 때 무엇을 기준으로 봐야 할까?

- 날짜에서 어떤 기준을 뽑아야 할까?
- 원하는 기간의 데이터만 어떻게 골라낼까?
- 두 날짜 사이의 차이는 어떻게 계산할까?

## 1. 날짜에서 어떤 기준을 뽑아야 할까?

<details>
<summary>⋯</summary>

날짜를 분석할 때는 전체 날짜를 그대로 사용하는 것보다 **연도, 월, 일처럼 분석에 필요한 기준으로 나누어 보는 경우가 많다.**

예를 들어 월별 주문 금액을 확인하려면 `order_date`에서 월을 추출해야 한다.

### SQL

```sql
SELECT
    EXTRACT(MONTH FROM order_date) AS month,
    SUM(amount) AS total_amount
FROM orders
GROUP BY EXTRACT(MONTH FROM order_date)
ORDER BY month;
```

### pandas

```python
orders["month"] = orders["order_date"].dt.month

orders.groupby("month")["amount"].sum()
```

어떤 기준으로 날짜를 나눌지는 **분석하려는 질문에 따라 결정해야 한다.**

</details>

---

## 2. 원하는 기간의 데이터만 어떻게 골라낼까?

<details>
<summary>⋯</summary>

날짜 데이터를 사용할 때는 특정 기간만 골라서 분석해야 하는 경우도 많다.

예를 들어 2024년 2월의 주문만 확인할 수 있다.

### SQL

```sql
SELECT *
FROM orders
WHERE order_date >= '2024-02-01'
  AND order_date < '2024-03-01';
```

### pandas

```python
orders[
    (orders["order_date"] >= "2024-02-01") &
    (orders["order_date"] < "2024-03-01")
]
```

기간을 조건으로 사용할 때는 **시작일과 종료일을 어떻게 포함할 것인지** 명확하게 정해야 한다.

특히 시간까지 포함된 데이터라면 종료일의 `23:59:59`를 직접 지정하기보다 다음 기간의 시작 직전까지를 조건으로 잡는 방식이 안전하다.

</details>

---

## 3. 두 날짜 사이의 차이는 어떻게 계산할까?

<details>
<summary>⋯</summary>

날짜는 서로 비교하는 것뿐만 아니라 **두 날짜 사이의 기간**을 계산할 수도 있다.

예를 들어 주문일과 특정 기준일 사이에 며칠이 지났는지 계산할 수 있다.

### SQL

```sql
SELECT
    order_id,
    order_date,
    CURRENT_DATE - order_date AS days_passed
FROM orders;
```

### pandas

```python
orders["order_date"] = pd.to_datetime(orders["order_date"])

orders["days_passed"] = (
    pd.Timestamp.today() - orders["order_date"]
).dt.days
```

다만 날짜 차이는 단순히 숫자를 빼는 문제가 아니다.

**일 단위인지, 월 단위인지, 영업일 기준인지**에 따라 계산 방법과 결과의 의미가 달라질 수 있다.

</details>

---

## 정리

<details open>
<summary>⋯</summary>

날짜를 분석할 때는 날짜 자체보다 **어떤 시간 기준으로 데이터를 바라볼 것인지** 먼저 정해야 한다.

**날짜 기준 추출 → 기간 필터링 → 날짜 차이 계산**

순서로 생각해볼 수 있다.

| 작업 | SQL | pandas |
|---|---|---|
| 날짜 기준 추출 | `EXTRACT()` | `.dt` |
| 기간 필터링 | `WHERE` | 조건식 |
| 날짜 차이 계산 | 날짜 연산 | `Timestamp` 연산 |
| 날짜 타입 변환 | `CAST()` | `pd.to_datetime()` |

특히 날짜 데이터에서는 다음을 확인해보자.

- 연도, 월, 일 중 어떤 기준이 필요한가?
- 기간의 시작과 끝을 어떻게 정의할 것인가?
- 날짜와 시간이 함께 있다면 시간까지 고려해야 하는가?
- 두 날짜의 차이를 어떤 단위로 계산할 것인가?

**날짜는 단순한 값이 아니라 시간의 기준이다.  
어떤 기준으로 나누고 비교하느냐에 따라 같은 데이터도 전혀 다른 결과가 될 수 있다.**

</details>
