# 데이터를 어떻게 나눠서 봐야 할까?

전체 데이터를 한꺼번에 살펴보면 세부 특징을 발견하기 어려울 수 있다.  
예를 들어 주문 금액을 하나의 분포로만 보는 대신, 금액 구간별로 나누면 어떤 구간에 주문이 많이 몰려 있는지 확인할 수 있다.

한편 데이터를 어떤 기준으로 나누느냐에 따라 보이는 특징도 달라질 수 있다.

> 데이터를 어떤 기준으로 나누면 의미 있는 특징을 발견할 수 있을까?

이번에는 수치형 데이터를 구간으로 나누어 살펴보면서, **구간을 나누는 기준에 따라 데이터의 특징이 어떻게 달라지는지** 탐색해본다.

---

- 분석 목적에 따라 어떤 기준을 선택해야 할까?

## 1. 어떤 기준으로 데이터를 나눌 수 있을까?

<details>
<summary>⋯</summary>

수치형 데이터는 일정한 범위를 기준으로 여러 구간으로 나눌 수 있다.  
예를 들어 주문 금액을 낮은 금액, 중간 금액, 높은 금액으로 분류할 수 있다.  
pandas의 `cut()`을 사용하면 미리 정한 경계값을 기준으로 데이터를 나눌 수 있다.

```python
orders["amount_group"] = pd.cut(
    orders["amount"],
    bins=[0, 15000, 30000, float("inf")],
    labels=["낮음", "중간", "높음"]
)
```

이렇게 하면 다음과 같이 금액 구간을 구분할 수 있다.

| 주문 금액 | 구간 |
|---:|---|
| 10000 | 낮음 |
| 20000 | 중간 |
| 60000 | 높음 |

이때 구간의 경계값은 분석 목적에 맞게 설정해야 한다.  
예를 들어 실제 업무에서 주문 금액 15000원을 기준으로 할인 정책이 달라진다면, 해당 기준으로 구간을 나누는 것이 의미 있을 수 있다.  
반대로 특별한 기준이 없다면 구간을 임의로 나누기보다 데이터의 분포를 먼저 확인하는 것이 좋다.

</details>

## 2. 각 구간에는 데이터가 얼마나 포함될까?

<details>
<summary>⋯</summary>

**구간별 개수와 비율을 확인하면 데이터가 어느 범위에 집중되어 있는지 파악할 수 있다.**

```python
# 구간별 개수
orders["amount_group"].value_counts(
    sort=False
)

# 구간별 비율
orders["amount_group"].value_counts(
    normalize=True,
    sort=False
) * 100
```

## 3. 데이터를 비슷한 개수로 나누면 어떤 차이가 있을까?

<details>
<summary>⋯</summary>

앞에서는 금액의 경계값을 직접 정했다.

이번에는 각 구간에 비슷한 개수의 데이터가 포함되도록 나누어 보자.  
pandas의 `qcut()`은 데이터의 분위수를 기준으로 구간을 나눈다.

```python
orders["amount_quantile"] = pd.qcut(
    orders["amount"],
    q=3,
    labels=["낮음", "중간", "높음"]
)

orders[["amount", "amount_quantile"]]
```

전체 주문이 12건이므로 세 구간에 각각 4건씩 배정된다.

앞에서 사용한 `cut()`과 비교하면 차이가 있다.

| 구분 | `cut()` | `qcut()` |
|---|---|---|
| 구간을 나누는 기준 | 정해진 경계값 | 데이터의 분위수 |
| 구간별 데이터 수 | 서로 다를 수 있음 | 가능한 한 비슷하게 나뉨 |
| 활용 목적 | 의미 있는 범위별 비교 | 데이터 순위나 상대적 위치에 따른 비교 |

`cut()`은 금액이나 나이처럼 해석하기 쉬운 경계값을 기준으로 비교할 때 유용하다.  
`qcut()`은 데이터의 상대적인 위치를 기준으로 비슷한 크기의 그룹을 만들 때 유용하다.  
단 `qcut()`으로 비슷한 개수의 그룹을 만들 때, 각 구간의 금액 구간의 크기는 서로 다를 수 있다.

</details>

## 4. 분석 목적에 따라 어떤 기준을 선택해야 할까?

<details>
<summary>⋯</summary>

데이터를 나누는 데 항상 정답인 기준이 있는 것은 아니다.  
어떤 특징을 발견하려는지에 따라 적절한 방법이 달라진다.

**의미 있는 경계값으로 나누는 경우**  
상품 가격대나 고객 연령대처럼 실제로 해석하기 쉬운 구간이 필요할 때 적합하다.

**비슷한 개수로 나누는 경우**  
고객을 구매 금액의 상대적인 수준에 따라 구분하거나, 데이터의 낮은 구간부터 높은 구간까지 비교할 때 적합하다.

구간을 너무 많이 나누면 각 구간의 데이터가 적어져 전체적인 특징을 파악하기 어려울 수 있다.  
반대로 구간을 너무 적게 나누면 서로 다른 특징이 하나의 구간에 섞일 수 있다.

따라서 데이터를 나눌 때는 다음을 고려해야 한다.

- 구간을 나누는 기준을 설명할 수 있는가?
- 각 구간에 데이터가 충분히 포함되어 있는가?
- 구간을 나눈 결과가 분석 질문에 도움이 되는가?

무엇보다 구간별 차이가 발견되었다고 해서 그 차이가 발생한 원인까지 알 수 있는 것은 아니다.

</details>

## 정리

<details open>
<summary>⋯</summary>

수치형 데이터를 구간으로 나누어 탐색할 때는 다음과 같이 살펴볼 수 있다.

1. 분석 목적에 맞는 구간 기준을 정한다.
2. 구간별 데이터 수와 비율을 확인한다.
3. 필요하다면 분위수를 기준으로 나눈 결과와 비교한다.
4. 구간의 경계와 데이터 수가 분석 목적에 적절한지 검토한다.

| 확인할 내용 | pandas |
|---|---|
| 정해진 경계값으로 구간 나누기 | `pd.cut()` |
| 분위수로 구간 나누기 | `pd.qcut()` |
| 구간별 개수 | `value_counts()` |
| 구간별 비율 | `value_counts(normalize=True)` |

핵심은 **데이터를 나누는 것 자체가 아니라, 분석 목적에 맞는 기준으로 나누어 새로운 특징을 발견하는 것**이다.

> EDA에서는 데이터의 구간을 어떻게 정의하느냐에 따라 보이는 특징이 달라질 수 있다는 점을 기억해야 한다.

</details>
