# 데이터의 분포는 어떨까?

평균이나 최댓값을 구했다고 해서 데이터의 전체 모습을 알 수 있는 것은 아니다.  
같은 평균을 가진 데이터라도 값이 특정 구간에 몰려 있을 수도 있고, 일부 값만 유난히 클 수도 있다.

EDA에서는 개별적인 값보다 **값들이 전체적으로 어떻게 퍼져 있는지**를 살펴볼 필요가 있다.

---

## 질문

> 평균이 얼마인지는 알겠는데, 실제 값들은 어떻게 퍼져 있을까?

- 값이 어느 구간에 많이 모여 있을까요?
- 값이 한쪽으로 치우쳐 있지는 않을까요?
- 데이터의 대부분은 어느 범위에 있을까요?
- 분포를 눈으로 확인하면 무엇이 달라질까요?

---

## 데이터

```python
import pandas as pd

orders = pd.DataFrame({
    "order_id": range(1, 11),
    "amount": [
        10000,
        11000,
        12000,
        13000,
        14000,
        15000,
        16000,
        17000,
        18000,
        100000
    ]
})
```

---

## 1. 값이 어느 구간에 많이 모여 있을까?

<details>
<summary>⋯</summary>

먼저 값을 일정한 구간으로 나누고, 각 구간에 데이터가 몇 개씩 들어 있는지 확인해보자.  
예를 들어 주문 금액을 다음과 같이 나눌 수 있다.

- 0 ~ 20,000
- 20,000 ~ 40,000
- 40,000 ~ 60,000
- 60,000 ~ 80,000
- 80,000 ~ 100,000
- 100,000 이상

`pd.cut()`을 사용하면 연속적인 숫자 데이터를 구간으로 나눌 수 있다.

```python
bins = [0, 20000, 40000, 60000, 80000, 100000, float("inf")]

labels = [
    "0~2만원",
    "2~4만원",
    "4~6만원",
    "6~8만원",
    "8~10만원",
    "10만원 이상"
]

orders["amount_range"] = pd.cut(
    orders["amount"],
    bins=bins,
    labels=labels,
    right=False
)

orders["amount_range"].value_counts().sort_index()
```

대부분의 주문이 `0~2만원` 구간에 몰려 있고, `10만원 이상`인 주문은 하나뿐이다.

평균이나 최댓값만 볼 때와는 다른 모습이 보인다.  
**분포를 확인하면 값이 어디에 집중되어 있는지 알 수 있다.**

</details>

---

## 2. 값이 한쪽으로 치우쳐 있지는 않을까?

<details>
<summary>⋯</summary>

이번에는 평균과 중앙값을 비교해보자.

```python
orders["amount"].agg(["mean", "median"])
```

이 데이터에서는 `100000`이라는 큰 값 하나 때문에 평균이 크게 올라간다.  
반면 중앙값은 대부분의 주문이 위치한 구간에 더 가까운 값을 보여준다.

</details>

---

## 3. 데이터의 대부분은 어느 범위에 있을까?

<details>
<summary>⋯</summary>

특정 값 하나만 보는 대신, 데이터의 일정 비율이 어느 범위에 들어오는지도 확인할 수 있다.

대표적으로 분위수를 사용한다.

- `25%`: 데이터의 25%가 이 값 이하
- `50%`: 중앙값
- `75%`: 데이터의 75%가 이 값 이하

```python
orders["amount"].quantile([0.25, 0.5, 0.75])
```

또는 `describe()`를 사용하면 주요 통계량과 분위수를 한 번에 확인할 수 있다.

```python
orders["amount"].describe()
```

특히 `25% ~ 75%` 사이의 범위를 보면 데이터의 가운데 50%가 어느 구간에 모여 있는지 확인할 수 있다.

</details>

---

## 4. 분포를 눈으로 확인하면 무엇이 달라질까?

<details>
<summary>⋯</summary>

숫자로만 분포를 확인하는 것보다 그래프로 보면 데이터의 형태를 빠르게 파악할 수 있다.

수치형 변수를 시각화하는 대표적인 방법이 **히스토그램**이다.  
히스토그램은 값을 여러 구간으로 나누고, 각 구간에 데이터가 얼마나 들어 있는지를 보여준다.

```python
import matplotlib.pyplot as plt

plt.hist(orders["amount"], bins=5)

plt.xlabel("amount")
plt.ylabel("count")
plt.title("Distribution of Order Amount")

plt.show()
```

히스토그램을 통해 다음과 같은 패턴을 확인할 수 있다.

- 특정 구간에 값이 집중되어 있는가?
- 값이 여러 구간으로 퍼져 있는가?
- 한쪽으로 치우쳐 있는가?
- 유난히 멀리 떨어진 값이 있는가?

그래프는 분포의 형태를 빠르게 파악하는 데 도움이 된다.

</details>

## 정리

<details open>
<summary>⋯</summary>

분포를 본다는 것은 단순히 평균이나 최댓값을 구하는 것이 아니다.  
**값들이 어디에 얼마나 모여 있는지, 어느 쪽으로 치우쳐 있는지, 대부분의 데이터가 어느 범위에 있는지**를 확인하는 것이다.

| 확인할 내용 | pandas |
|---|---|
| 구간별 데이터 개수 | `pd.cut()` + `value_counts()` |
| 평균 | `mean()` |
| 중앙값 | `median()` |
| 분위수 | `quantile()` |
| 주요 통계량 확인 | `describe()` |
| 분포 시각화 | `plt.hist()` |

결국 중요한 것은 **데이터는 하나의 숫자만으 로 설명되지 않는다는 사실을 이해하는 것**이다.

</details>
