# 그룹에 따라 차이가 있을까?

전체 데이터를 한 번에 살펴보면 놓칠 수 있는 특징이 있다.  
데이터를 특정 기준으로 나누어 보면 그룹마다 값의 크기나 분포가 다르게 나타날 수 있다.  
예를 들어 온라인과 오프라인 주문의 구매 금액을 비교하면, 판매 채널에 따라 주문 금액이 어떻게 다른지 살펴볼 수 있다.

이번에는 데이터를 그룹별로 나누어 비교하면서 **그룹 간 차이와 그 차이가 나타나는 모습**을 탐색해본다.

--- 

## 질문

> 그룹에 따라 차이가 있을까?

- 그룹마다 값의 크기가 다를까?
- 평균만으로 그룹 간 차이를 설명할 수 있을까?
- 그룹별 분포는 어떻게 다를까?
- 그룹별 데이터 수는 충분할까?

---

## 데이터

```python
import pandas as pd

orders = pd.DataFrame({
    "order_id": range(1, 11),
    "channel": [

    ],
    "amount": [
        10000, 12000, 13000, 15000, 50000,
        18000, 19000, 20000, 21000, 22000
    ]
})

orders
```

## 1. 그룹마다 값의 크기가 다를까?

<details>
<summary>⋯</summary>

먼저 그룹별로 데이터를 나누고 대표적인 값을 비교해본다.

```python
orders.groupby("channel")["amount"].agg(
    ["count", "mean", "median", "min", "max"]
)
```

이렇게 하면 각 그룹의 데이터 수, 평균, 중앙값, 최솟값, 최댓값을 한 번에 확인할 수 있다.

그룹별 요약값을 비교하면 전체 데이터를 하나로 봤을 때는 보이지 않던 차이를 발견할 수 있다.  
예를 들어 두 그룹의 평균이 비슷하더라도 중앙값이나 최댓값은 다르게 나타날 수 있다.

**그룹별 요약값을 비교하는 것은 차이를 발견하기 위한 출발점이다.**

</details>

---

## 2. 평균만으로 그룹 간 차이를 설명할 수 있을까?

<details>
<summary>⋯</summary>

그룹별 평균을 비교하면 각 그룹의 전반적인 수준을 간단하게 비교할 수 있다.

```python
orders.groupby("channel")["amount"].mean()
```

하지만 평균만으로 그룹의 특징을 충분히 이해할 수 있는 것은 아니다.

이번 데이터에서는 온라인 주문 금액 중 50000이라는 큰 값이 있다. 이 값 때문에 온라인 그룹의 평균이 높아진다.

```python
orders.groupby("channel")["amount"].agg(
    ["mean", "median"]
)
```

온라인과 오프라인의 평균은 모두 20000이지만, 중앙값은 서로 다르다.

평균은 모든 값을 반영하지만 큰 값의 영향을 받을 수 있다.  
중앙값은 값을 순서대로 놓았을 때 가운데에 위치하는 값이므로 극단적으로 큰 값의 영향을 상대적으로 적게 받는다.

따라서 그룹을 비교할 때는 평균만 확인하기보다 **중앙값과 실제 데이터도 함께 살펴보는 것**이 좋다.

</details>

---

## 3. 그룹별 분포는 어떻게 다를까?

<details>
<summary>⋯</summary>

요약값만으로는 값들이 어떻게 퍼져 있는지 충분히 알기 어렵다.  
상자그림(Box Plot)을 이용하면 그룹별 분포를 한눈에 비교할 수 있다.

```python
import matplotlib.pyplot as plt

orders.boxplot(
    column="amount",
    by="channel"
)

plt.title("Order Amount by Channel")
plt.suptitle("")
plt.xlabel("Channel")
plt.ylabel("Amount")
plt.show()
```

상자그림에서는 다음과 같은 특징을 살펴볼 수 있다.

- 중앙값이 그룹마다 얼마나 다른가?
- 값들이 얼마나 넓게 퍼져 있는가?
- 유난히 크거나 작은 값이 있는가?

이번 데이터에서는 온라인 주문 금액에 유난히 큰 값이 있고, 오프라인 주문 금액은 비교적 좁은 범위에 모여 있다.  
이처럼 평균이나 중앙값이 비슷하더라도 실제 분포는 다를 수 있다.

**그룹 간 차이를 제대로 이해하려면 대표값뿐 아니라 분포의 모습도 비교해야 한다.**

</details>

---

## 4. 그룹별 데이터 수는 충분할까?

<details>
<summary>⋯</summary>

그룹별 차이를 비교할 때는 각 그룹에 데이터가 얼마나 있는지도 확인해야 한다.

```python
orders.groupby("channel").size()
```

그룹마다 데이터 수가 크게 다르다면, 일부 그룹의 요약값은 적은 수의 데이터에 영향을 많이 받을 수 있다.  
특히 데이터가 적은 그룹에서 큰 차이가 관찰되더라도, 그것이 해당 그룹의 일반적인 특징인지 판단하기에는 정보가 부족할 수 있다.

따라서 그룹별 비교 결과를 해석할 때는 다음을 함께 확인하는 것이 좋다.

- 각 그룹의 데이터 수는 얼마인가?
- 그룹마다 데이터 수에 큰 차이가 있는가?
- 일부 데이터에 의해 결과가 크게 달라질 수 있는가?

그룹별 데이터 수가 많다고 해서 반드시 비교가 타당한 것은 아니지만, **데이터 수를 확인하는 것은 결과를 해석하기 위한 중요한 과정**이다.

</details>

## 정리

<details open>
<summary>⋯</summary>

그룹별 차이를 탐색할 때는 다음 순서로 살펴볼 수 있다.

1. 그룹별 요약값을 비교해 차이를 발견한다.
2. 평균과 중앙값을 함께 보며 대표값을 해석한다.
3. 시각화로 그룹별 분포와 특이한 값을 확인한다.
4. 그룹별 데이터 수를 확인하고 결과를 신중하게 해석한다.

| 확인할 내용 | pandas / 시각화 |
|---|---|
| 그룹별 요약값 | `groupby()` + `agg()` |
| 평균과 중앙값 | `mean()`, `median()` |
| 그룹별 분포 | `boxplot()` |
| 그룹별 데이터 수 | `groupby().size()` |

그룹별 차이를 발견했다고 해서 그 차이가 발생한 이유까지 알 수 있는 것은 아니다.

EDA에서는 먼저 **어떤 그룹이 어떻게 다른지**를 탐색하고, 그 차이가 왜 나타나는지는 추가적인 분석을 통해 알아본다.

</details>
