# 이 패턴을 다른 관점에서도 확인할 수 있을까?

데이터를 탐색하다 보면 하나의 특징을 발견할 수 있다.  

예를 들어 A 캠페인보다 B 캠페인에서 구매가 더 많이 발생했다면, B 캠페인의 성과가 더 좋다고 생각할 수 있다.  
그런데 두 캠페인의 방문자 수가 크게 다르다면 어떨까?

> 같은 데이터를 다른 기준으로 살펴보면, 처음 발견한 패턴도 다르게 해석될 수 있을까?

이번에는 하나의 현상을 여러 지표와 시각화로 확인하면서 **각 관점이 보여주는 특징과 해석의 차이**를 탐색해본다.

---

## 질문

> 이 패턴을 다른 관점에서도 확인할 수 있을까?

- 처음 데이터를 살펴봤을 때 어떤 차이가 보일까?
- 다른 지표로 비교하면 결과도 같을까?
- 그래프로 다시 살펴보면 어떤 특징이 보일까?
- 각 관점은 무엇을 알려주고, 무엇을 놓칠 수 있을까?

---

## 데이터

```python
import pandas as pd

campaigns = pd.DataFrame({
    "campaign": ["A", "B"],
    "visitors": [100, 500],
    "purchases": [30, 50]
})

campaigns
```

| campaign | visitors | purchases |
|---|---:|---:|
| A | 100 | 30 |
| B | 500 | 50 |

---

## 1. 처음 데이터를 살펴봤을 때 어떤 차이가 보일까?

<details>
<summary>⋯</summary>

먼저 캠페인별 구매 수를 비교해본다.

```python
campaigns.loc[:, ["campaign", "purchases"]]
```

A 캠페인에서는 30건, B 캠페인에서는 50건의 구매가 발생했다.  
구매 수만 보면 B 캠페인의 실적이 더 높다.  

하지만 이 결과만으로 B 캠페인이 더 효율적이라고 판단할 수는 없다.  
B 캠페인의 방문자 수가 A 캠페인보다 훨씬 많기 때문이다.  
따라서 구매 수 외에 다른 지표도 살펴볼 필요가 있다.

</details>

---

## 2. 다른 지표로 비교하면 결과도 같을까?

<details>
<summary>⋯</summary>

구매 수뿐 아니라 방문자 대비 구매 비율도 비교해보자.  
방문자 수가 다른 캠페인을 비교할 때는 전체 방문자 중 구매로 이어진 비율을 살펴볼 수 있다.

```python
campaigns["purchase_rate"] = (
    campaigns["purchases"]
    / campaigns["visitors"]
    * 100
)

campaigns[[
    "campaign",
    "visitors",
    "purchases",
    "purchase_rate"
]]
```

| campaign | visitors | purchases | purchase_rate |
|---|---:|---:|---:|
| A | 100 | 30 | 30.0 |
| B | 500 | 50 | 10.0 |

구매 수와 구매 비율을 비교하면 결과가 달라진다.

- **구매 수:** B 캠페인이 더 많다.
- **구매 비율:** A 캠페인이 더 높다.

두 결과가 서로 모순되는 것은 아니다.  
B 캠페인은 더 많은 방문자를 확보해 구매 수가 많았고, A 캠페인은 방문자 중 구매로 이어진 비율이 더 높았다.  
즉, 어떤 지표를 사용하느냐에 따라 발견하는 특징과 해석이 달라질 수 있다.

</details>

---

## 3. 그래프로 다시 살펴보면 어떤 특징이 보일까?

<details>
<summary>⋯</summary>

숫자를 직접 비교하는 것뿐 아니라 그래프로 표현하면 두 지표의 차이를 더 직관적으로 확인할 수 있다.  
먼저 캠페인별 구매 수를 비교해보자.

```python
import matplotlib.pyplot as plt

campaigns.plot(
    x="campaign",
    y="purchases",
    kind="bar",
    legend=False
)

plt.xlabel("Campaign")
plt.ylabel("Purchases")
plt.title("Purchases by Campaign")
plt.xticks(rotation=0)

plt.show()
```

이번에는 구매 비율을 비교해보자.

```python
campaigns.plot(
    x="campaign",
    y="purchase_rate",
    kind="bar",
    legend=False
)

plt.xlabel("Campaign")
plt.ylabel("Purchase Rate (%)")
plt.title("Purchase Rate by Campaign")
plt.xticks(rotation=0)

plt.show()
```

첫 번째 그래프에서는 B 캠페인의 구매 수가 더 많지만, 두 번째 그래프에서는 A 캠페인의 구매 비율이 더 높게 나타난다.  
**같은 데이터를 사용하더라도 어떤 지표를 선택하느냐에 따라 강조되는 특징이 달라지는 것이다.**

</details>

## 4. 각 관점은 무엇을 알려주고, 무엇을 놓칠 수 있을까?

<details>
<summary>⋯</summary>

지금까지 살펴본 두 지표는 서로 다른 질문에 답한다.

| 지표 | 답하는 질문 | 놓칠 수 있는 부분 |
|---|---|---|
| 구매 수 | 구매가 얼마나 많이 발생했을까? | 방문자 규모의 차이 |
| 구매 비율 | 방문자 중 구매로 이어진 비율은 얼마일까? | 전체 구매 규모의 차이 |

구매 수가 중요하다면 전체 구매 규모를 살펴봐야 하고, 방문자를 구매로 전환하는 비율이 중요하다면 구매 비율을 확인해야 한다.  
어느 지표가 더 좋은지는 분석 목적에 따라 달라진다.  
필요하다면 구매 금액, 마케팅 비용, 신규 고객 비율 같은 다른 지표도 살펴볼 수 있다.

다만 여러 지표를 확인한다고 해서 그 자체로 결과가 정확해지거나 원인이 밝혀지는 것은 아니다.  
각 지표가 무엇을 의미하는지 이해하고, 분석하려는 질문에 맞게 해석해야 한다.

</details>

## 정리

<details open>
<summary>⋯</summary>

하나의 패턴을 여러 관점에서 탐색할 때는 다음과 같이 살펴볼 수 있다.

1. 먼저 눈에 띄는 차이를 확인한다.
2. 다른 지표로 비교했을 때도 같은 특징이 나타나는지 살펴본다.
3. 그래프로 표현해 차이를 직관적으로 확인한다.
4. 각 지표가 무엇을 설명하고 무엇을 놓치는지 해석한다.

| 확인할 내용 | 방법 |
|---|---|
| 절대적인 규모 비교 | 개수, 합계 |
| 상대적인 비율 비교 | 비율 계산 |
| 지표별 차이 확인 | `plot(kind="bar")` |
| 결과 해석 | 분석 목적과 지표의 의미 확인 |

핵심은 **하나의 지표로 발견한 패턴을 전체적인 결론으로 받아들이지 않는 것**이다.  
다른 지표와 시각화로 같은 데이터를 살펴보면 처음에는 보이지 않았던 특징을 발견할 수 있다.

> EDA에서는 하나의 패턴을 여러 관점에서 살펴보며, 데이터가 보여주는 현상을 더 입체적으로 이해한다.

</details>
