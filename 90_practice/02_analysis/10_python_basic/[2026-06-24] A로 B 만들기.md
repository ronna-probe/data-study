## 문제

소문자로 이루어진 문자열 `before`와 `after`가 매개변수로 주어진다.  

before의 순서를 바꾸어 after를 만들 수 있으면 1을,  
만들 수 없으면 0을 반환하는 문제이다.

---

## 예시

| before | after | result |
|--------|-------|--------|
| "aab" | "baa" | 1 |
| "xxyz" | "xyzz" | 0 |

---

## 접근

이 문제는 **순서가 아니라 문자 구성(빈도)을 비교**하는 문제이다.

즉, 두 문자열이 같은지 판단하는 기준은 다음 하나로 압축된다:

- multiset이 동일한가

---

## 코드

### 1. 정렬 기반 비교

- 문자열을 정렬하면 구성 비교 가능
- 가장 직관적인 풀이

```python
def is_anagram(before, after):

    return int(sorted(before) == sorted(after))
```

### 2. 딕셔너리 비교

- 문자별 등장 횟수를 직접 계산
- 구조적으로 명확한 방식

```python
def is_anagram(before, after):

    # set × count() 반복 구조 → O(n^2)
    freq_before = {ch: before.count(ch) for ch in set(before)}
    freq_after = {ch: after.count(ch) for ch in set(after)}
  
    return int(freq_before == freq_after)
```

### 3. get 기반 카운팅

- 한 번 순회로 빈도 계산 가능
- 효율적인 구현 방식

```python
def is_anagram(before, after):

    # O(n): 단일 순회 기반 frequency counter
    freq = {}

    for ch in before:
        freq[ch] = freq.get(ch, 0) + 1

    for ch in after:
        freq[ch] = freq.get(ch, 0) - 1

    return int(all(cnt == 0 for cnt in freq.values()))
```

---

## 정리

이 문제의 핵심은 정렬 또는 카운팅을 통해  
**multiset equality**를 확인하는 데 있다.
