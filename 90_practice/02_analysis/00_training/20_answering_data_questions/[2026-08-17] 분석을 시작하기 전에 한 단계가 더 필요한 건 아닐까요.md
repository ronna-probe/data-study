# 데이터 이해

데이터 분석의 첫 단계는, 분석을 시작하는 것이 아니라 데이터를 이해하는 것이다.  
분석에 들어가기 전에 다음 질문에 답할 수 있어야 한다.

- 데이터의 규모는?
- 데이터의 내용은?
- 데이터 타입은?
- 어떤 범주형 데이터가 있는가?
- 수치형 데이터의 특성은 어떠한가?

df.shape

## 2. 데이터의 내용은?

실제 데이터를 직접 확인하면서 어떤 값이 들어 있는지 파악한다.

### SQL

```sql
SELECT *
FROM orders
LIMIT 5;
```

### pandas

```python
df.head()
```

## 3. 데이터 타입은?

데이터 타입을 확인하면 이후 특정 연산에 적합한 형태인지 판단할 수 있다.  
예를 들어 숫자처럼 보이는 값이 문자열로 저장되어 있다면 집계나 계산 전에 변환이 필요하다.

### SQL

SQL에서는 데이터베이스의 스키마 정보를 통해 데이터 타입을 확인한다.

```sql
SELECT
    column_name,
    data_type
FROM information_schema.columns
WHERE table_name = 'orders';
```

> 결과 :
> 
> | column_name | data_type |
> |---|---|
> | order_id | integer |
> | customer_id | integer |
> | product | varchar |
> | amount | integer |

### pandas

```python
df.info()
```

> 결과 :
> 
> RangeIndex: 5 entries, 0 to 4  
> Data columns (total 4 columns):  
>   order_id       int64  
>   customer_id    int64  
>   product        object  
>   amount         int64  

--- 

## 4. 어떤 범주형 데이터가 있는가?

예를 들어 product에 어떤 상품이 존재하는지 확인해보자.

### SQL

```sql
SELECT
    product,
    COUNT(*) AS count
FROM orders
GROUP BY product;
```

> 결과:
>
> | product | count |
> |---|---|
> | A | 2 |
> | B | 2 |
> | C | 1 |

### pandas

```python
df["product"].unique()
```

> 결과:  
> 
> array(['A', 'B', 'C'], dtype=object)

```python
df["product"].value_counts()
```

> 결과:
> 
> product  
> A          2  
> B          2  
> C          1  
> Name: count, dtype: int64

---

## 5. 수치형 데이터의 특성은 어떠한가?

amount의 기술통계를 확인해보자.

### SQL

```sql
SELECT
    COUNT(amount) AS count,
    AVG(amount) AS mean,
    MIN(amount) AS min,
    MAX(amount) AS max
FROM orders;
```

> 결과:
>
> | count | mean | min | max |
> |---|---|---|---|
> | 5 | 13000 | 8000 | 20000 |

### pandas

```python
df["amount"].describe()
```

> 결과:
>
> |  | amount |
> |---|---:|
> | count | 5.0 |
> | mean | 13000.0 |
> | std | 4743.4 |
> | min | 8000.0 |
> | 25% | 10000.0 |
> | 50% | 12000.0 |
> | 75% | 15000.0 |
> | max | 20000.0 |

## 정리

데이터를 제대로 이해하지 못한 상태에서 시작한 분석은 결과가 맞더라도 신뢰하기 어렵다.

> 크기 · 내용 · 타입 · 형태

### SQL과 pandas 비교

| 질문 | SQL | pandas |
|---|---|---|
| 행 개수 | `COUNT(*)` | `df.shape[0]` |
| 데이터 미리보기 | `LIMIT 5` | `df.head(5)` |
| 데이터 타입 | `information_schema` | `df.info()` |
| 고유값 | `DISTINCT` | `df["col"].unique()` |
| 고유값 개수 | `COUNT(DISTINCT)` | `df["col"].nunique()` |
| 기술 통계 | `AVG`, `MIN`, `MAX` 등 | `df.describe()` |
