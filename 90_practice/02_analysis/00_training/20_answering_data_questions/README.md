# 데이터 조작

데이터 질문을 해결하며, 데이터를 조회·변환·집계하는 기술을 훈련한다.

---

## 질문

- 어떻게 데이터를 원하는 형태로 만들 수 있을까?
- 여러 데이터를 어떻게 하나의 분석 가능한 데이터로 만들 수 있을까?
- 데이터를 어떻게 요약해서 의미 있는 정보를 얻을 수 있을까?
- 데이터의 순서와 변화를 어떻게 분석할 수 있을까?

---

## 학습 방법

각 질문을 SQL과 pandas로 각각 해결한다.
