# 데이터 조작

데이터 질문을 해결하며, 데이터를 조회·변환·집계하는 기술을 훈련한다.

---

## 질문

이런 질문을 받는다면 어떻게 답할까?  
내가 미처 생각하지 못했던 부분은 무엇일까?

- 분석을 시작하기 전에 놓친 건 없을까요?
- 이 데이터들을 지금 상태 그대로 사용해도 될까요?
- 이렇게 만든 숫자를 그대로 믿어도 괜찮을까요?
- 이 결과가 보여주지 않는 것은 무엇일까요?
