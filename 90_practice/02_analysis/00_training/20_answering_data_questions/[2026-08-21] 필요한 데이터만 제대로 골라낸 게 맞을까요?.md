# 데이터 필터링

분석에서는 전체 데이터를 그대로 사용하기보다,  
분석 목적에 맞는 데이터만 골라서 사용하는 것이 일반적이다.

이때 중요한 것은 단순히 필터링을 할 수 있는지가 아니라,  
**내가 의도한 데이터만 정확하게 골라냈는지 확인하는 것**이다.

- 원하는 조건은 무엇인가?
- 여러 조건을 적용하려면?
- 어떤 값을 포함할 것인가?
- 제외할 값은 무엇인가?
- 필터링 결과가 예상과 맞는가?

### 데이터셋

간단한 주문 데이터셋을 사용한다.

| order_id | customer_id | product | amount |
|---|---|---|---:|
| 1 | 101 | A | 10000 |
| 2 | 102 | B | 15000 |
| 3 | 101 | A | 12000 |
| 4 | 103 | C | 8000 |
| 5 | 102 | B | 20000 |

---

## 1. 원하는 조건은 무엇인가?

<details>
<summary>⋯</summary>

`amount`가 10000 이상인 주문만 확인해보자.

### SQL

```sql
SELECT *
FROM orders
WHERE amount >= 10000;
```

> 결과:
>
> | order_id | customer_id | product | amount |
> |---:|---:|---|---:|
> | 1 | 101 | A | 10000 |
> | 2 | 102 | B | 15000 |
> | 3 | 101 | A | 12000 |
> | 5 | 102 | B | 20000 |

### pandas

```python
df[df["amount"] >= 10000]
```

</details>

---

## 2. 여러 조건을 적용하려면?

<details>
<summary>⋯</summary>

`product`가 A이면서 `amount`가 10000 이상인 주문을 찾아보자.

### SQL

```sql
SELECT *
FROM orders
WHERE product = 'A'
  AND amount >= 10000;
```

> 결과:
>
> | order_id | customer_id | product | amount |
> |---:|---:|---|---:|
> | 1 | 101 | A | 10000 |
> | 3 | 101 | A | 12000 |

### pandas

```python
df[
    (df["product"] == "A") &
    (df["amount"] >= 10000)
]
```

pandas에서는 여러 조건을 사용할 때 각 조건을 괄호로 묶어 연산의 우선순위를 명시해야 한다.  
특히 AND와 OR을 함께 사용할 때 괄호를 생략하면 의도와 다른 결과가 나올 수 있다.

</details>

---

## 3. 어떤 값을 포함할 것인가?

<details>
<summary>⋯</summary>

상품 A 또는 B에 해당하는 주문만 골라보자.

### SQL

```sql
SELECT *
FROM orders
WHERE product IN ('A', 'B');
```

### pandas

```python
df[df["product"].isin(["A", "B"])]
```

</details>

---

## 4. 제외할 값은 무엇인가?

<details>
<summary>⋯</summary>

상품 A를 제외한 주문만 골라보자.

### SQL

```sql
SELECT *
FROM orders
WHERE product != 'A';
```

> 결과: 4

### pandas

```python
df[df["product"] != "A"]
```

> 결과: 4

조건을 반대로 적용하는 경우에도 중요한 것은 무엇을 제외하는지 **명확하게 정의하는 것**이다.

</details>

---

## 5. 필터링 결과가 예상과 맞는가?

<details>
<summary>⋯</summary>

필터링은 조건을 작성하는 것으로 끝나지 않는다.

`amount >= 10000`을 적용했을 때 4개의 주문이 남는게 맞는지 확인해보자.

### SQL

```sql
SELECT COUNT(*) AS row_count
FROM orders
WHERE amount >= 10000;
```

> 결과: 4

### pandas

```python
df[df["amount"] >= 10000].shape[0]
```

> 결과: 4

결과 건수뿐만 아니라 조건의 경계값과 실제 데이터를 함께 확인하면, 필터링 조건이 의도대로 적용되었는지 검증할 수 있다.

</details>

---

## 정리

<details open>
<summary>⋯</summary>
  
필요한 데이터만 골라내는  것은 단순한 조회 작업처럼 보이지만,  
잘못된 조건으로 데이터를 필터링하면 이후의 모든 분석 결과가 달라질 수 있다.

특히 다음을 확인해야 한다.

> **조건 → 경계값 → 포함·제외 대상 → 결과 건수**

### 비교

| 질문 | SQL | pandas |
|---|---|---|
| 조건 필터링 | `WHERE` | Boolean indexing |
| AND 조건 | `AND` | `&` |
| OR 조건 | `OR` | `\|` |
| 여러 값 중 선택 | `IN` | `isin()` |
| 제외 조건 | `!=` | `!=` |
| 결과 건수 | `COUNT(*)` | `.shape[0]` |

</details>
