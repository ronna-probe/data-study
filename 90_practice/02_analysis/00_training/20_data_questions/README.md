# 데이터 조작

데이터 질문을 해결하며, 데이터를 조회·변환·집계하는 기술을 훈련한다.

---

## 질문

> 이런 질문을 받는다면 어떻게 답할까?  
> 내가 미처 생각하지 못했던 부분은 무엇일까?

- 분석하기 전에, 이 데이터를 얼마나 이해하고 있어야 할까요?
- 원하는 답을 얻으려면, 데이터를 어떻게 만들어야 할까요?
- 복잡한 질문을 데이터로 어떻게 풀어낼까요?
- 이 결과가 보여주지 않는 것은 무엇일까요?

---

## 학습 방법

각 질문을 SQL과 pandas로 각각 해결한다.
