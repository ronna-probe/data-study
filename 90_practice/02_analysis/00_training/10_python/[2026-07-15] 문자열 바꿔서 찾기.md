## 문제

문자 "A"와 "B"로 이루어진 문자열 `my_string`과 `pat`이 주어진다.

`my_string`의 모든 문자를 다음과 같이 변경한다.

- "A" → "B"
- "B" → "A"

변경된 문자열 안에 `pat`이 연속하는 부분 문자열로 존재하면 1,  
존재하지 않으면 0을 반환한다.

---

## 예시

```python
my_string = "ABAA"
pat = "BAB"
```

`my_string`의 문자를 변경하면

```text
ABAA
 ↓
BABB
```

가 된다.

변경된 문자열 "**BAB**B" 안에 "BAB"가 존재하므로 결과는 1이다.

---

## 접근

이 문제는 크게 두 단계로 나눌 수 있다.

- 문자열의 A와 B를 서로 교환한다.
- 변환된 문자열에 pat이 포함되는지 확인한다.

---

## 코드

```python
def included_in_swapped_string(my_string, pat):
    swapped = ''.join(
        'B' if ch == 'A' else 'A'
        for ch in my_string
    )

    return int(pat in swapped)
```

---

## 정리

- 데이터를 원하는 형태로 먼저 변환하면 이후의 처리를 단순하게 만들 수 있다.

---

## 참고

### 1. 문자열 메서드 활용

lower()와 replace()를 조합해 문자 교환을 구현할 수 있다.

```python
swapped = my_string.lower().replace("a", "B").replace("b", "A")
```

### 2. 불리언 인덱싱

True는 1, False는 0으로 취급되는 점을 이용한 방법이다.

```python
swapped = ''.join('AB'[ch == 'A'] for ch in my_string)
```
