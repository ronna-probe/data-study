## 문제

자연수 `l`과 `r`이 주어졌을 때, `l` 이상 `r` 이하의 자연수 중에서  
숫자 `0`과 `5`로만 이루어진 모든 자연수를 오름차순으로 저장한 배열을 반환한다.

조건을 만족하는 자연수가 없다면 `[-1]`을 반환한다.

---

## 예시

```text
l = 21
r = 543

[50, 55, 500, 505]
```

---

## 접근

`l`부터 `r`까지 모든 정수를 확인하면서 각 숫자가 `0`과 `5`로만 이루어져 있는지 검사한다.

---

## 코드

```python
def is_valid(n):
    while n > 0:
        digit = n % 10

        if digit != 0 and digit != 5:
            return False

        n //= 10

    return True


def find_valid_numbers(l, r):
    valid_numbers = []

    for n in range(l, r + 1):
        if is_valid(n):
            valid_numbers.append(n)

    return valid_numbers if valid_numbers else [-1]
```

---

## 정리

숫자의 각 자릿수는 다음과 같이 확인할 수 있다.

- `% 10`으로 마지막 자릿수를 확인
- `// 10`으로 마지막 자릿수를 제거
- 모든 자릿수가 `0` 또는 `5`인지 검사

`range(l, r + 1)`이 작은 수부터 순서대로 순회하기 때문에 결과를 별도로 정렬할 필요는 없다.

---

## 참고

### 패턴

> 5, 50, 55, 500, 505, 550, 555

처음에는 숫자의 증가 구조가 이진수와 유사하다는 점에 착안하여 풀이를 시도하였다.

> 1, 10, 11, 100, 101, 110, 111

각 자릿수가 `0` 또는 `5` 밖에 없다는 점에서  
이진수의 `0`과 `1`에 대응시킬 수 있다.

이 규칙을 활용한 구현을 시도했으나 코드로 옮기는 과정에서 막혀,  
각 숫자의 자릿수를 직접 검사하는 방법으로 해결했다.

### bin()

Python에 `bin()` 이라는 이진수 변환 함수가 있다는 것을 알게 되었다.

```python
bin(5)  # '0b101'
```

GPT에게 물어본 결과, 아래와 같은 풀이를 확인할 수 있었다.

```python
def find_valid_numbers(l, r):
    valid_numbers = []

    for i in range(1, 2**10):
        binary = bin(i)[2:]
        number = int(binary.replace('1', '5'))

        if l <= number <= r:
            valid_numbers.append(number)

    return valid_numbers if valid_numbers else [-1]
```
