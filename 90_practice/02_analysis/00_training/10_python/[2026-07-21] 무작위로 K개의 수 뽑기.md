## 문제

정수 배열 `arr`, 자연수 `k`가 주어진다.

`arr`의 원소를 앞에서부터 확인하면서 처음 등장한 수만 결과 배열에 추가한다.

앞에서부터 `k`개의 서로 다른 수를 선택한 결과를 반환한다.  
만약 서로 다른 수의 개수가 `k`보다 적다면 부족한 자리를 -1로 채운다.

---

## 예시

```python
arr = [6, 7, 7, 8, 9]
k = 3
```

앞에서부터 확인하면

```text
6 → 추가
7 → 추가
7 → 중복이므로 건너뜀
8 → 추가
```

이미 `k`개의 서로 다른 수를 선택했으므로 이후는 고려하지 않는다.

결과는

```python
[6, 7, 8]
```

이다.

---

## 접근

중복 여부를 상태로 관리하면 한 번의 순회로 구현할 수 있다.  

---

## 코드

```python
def select_unique_numbers(arr, k):
    selected_numbers = []
    seen = set()

    for number in arr:
        if len(selected_numbers) == k:
            break

        if number not in seen:
            selected_numbers.append(number)
            seen.add(number)

    return selected_numbers + [-1] * (k - len(selected_numbers))
```

---

## 정리

이 문제의 핵심은

- 중복 제거
- 순서 유지
- 필요한 요소만 선택

즉, 어떤 값을 선택할지보다 **언제 선택하지 않을지**를 결정하는 것이다.

결과는 입력 배열의 부분 수열(Subsequence)이 된다.  
따라서 결과 배열은 원본 배열에서 일부 값을 건너뛴 형태와 같다.

---

## 참고

Python 3.7부터는 dict가 입력 순서를 보장하므로,  
dict.fromkeys()를 활용해 순서를 유지한 중복 제거가 가능하다.
 
```python
def select_unique_numbers(arr, k):
    unique_numbers = list(dict.fromkeys(arr))

    return unique_numbers[:k] + [-1] * (k - len(unique_numbers[:k]))
```

다만 결과가 확정되는 시점이 발생할 수 있으므로,  
모든 원소를 확인하는 방식보다 적은 탐색으로도 해결할 수 있다.
