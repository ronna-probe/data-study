# 실습

데이터를 기반으로 문제를 탐색하고 분석하며,  
결과를 해석하는 과정을 수행하는 공간이다.  

사고 구조를 형성하기 위해 작은 단위의 분석을 지속적으로 쌓아간다.

---

## 구성

실습 과정은 다음의 순환 구조로 이루어진다:

> exploration → analysis → insights

각 단계는 독립적이면서도 서로 연결된 분석 사이클이다.

- exploration: 문제 탐색
- analysis: 데이터 분석
- insights: 의미 도출
