# 상태 정리

이 폴더는 프로젝트의 주요 해석과 버전별 상태를 정리한다.

---

## Rule

- 개별 변화 과정은 `../state_records`에 기록한다.
- State Snapshot은 여러 State Record를 종합하여 특정 시점의 프로젝트 상태를 정리한다.

---

## Future Versions

v1은 포트폴리오를 이해하기 위한 단계였다.  
v2는 포트폴리오라는 개념이 어떻게 변화하는지를 관찰하기 위한 단계이다.

그 이후에도 질문은 끝나지 않을 것이다.

정의는 언제든 바뀔 수 있고,  
새로운 관점은 무한히 등장할 수 있다.

그러나 더 이상 흔들리지는 않을 것이다.

이후의 모든 질문은,

새로운 전환점이 아니라  
미래의 역사일 뿐이므로.
