# META PORTFOLIO 🧠
### PORTFOLIO for portfolio

```text
나의 말:

나는 portfolio를 잘 모른다. 그럼 어떻게 만들어가야 하지?
portfolio를 만들어 가는 과정 자체를 `PORTFOLIO`로 만들어볼 수 있을까.
```

---

## 1. 문제 정의

데이터 분석 포트폴리오가 무엇인지 명확히 이해하지 못한 상태에서 시작하였다.

대부분의 정보는 포트폴리오의 결과물을 중심으로 설명되어 있었고,  
본 프로젝트는 결과가 아닌 형성 과정에 주목하기로 하였다.

일반적인 포트폴리오가 정의된 문제를 해결하는 것에 초점을 둔다면,  
본 프로젝트는 포트폴리오라는 개념을 정의하는 과정을 다룬다.

이러한 의미에서 본 프로젝트는 **포트폴리오에 대한 포트폴리오**,  
즉 하나의 메타 포트폴리오라고 할 수 있다.

따라서 프로젝트명은 `00_META_PORTFOLIO`로 정의하였다.

---

## 2. 모델 정의

본 프로젝트는 GPT와의 대화 과정에서 발생하는 사고의 변화를  
질문 로그를 기반으로 한 **상태 전이 구조**로 모델링한다.

모델은 다음 3가지 요소로 구성된다:

- Event: 질문 등 상태 변화를 유발하는 입력
- State: 특정 시점에서의 이해 구조
- Transition: Event에 의해 State가 재구성되는 과정

---

## 3. 프로젝트 구조

- docs: 분석 기준
- state_records: 변화 기록
- state_snapshots: 상태 정리
