# 변화 기록

프로젝트 진행 과정에서 발생한 상태 변화와 그 영향을 기록한다.

---

## Types

- exp (Experiment) : 지표 및 모델 실험
- rfl (Reflection) : 프로젝트 내부 객체에 대한 해석 변화
- def (Definition) : 핵심 개념의 정의 변화
- evo (Evolution) : exp/rfl/def를 포함한 시스템 구조의 시간적 변화 및 전이

> exp → rfl → def → evo

---

## Recording Structure

프로젝트 진행 과정에서 기록 방식 또한 설계의 대상이 되었다.  
모든 기록은 다음 구조를 기본 형식으로 사용한다.

- Context: 이전 상태
- Shift: 발생한 변화
- Implication: 변화의 영향

필요한 경우 Notes를 추가하여  
예시, 후속 질문, 메타 메모를 기록할 수 있다.

### Format Transition

2026-06-18 이전 기록은 현재 형식이 정립되기 전 작성된 문서로,  
당시의 사고 구조와 기록 방식을 그대로 보존한다.

문서 형식의 차이 또한 프로젝트 진화 과정의 일부로 간주한다.
