# User Behavior Analysis

---

## 1. 프로젝트 목적

GA4 공개 전자상거래 이벤트 데이터를 활용하여 사용자별 행동 데이터를 집계하고, 기초적인 통계 분석과 대시보드 시각화를 수행한다.

BigQuery에서 사용자별 데이터를 가공하고, Python을 활용해 데이터의 기본적인 통계적 특성과 구매 여부에 따른 행동 차이를 탐색한다.

또한 Google Sheets와 Apps Script를 연동하여 선택한 기간에 따른 주요 지표를 확인할 수 있는 대시보드를 구현한다.

---

## 2. 주요 분석 내용

- 사용자별 전체 이벤트 발생 횟수의 기본적인 통계적 특성은 어떠한가?
- 상품 조회, 장바구니 추가, 구매 이벤트는 사용자별로 어느 정도 발생하는가?
- 구매 경험이 있는 사용자와 없는 사용자의 이벤트 발생 수준에는 어떤 차이가 있는가?
- 최초 이벤트 발생일을 기준으로 기간을 선택했을 때 주요 지표는 어떻게 달라지는가?

---

## 3. 분석 데이터

- **원천 데이터:** `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`
- **데이터 유형:** GA4 웹 이벤트 로그
- **분석 단위:** 사용자 1명당 1행
- **사용자 식별자:** `user_pseudo_id`
- **관측 기간:** 2020-11-01 ~ 2021-01-31

---

## 4. 데이터 마트 설계

사용자별 행동 정보를 집계한 User DM을 생성한다.

| 컬럼명 | 설명 |
|---|---|
| user_pseudo_id | 사용자 식별자 |
| total_events | 총 이벤트 발생 횟수 |
| view_item_count | 상품 조회 횟수 |
| add_to_cart_count | 장바구니 추가 횟수 |
| purchase_count | 구매 이벤트 발생 횟수 |
| purchase_flag | 구매 이벤트 발생 여부 |
| first_event_date | 최초 관측일 |

## 5. 분석 및 구현 방법

### SQL / BigQuery
- GA4 원천 데이터 조회
- 사용자별 이벤트 집계
- User DM 생성
- 데이터 품질 검증

### Python / Google Colab
- BigQuery에서 생성한 User DM 데이터 활용
- Pandas를 활용한 데이터 처리
- 주요 변수의 기술통계 분석
  - 평균, 중앙값, 표준편차, 최솟값, 최댓값
- 구매자와 비구매자 간 그룹별 기초 통계 비교
- Matplotlib을 활용한 기초 데이터 시각화

### Google Sheets
- BigQuery에서 추출한 사용자별 집계 데이터 관리
- 날짜별 요약 데이터 구성
- 이벤트 발생량 및 구매 여부별 사용자 수 시각화
- 대시보드 구성

### Google Apps Script
- 대시보드의 시작일 및 종료일 입력값 처리
- 선택한 기간에 따른 데이터 갱신 자동화
- 분석 결과를 Google Sheets 대시보드에 반영
- 입력값 검증 및 예외 처리

## 7. 분석 시 참고사항

- `user_pseudo_id`는 익명 사용자 식별자로 실제 개인이나 로그인 계정을 의미하지 않을 수 있다.
- `purchase_count`는 구매 이벤트 발생 횟수이며 실제 주문 건수와 다를 수 있다.
- `purchase_flag`는 전체 관측 기간 내 구매 이벤트 발생 여부를 의미한다.
- `first_event_date`는 관측 기간 내 최초 이벤트 발생일이며 실제 가입일을 의미하지 않는다.
- 날짜 필터는 선택 기간에 최초 이벤트가 발생한 사용자 그룹을 대상으로 한다.
- 이벤트 횟수와 구매 여부는 전체 관측 기간의 집계값을 사용한다.
- 구매자와 비구매자 간 행동 차이는 기술통계적 비교이며 인과관계를 의미하지 않는다.

- `Google Apps Script`: 데이터 분석 및 대시보드 갱신 로직
- `Google Sheets`: 원본 데이터, 요약 데이터 및 대시보드
