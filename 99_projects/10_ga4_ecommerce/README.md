# GA4 E-Commerce Analysis

---

## 1. 프로젝트 소개

성장형 데이터 분석 프로젝트이다.  
하나의 데이터셋을 기반으로 다양한 분석 과제를 수행한다.  

---

## 2. 분석 과제

| 순서 | 분석 과제 | 분석 주제 |
|---|---|---|
| 01 | User Behavior | 사용자 행동 분석 |
| 02 | Session Behavior | 세션 행동 분석 |
| 03 | Purchase Funnel | 구매 퍼널 분석 |
| 04 | User Retention | 사용자 리텐션 분석 |

각 과제는 독립적으로 진행하며, 완료한 분석을 바탕으로 다음 분석 과제에 도전한다.
