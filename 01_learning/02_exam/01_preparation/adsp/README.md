# ADsP (데이터분석 준전문가)

## 초기 수준
AICE Basic 학습을 통해 기본적인 데이터 분석 개념 및 분석 흐름을 접해본 수준으로,  
통계적 해석 및 분석 설계 부분은 부족한 상태였다.

## 목적
데이터 분석 체계 및 통계적 사고를 학습하고, ADsP 자격 취득을 목표로 한다.  
목표는 단순히 자격증 취득이 아니라, 데이터 분석 흐름(이해 → 기획 → 분석)을 체계적으로 이해하는 것을 목표로 한다.

## 시험 계획
- 시험 목표: ADsP
- 학습 기간: 2026년 3월 ~ 5월 (약 2개월)
- 응시 예정: 49회, 2026년 5월 17일 시험

## 학습 방식
- 주 교재: 2026 ADsP 준전문가(미어캣)
- GPT, 검색, 유튜브 강의 참고
