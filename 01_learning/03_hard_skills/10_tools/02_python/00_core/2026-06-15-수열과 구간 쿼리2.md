# [수열과 구간 쿼리 2](https://school.programmers.co.kr/learn/courses/30/lessons/181923)

## 문제

정수 배열 `arr`와 2차원 정수 배열 `queries`가 주어진다.

각 query는 `[s, e, k]` 형태이며 다음을 수행한다:

- 구간 `s ≤ i ≤ e`에서
- `arr[i] > k`인 값 중 가장 작은 값을 찾는다.

조건을 만족하는 값이 없다면 `-1`을 반환한다.

### 예시

| arr           | queries                      | result        |
|---------------|------------------------------|---------------|
| [0, 1, 2, 4, 3] | [[0, 4, 2], [0, 3, 2], [0, 2, 2]] | [3, 4, -1] |

---

## 접근

각 query는 독립적인 구간 탐색 문제이다.

해야 하는 작업은 항상 동일하다:

- 특정 구간을 순회한다
- 조건 (`arr[i] > k`)을 만족하는 값만 고려한다
- 그 중 최솟값을 선택한다

즉, “구간 필터링 + 최소값 선택” 문제이다.

---

## 코드

```python
def query_min_above_threshold(arr, queries):
    query_results = []

    for start, end, threshold in queries:
        min_valid_value = float('inf')  # sentinel value

        for i in range(start, end + 1):
            if arr[i] > threshold:
                min_valid_value = min(min_valid_value, arr[i])

        query_results.append(min_valid_value if min_valid_value != float('inf') else -1)

    return query_results
```

---

## 정리

- “필터링 후 최소값을 찾는 것”이 아니라,
- 구간을 순회하면서 조건을 만족하는 최솟값을 즉시 갱신하는 구조로 전환
