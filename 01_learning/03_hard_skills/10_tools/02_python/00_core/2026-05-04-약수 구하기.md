# [약수 구하기](https://school.programmers.co.kr/learn/courses/30/lessons/120897)

## 문제
자연수 n을 인자로 받아, n의 모든 약수를 오름차순으로 담은 리스트를 반환하는 함수를 작성한다.

### 예시
| n  | result                  |
|----|-------------------------|
| 12 | [1, 2, 3, 4, 6, 12]     |
| 17 | [1, 17]                  |

---

## 접근
- 1부터 n까지 탐색하면 문제를 해결할 수 있으며, O(n)이 걸린다. 탐색 범위를 줄일 수 있는지 살펴보자.
- 약수는 쌍으로 존재하므로, 이 성질을 활용하면 √n까지만 확인해도 모든 약수를 구할 수 있다.

---

## 코드
```python
def get_divisors(n):
    small = []
    large = []
  
    for x in range(1, int(n**0.5) + 1):
        if n % x == 0:
            small.append(x)
            if x != n // x:
                large.append(n // x)
                
    return small + large[::-1]
```

---

## 정리
- 탐색 범위를 줄여 O(n)에서 O(√n)으로 개선할 수 있다.
- 두 개의 버퍼를 조합하여, 별도의 정렬 없이도 오름차순 결과를 얻을 수 있다.
