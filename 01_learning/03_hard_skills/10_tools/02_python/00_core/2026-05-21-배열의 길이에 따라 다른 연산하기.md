# [배열의 길이에 따라 다른 연산하기](https://school.programmers.co.kr/learn/courses/30/lessons/181854)

## 문제
정수 배열 arr과 정수 n이 매개변수로 주어진다.  
조건에 따라 특정 인덱스에 n을 더한 배열을 반환하는 함수를 작성한다.

- arr 길이가 홀수이면 짝수 인덱스에 n을 더한다.
- arr 길이가 짝수이면 홀수 인덱스에 n을 더한다.

### 예시

| arr         | n | result        |
|-------------|---|--------------|
| [5, 6, 7, 8, 9] | -4 | [5, 2, 7, 4, 9]  |
| [1, 2, 3, 4]   | 10 | [1, 12, 3, 14]  |

---

## 접근
- 배열 길이의 홀짝 여부에 따라 값을 더할 인덱스 parity가 달라진다.
- 조건에 맞는 parity 값을 기준값으로 사용한다.
  
```python
index_parity = 1 if len(arr) % 2 == 0 else 0
```

---

## 코드

```python
def add_by_index_parity(arr, n):
    is_even_length = len(arr) % 2 == 0
    index_parity = 1 if is_even_length else 0
    
    added_arr = [
        value + n if index % 2 == index_parity else value
        for index, value in enumerate(arr)
    ]
    
    return added_arr
```

---

## 정리
- 삼항 연산자를 사용해 선택할 인덱스 parity를 간결하게 결정할 수 있다.
- 리스트 컴프리헨션으로 조건에 맞는 결과 배열을 한 번에 생성할 수 있다.
