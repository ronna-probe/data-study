# [문자열 섞기](https://school.programmers.co.kr/learn/courses/30/lessons/181942)

## 문제

길이가 같은 두 문자열 `str1`, `str2`가 주어진다.  
두 문자열의 각 문자를 앞에서부터 번갈아가며 한 번씩 등장하는 문자열을 만들어 반환하는 문제이다.

예시

| str1   | str2   | result   |
|--------|--------|----------|
| aaa    | bbb    | ababab   |

---

## 접근

```python
str1 = "aaa"
str2 = "bbb"
```

이 문제는 **인덱스 단위**로 보면 구조가 단순하다.

해야 하는 작업은 항상 동일하다:

- 같은 위치의 문자끼리 묶는다
- 순서를 유지하면서 번갈아 배치한다
- 결과 문자열을 누적한다

이 구조는 사실 2개의 문자열을 “열(column)”로 보는 2차원 구조로 해석할 수 있다.

- 같은 인덱스의 문자들을 하나의 쌍(row)으로 묶는다
- 순서를 유지하며 row 단위로 순회한다
- 이를 1차원 문자열로 펼친다(flatten)

---

## 코드

### stateful

중간에 list buffer를 사용해 row 단위 결과를 누적한다.

```python
def interleave_strings(str1, str2):
    merged_chars = []

    for ch1, ch2 in zip(str1, str2):
        merged_chars.append(ch1)
        merged_chars.append(ch2)

    return ''.join(merged_chars)
```

### stateless

중간 상태 없이 generator로 바로 row를 변환한다.

```python
def interleave_strings(str1, str2):

    return ''.join(f"{ch1}{ch2}" for ch1, ch2 in zip(str1, str2))
```

---

## 정리

- 핵심은 “두 문자열을 같은 인덱스로 묶어 순서대로 풀어내는 것”
- 구조적으로는 2차원 데이터를 row-wise로 flatten 하는 문제이다
- zip을 쓰면 column을 기준으로 묶어 병렬 순회 구조로 자연스럽게 해결된다
