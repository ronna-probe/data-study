# [문자열 섞기](https://school.programmers.co.kr/learn/courses/30/lessons/181942)

## 문제

길이가 같은 두 문자열 `str1`, `str2`가 주어진다.  
두 문자열의 각 문자를 앞에서부터 번갈아가며 한 번씩 등장하는 문자열을 만들어 반환하는 문제이다.

예시

| str1   | str2   | result   |
|--------|--------|----------|
| aaa    | bbb    | ababab   |

---

## 접근

```python
str1 = "aaa"
str2 = "bbb"
```

이 문제는 **인덱스 단위**로 보면 구조가 단순하다.

해야 하는 작업은 항상 동일하다:

- 같은 위치의 문자끼리 묶는다
- 순서를 유지하면서 번갈아 배치한다
- 결과 문자열을 누적한다

즉, 같은 인덱스끼리 값을 대응시키는 문제이다.

- zip은 두 문자열에서 같은 위치의 문자들을 (ch1, ch2) 형태의 쌍으로 만든다
- 각 쌍은 서로 대응되는 문자 2개로 구성된다
- 이 쌍들을 순차적으로 이어붙여 하나의 문자열로 만든다

즉, 두 문자열을 나란히 놓고 같은 인덱스끼리 대응시키는 table 관점으로 이해할 수 있다.

---

## 코드

### stateful

리스트에 누적하며 상태를 유지한다.

```python
def interleave_strings(str1, str2):
    merged_chars = []

    for ch1, ch2 in zip(str1, str2):
        merged_chars.append(ch1)
        merged_chars.append(ch2)

    return ''.join(merged_chars)
```

### stateless

쌍을 즉시 변환해 상태 없이 처리한다.

```python
def interleave_strings(str1, str2):

    return ''.join(f"{ch1}{ch2}" for ch1, ch2 in zip(str1, str2))
```

---

## 정리

- 핵심은 “두 문자열을 같은 인덱스로 묶어 순서대로 펼치는 것”
- 구조적으로는 2차원 데이터를 flatten 하는 과정이다
