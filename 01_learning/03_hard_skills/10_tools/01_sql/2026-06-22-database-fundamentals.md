## 요약

- 데이터베이스는 데이터를 단순 저장하는 공간이 아니라 관리하는 시스템이다.
  - 트랜잭션은 데이터의 일관성과 신뢰성을 보장하기 위한 처리 단위이다.
  - 데이터베이스 운영에서는 비용, 성능, 안정성과 같은 요소가 함께 고려된다.

- SQL은 선언형 언어로, Python 등의 절차형 언어와 구분된다.
  - 사용자는 원하는 결과만 선언하고, 실행 방식은 옵티마이저가 결정한다.

---

## 서평

- 지금까지 배워온 SQL 문법이 왜 존재하는지 조금이나마 이해할 수 있었다.
- 같은 SQL이라도 데이터 상태에 따라 다른 실행 계획이 선택될 수 있다는 점이 인상적이었다.
- 데이터베이스를 단순한 저장소가 아니라 하나의 시스템으로 바라보게 만든 책이었다.

---

## 활용

- 데이터 구조와 테이블 간 관계를 이해하는 데 활용할 수 있을 것 같다.
- 쿼리 작성 시 결과뿐 아니라 실행 계획과 성능까지 고려해볼 수 있을 것 같다.
