# 기술적 역량

데이터를 추출·처리·분석하고 구현하기 위한 기술 기반 역량을 학습하는 공간이다.

## 구성

### Tools
- sql: 데이터 추출 및 가공
- python: 데이터 분석 및 자동화
- visualization: 데이터 시각화

### Engineering
- engineering_basics: 시스템 구조 기초

### Analysis
- machine_learning: 머신러닝
- mathematics: 수학 및 통계

## 목적
데이터를 실제로 다루고 분석할 수 있는 기술적 기반과 구현 역량을 기르는 것을 목표로 한다.
