# 등차수열의 특정한 항만 더하기

## 출처

---

## 문제

두 정수 `a`, `d`와 길이가 n인 boolean 배열 `included`가 주어진다.

첫째항이 a, 공차가 d인 등차수열에서 included[i]가 i+1번째 항을 의미할 때,  
1항부터 n항까지 included가 true인 항들만 더한 값을 반환하는 문제이다.

---

## 접근

- included는 선택 여부를 나타내는 마스크이다

---

## 코드

### 수열 생성 후 필터링

```
def sum_included_terms(a, d, included):
    terms = [a + i * d for i in range(len(included))]

    selected_sum = 0

    for idx, is_included in enumerate(included):
        if is_included:
            selected_sum += terms[idx]

    return selected_sum
```

---

### 직접 계산

```python
def sum_included_terms(a, d, included):
    total = 0

    for idx, is_included in enumerate(included):
        if is_included:
            total += a + idx * d

    return total
```

---

## 정리

- 수열 생성 과정 없이, 필요한 항만 계산할 수 있다
