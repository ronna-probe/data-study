# 챗GPT로 데이터 분석 가로채기 - 디지털북스

링크: https://product.kyobobook.co.kr/detail/S000214172865

---

## 초기수준
- ADsP 공부를 통해 기초적인 데이터 분석 흐름에 대해 조금은 알고 있었다.
- SQL과 Python은 아직 능숙하지 않고, 계속 학습 중인 단계이다.
- 분석 기법을 배웠다고 치더라도, '실제 데이터 분석이 어떻게 이루어지는지'는 여전히 막연했다.
- 코딩 없이도 GPT를 활용해 데이터 분석에 대한 감각을 익혀보고자 이 책을 읽게 되었다.

---

## 목차
- 데이터 분석 첫걸음
- 실전 데이터 분석: '검색광고' 활용하기
- 실전 데이터 분석: '데이터랩' 활용하기
- 데이터 분석 보고서 작성 방법

---

## 요약
- 데이터 분석의 본질은 코딩이 아니라 '분석'임을 일깨워주는 책이다.
- 특히 다음 문장이 인상 깊게 남았다.
- "우선 '캠핑장 예약'과 '캠핑장 추천' 키워드를 검색하는 사람들에 대해 상상해보자"
- 상상해본 결과, 두 그룹의 공통점 및 차이점을 발견해 볼 수 있었다.

---

## 서평
- 우선 코딩을 몰라도 분석을 시도해볼 수 있다는 아이디어를 간접적으로 체험할 수 있어 좋았다.
- 단순히 분석 과정을 나열하기보다, "왜 이렇게 분석하는가"를 함께 설명하려는 흐름이 좋았다.
- 상관계수의 최댓값과 최솟값을 기준으로 히트맵을 다시 그리는 등, 저자의 실전 노하우가 담겨있었다.

---

## 활용
- 책을 덮으면서 '분석이란 무엇인가', '좋은 질문이란 무엇인가' 등 다음 질문으로 이어지게 되었다.
- 아직 데이터 분석이 막막하게 느껴지지만, 데이터를 바탕으로 작은 분석부터 직접 시도해볼 예정이다.
