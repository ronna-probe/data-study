# 분석 기준

메타 포트폴리오를 분석하기 위한 기준과 구조를 정의한다.

```text
Overview
    ↓
Framework
    ↓
Hypothesis
    ↓
Data
    ↓
Operation
```

---

## Structure

- Project Overview: 무엇을 할 것인가
- Analysis Framework: 어떻게 볼 것인가
- Hypothesis: 무엇을 검증할 것인가
- Data Architecture: 어떻게 기록할 것인가
- Project Operation: 어떻게 활용할 것인가

---

## Note

본 프로젝트는 고정된 모델이나 지표를 전제로 하지 않는다.

프로젝트 진행 과정에서 분석 대상과 구조가 변화할 수 있으며,  
문서는 해당 시점의 정의와 설계를 기록한다.
