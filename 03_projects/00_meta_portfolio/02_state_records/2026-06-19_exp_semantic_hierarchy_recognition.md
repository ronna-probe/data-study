## Context

- 시스템 구조가 단일 테이블 기반 RDB가 아니라 계층적 의미 구조로 해석되기 시작함
- Event → Metric → State → Concept → Meta Model로 이어지는 구조적 분리가 관찰됨

---

## Shift

- 데이터 저장 구조 → 의미 생성 구조로 관점 전환
- flat schema → layered semantic structure

---

## Implication

- 데이터는 고정된 값이 아니라 해석 가능한 변환 단위로 기능함
- 계층은 저장 구조가 아니라 의미 생성 방향성을 나타냄
- 분석 대상은 데이터 자체가 아니라 데이터가 구성하는 의미 레이어임

---

## Notes

- Event Sourcing, Knowledge Graph, Temporal Semantic Model이 결합된 구조로 해석 가능
- 시스템은 정적 구조가 아니라 의미 변화 과정을 관찰하는 모델임
- 구조 설계의 핵심 문제가 데이터 저장 방식에서 의미 계층의 범위 설정 문제로 이동함
