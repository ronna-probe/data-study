# 의미 계층 구조의 발견

```text
나의 말:

생각해보니 DB가 계층적이네
```

Question IDs: [96]
Date: 2026.06.19
Type: exp

---

## Context

- 질문 로그와 상태 기록이 누적되면서 구조적 패턴이 드러나기 시작함
- 기존에는 시스템을 데이터 저장 구조로 인식하고 있었음

---

## Shift

- 데이터베이스 → 계층적 의미 구조로 인식 전환
- 개별 레코드보다 레이어 간 관계에 주목하게 됨

---

## Implication

- Event, Metric, State, Definition, Meta Model이 서로 다른 의미 층위로 해석되기 시작함
- 시스템을 단순 저장소가 아닌 의미 생성 구조로 바라보게 됨

---

## Notes

- 계층은 저장 구조가 아니라 의미 추상화 수준을 나타낼 수 있음
- 데이터보다 해석 구조가 상위에 존재할 수 있다는 가능성을 인식함
- 구조 설계의 핵심 질문이 데이터 저장 방식에서 의미 구조 설계로 이동하기 시작함
