# 변화 기록

프로젝트 진행 과정에서 발생한 주요 변화와 실험을 기록한다.
- exp (Experiment): 어떤 실험이 수행되었는가
- rfl (Reflection): 모델이 어떻게 변했는가
- def (Definition): 핵심 개념이 어떻게 재정의되었는가
- evo (Evolution): 프로젝트 관점이 어떻게 진화했는가

> exp → rfl → def → evo

결과물보다 프로젝트가 어떻게 변화했는지를 추적하기 위한 공간이다.

---

## Types

### exp
지표 및 모델 실험

- 파라미터 튜닝
- 계산식 검증

### rfl
프로젝트 내부 객체에 대한 해석 변화

- PUL 재해석
- QCI 의미 수정

### def
핵심 개념의 정의 변화

- 포트폴리오 정의 변화
- 데이터분석가 역할 재정의

### evo
프로젝트 관점 및 문제 구조의 변화

- 측정 대상 재정의
- 관측 단위 설계
- 분석 관점 변화

## Versioning

프로젝트 버전은 개별 기록에 부여되지 않는다.

버전은 특정 시점에 프로젝트의 문제 정의,
분석 대상 또는 해석 프레임이 변화했을 때
여러 state record를 종합하여 부여하는 마일스톤이다.

즉,

- state_record = 변화 이벤트
- version = 변화 이벤트들의 해석 결과

로 구분한다.

예시:

- v1 : 포트폴리오 이해도 측정 중심
- v2 : 포트폴리오 개념 재정의 과정 관찰 중심
