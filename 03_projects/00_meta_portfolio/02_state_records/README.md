# 변화 기록

프로젝트 진행 과정에서 발생한 실험, 해석 변화, 개념 재정의, 관점 전환을 기록한다.

> exp → rfl → def → evo

결과물보다 프로젝트가 어떻게 변화했는지를 추적하기 위한 공간이다.

---

## Types

- exp (Experiment) : 지표 및 모델 실험
- rfl (Reflection) : 프로젝트 내부 객체에 대한 해석 변화
- def (Definition) : 핵심 개념의 정의 변화
- evo (Evolution) : 프로젝트 관점 및 문제 구조의 변화

---

## Naming

```text
yyyy-mm-dd_<type>_<label>.md
```

---

## Record Structure

프로젝트 진행 과정에서 기록 방식 또한 설계의 대상이 되었다.  
모든 기록은 다음 구조를 기본 형식으로 사용한다.

- Context: 이전 상태
- Shift: 발생한 변화
- Implication: 변화의 영향
- Notes: 기타 메모

### Historical Records
