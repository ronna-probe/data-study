# 무엇을 원자로 선택할 것인가에 대한 기준

그런데 실제 문제는 이거야
“변화는 최소 몇 개의 객체로 설명 가능한가?”

## Context
- 2026-06-13 시점에서는 관측 단위는 “선택되는 것”이라는 수준에서 이해되고 있었다.
- 동일한 현상도 여러 방식으로 분해 가능하다는 인식이 중심이었다.
- 즉, 원자는 고정된 최소 단위가 아니라 모델링 결과로서 결정되는 것으로 받아들여지고 있었다.

---

## Shift
- “원자는 선택된다” → “원자를 어떤 기준으로 선택하는가”로 문제의 초점이 이동함
- 단순히 관측 단위를 인정하는 수준에서, 관측 단위의 선택 기준 자체를 설계 대상으로 보기 시작함
- 동일한 현상이라도 분해 방식에 따라 전혀 다른 모델 구조가 생성된다는 점이 강조됨
- 원자 선택이 데이터 구조 문제가 아니라 모델 구조를 결정하는 핵심 단계로 재인식됨

---

## Implication
- 분석의 핵심 문제가 “무엇을 측정할 것인가”에서 “어떤 기준으로 분해할 것인가”로 이동함
- 동일 데이터라도 선택된 원자 구조에 따라 완전히 다른 해석이 가능함
- 이후 모든 state_record 및 모델 설계는 관측 단위 선택의 결과로 해석될 필요가 있음
- Feature, Metric, Model 설계 이전에 “분해 기준 설계”가 선행되어야 함
- 해당 기록 또한 설명 중심 서술이 아니라 구조를 강제하는 변화 기록 방식으로 전환하였음

---

## Notes
- 원자 선택은 단순한 데이터 설계가 아니라 모델 구조 설계에 해당함
- 하나의 문제는 여러 방식의 원자화가 가능하며, 각 방식은 서로 다른 설명력을 가짐
- Shift 자체도 더 미세한 event 단위로 분해 가능할 가능성이 있음
