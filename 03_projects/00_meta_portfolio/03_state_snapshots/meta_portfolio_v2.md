# Meta Portfolio v2

Active Period: 2026-06-16 ~ Present

## Overview

v2는 학습 상태를 측정하는 단계에서,  
개념 상태의 변화를 관찰하는 단계로 전환된 버전이다.

프로젝트를 진행하면서 관심사는

> 현재 나는 얼마나 이해했는가?

에서

> 나는 무엇을 이해 대상으로 정의하고 있는가?

로 이동하였다.

질문 로그를 분석할수록  
이해도의 변화보다

분석 대상,
측정 대상,
관측 단위,
분석 프레임

자체가 반복적으로 재정의되고 있음을 발견하였다.

따라서 프로젝트는 더 이상 사용자의 학습 상태를 추정하는 것이 아니라,  
포트폴리오라는 개념이 질문과 의사결정 과정을 통해 어떻게 재정의되는지를 관찰하는 방향으로 전환되었다.

---

## Core Question

> 포트폴리오라는 개념은 질문과 의사결정 과정을 통해 어떻게 재정의되는가?

---

## Analysis Target

프로젝트의 분석 대상은

> 포트폴리오의 개념 상태 (Concept State)

이다.

개별 질문은 분석 대상이 아니라,  
개념 상태의 변화가 발생하는 이벤트로 해석된다.

프로젝트는 질문 로그를 통해

```text

개념 정의

↓

정의 수정

↓

정의 재구성

↓

새로운 개념 상태

```

의 전이 과정을 관찰한다.

---

## Main Concepts

### 1. Concept State

특정 시점에서 정의된  
포트폴리오 개념의 상태

### 2. State Transition

질문과 의사결정을 통해  
개념 상태가 변화하는 과정

### 3. State Record

개념 상태의 변화와  
그 원인이 되는 사건을 기록한 로그

### 4. Meta Portfolio

포트폴리오 결과물이 아니라,  
포트폴리오라는 개념이 형성되는 과정을 분석 대상으로 삼는 프로젝트

---

## Assumptions

v2는 다음과 같은 가설을 탐색하고자 한다.

### H1

개념 변화는 정보의 축적보다  
정의의 재구성을 통해 발생할 것이다.

### H2

중요한 상태 전이는  
단일 질문보다 연속적인 질문 묶음(question cluster)에 의해 발생할 것이다.

### H3

포트폴리오에 대한 이해는  
선형적으로 증가하는 것이 아니라,

정의를 반복적으로 수정하는 과정을 통해 진화할 것이다.

---

## Completion Criteria

프로젝트는 다음 조건을 만족할 때  
하나의 마일스톤에 도달한 것으로 간주한다.

### 1.

주요 상태 전이를 설명할 수 있다.

### 2.

각 상태 전이를 유발한 질문과 의사결정을 추적할 수 있다.

### 3.

포트폴리오라는 개념이 어떻게 변화했는지를  
하나의 일관된 서사로 설명할 수 있다.

---

## Version Transition

v1이

사용자의 학습 상태를 측정할 수 있는가?

를 다루었다면,

v2는

> 포트폴리오라는 개념은 어떻게 재정의되는가?

를 다룬다.

따라서 v2는

```text

Learning State Modeling

↓

Concept State Modeling

```

으로의 전환을 의미한다.
