# 🧠 Meta-Portfolio
### PORTFOLIO for portfolio

```text
나의 말:

나는 포트폴리오를 잘 모른다. 그럼 어떻게 만들어가야 하지?
포트폴리오를 만들어 가는 과정 자체를 데이터분석 포트폴리오로 만들어볼 수 있을까.
```

---

## 1. 문제 정의

데이터 분석 포트폴리오가 무엇인지 명확히 이해하지 못한 상태에서 시작하였다.

대부분의 정보는 결과물 중심으로 설명되어 있었고,  
본 프로젝트는 결과가 아닌 형성 과정에 주목하였다.

일반적인 포트폴리오가 문제 해결에 초점을 둔다면,  
본 프로젝트는 포트폴리오 개념이 질문과 의사결정을 통해 어떻게 재정의되는지를 분석한다.

이러한 의미에서 본 프로젝트는 '포트폴리오에 대한 포트폴리오',  
즉 하나의 메타 포트폴리오(meta-portfolio)라고 할 수 있다.

따라서 프로젝트명은 `00_meta_portfolio`로 정의하였다.

---

## 2. 모델 정의

GPT와의 대화에서 발생하는 인지 변화를 행동 데이터로 모델링한다.

---

## 3. 데이터 정의

### 3-1. 로그

본 프로젝트의 데이터는 GPT와의 상호작용 과정을 기록한 것으로  
Airtable에서 관리된다.

질문 로그는 프로젝트 진행 과정에서 지속적으로 추가되며  
현재 저장소에 데이터셋 원본은 포함하지 않는다.

### 3-2. 한계

본 데이터는 개인 의견 기반으로 주관이 포함된다.

따라서 사실 검증이 아닌,  
인식과 의사결정 변화 관찰을 위한 데이터로 해석한다.
