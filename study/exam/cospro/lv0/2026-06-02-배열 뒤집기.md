# 배열 뒤집기

## 문제
정수가 들어 있는 배열 num_list가 매개변수로 주어진다

num_list의 원소 순서를 거꾸로 뒤집은 배열을 반환하는 함수를 작성한다

---

## 접근

- 핵심은 '값'이 아니라 '인덱스'를 어떤 방향으로 읽고 재구성할 것인가에 있다
- 이 문제는 모든 원소를 한 번씩만 방문하면 해결 가능하며, 시간 복잡도는 O(n) 이다

---

## 코드

### 슬라이싱

```python
def reverse_list(num_list):
    return num_list[::-1]
```

### 리스트 컴프리헨션

```python
def reverse_list(num_list):
    reversed_list = [num_list[-i] for i in range(1, len(num_list)+1)]
    return reversed_list
```

## 정리

- 이 문제는 **데이터는 유지하고 관점을 바꾸는 문제**로 정리할 수 있다
- 관점을 바꾸는 기준은 **무엇을 하나의 단위로 보느냐**이다
  - 슬라이싱 방식이 가장 간결하며, '리스트 자체'를 하나의 단위로 보고 뒤집는 방식이다
  - 음수 인덱스 방식은 '리스트의 요소'를 단위로 보고 출발점과 도착점을 뒤집어 생각하는 방식이다

---

## 참고: 리스트 뒤집기 방법 6가지 비교

Python에서 리스트를 뒤집는 방법은 크게 3개의 계층으로 나눌 수 있다

### 1. 문법 수준

#### 슬라이싱

num_list[::-1]

- 원본 유지
- 가장 간단한 방식
- 새로운 리스트 생성(out-of-place)

#### reversed()

list(reversed(num_list))

- 원본 유지
- iterator 반환, lazy evaluation 기반
- 메모리 효율적

#### reverse()

num_list.reverse()

- 원본 변경(in-place)
- 반환값 없음
- 추가 메모리 거의 사용 안 함

### 2. 구현 수준

#### for 역순 순회

res = []
for i in range(len(num_list)-1, -1, -1):
    res.append(num_list[i])

- 원본 유지
- 인덱스를 직접 제어
- 알고리즘 원리 이해용

#### pop() 활용

res = []
while num_list:
    res.append(num_list.pop())

- 원본 파괴
- 스택 구조 활용
- 사용시 주의가 필요한 방식

### 3. 자료구조 수준

#### deque 활용

from collections import deque
d = deque(num_list)
d.reverse()
res = list(d)

- 원본 유지 (복사 후 작업)
- 자료구조 기반 reverse
- 대용량 데이터에서 효율적
