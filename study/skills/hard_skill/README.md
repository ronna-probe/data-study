# 기술적 역량

데이터를 추출·처리·분석하고 구현하기 위한 기술 역량을 학습하는 공간이다.

## 구성

### Engineering
- Engineering Basics: 웹·개발 및 엔지니어링 기초 이해

### Analysis
- Machine Learning: 머신러닝 모델 및 학습 방법 이해
- Mathematics: 수학·통계 기반 분석 이론 학습

### Tools
- Python: 데이터 분석 및 자동화를 위한 Python 활용
- SQL: 데이터 추출·가공 및 데이터베이스 질의 학습
- Visualization: 데이터 시각화 및 대시보드 표현 학습

## 목적
데이터를 실제로 다루고 분석할 수 있는 기술적 기반과 구현 역량을 기르는 것을 목표로 한다.
