# SQL

SQLD 시험 준비, 프로그래머스 SQL 문제 풀이, BigQuery 실습을 통해 SQL 문법과 데이터 조회 방법을 학습해왔다

하지만 문법은 익혀갔음에도 개별 문법이 사용되는 맥락을 이해하기 어려웠다

개별 문법을 습득하기보다 SQL을 관통하는 원리와 사고방식을 이해해보고자 한다

## 학습 계획

### 데이터베이스 첫걸음

관계형 데이터베이스의 기본 개념과 데이터가 저장·관리되는 방식을 이해한다

### SQL 레벨업

SQL을 문법이 아닌 집합과 관계의 관점에서 이해한다

### 데이터 모델링 이야기

데이터가 어떤 구조로 설계되고 관리되는지 이해한다

## 목표

SQLD 시험에 대비하는 것이 아니라, SQL 자체를 이해하는 것을 목표로 한다
