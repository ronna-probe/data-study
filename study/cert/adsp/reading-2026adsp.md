# 2026 ADsP 데이터분석 준전문가 - 위키북스

## 목차
- 1과목: 데이터 이해
- 2과목: 데이터 분석 기획
- 3과목: 데이터 분석

## 요약
1회독 때는 내용 따라가기에 급급했지만, 3회독 후에는 '결국 이런 얘기를 하고 있었구나' 라는 생각이 들었다.

- 1과목: 데이터 분석을 하고 싶다면, 분석 대상인 '데이터'가 뭔지는 알아야겠지?
- 2과목: 주먹구구식으로 분석 할 게 아니라, 설계 (혹은 지시) 할 수 있겠어?
- 3과목: 실제로 분석 결과까지 내는 흐름을 이해했어?

### 서평
- 방대하고 막연한 분야에서 전체 흐름을 잡는 데 도움이 되는 책이었다.
- 다만 설명 중 일부는 몇 번을 읽어도 이해되지 않는 부분이 있었고, 이는 검색이나 유튜브 강의를 참고하며 보완했다.
- 주성분분석, 차원 축소를 '그래프를 바라보는 관점'으로 설명하는 부분은 꽤나 인상적이었고, 이를 역으로 활용할 수도 있겠다는 생각이 들었다.
- 2과목에서 어려움을 느꼈는데, 특히 ‘분석 거버넌스 체계 수립’ 단원은 10번은 읽은 것 같다. 과락은 면할 수 있을 것 같은 자신감이 생겼다.

### 활용
- '데이터 구조 변경에 따른 사전 영향 평가' 내용을 참고해, 장기 활용을 고려하여 data-study 레포 구조를 초기 단계에서 정리해두었다.
- 이는 깃허브 구조(depth), 폴더 넘버링 및 관리 방식, pull/push 개념, .gitkeep 등 여러 개념을 요구하는 작업이었고, 이를 하나씩 이해해 나갔다.
- AICE Basic을 공부하면서 썼던 'AIDU ez'라는 프로그램으로, KDD의 분석 방법론의 각 과정을 구분하며 작업을 진행해보았다.
- 책을 읽다보니 문득 궁금해져 데이터 분석가 채용공고를 확인해보았는데, 어떤 역량을 필요로 하는지를 조금이나마 이해할 수 있었다.
