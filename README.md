# 데이터 분석 학습 기록

처음 파이썬을 접했던 순간이 어렴풋이 기억난다.  
그저 뭐든 만들어보고 싶다는 생각이었다.

이후 몇 해에 걸쳐 프로그래밍 분야를 탐색했다.  
그 과정에서 나와 맞지 않는 영역들을 하나씩 지워 나갈 수 있었다.

그러던 와중, 데이터 분석이라는 분야를 접하게 되었다.  
이는 내가 평소 흥미를 느끼던 여러 영역과 맞닿아 있었다.  
특히 "정보를 구조화하고 의미를 전달하는 과정"에서 큰 흥미를 느꼈다.

2026년 봄, 데이터 분석가로 성장하기 위한 학습의 흐름을 기록하기 시작한다.

## 관심사 & 경험

### 사고 구조화
사고를 구조화하는 방식에 관심이 있으며,  
복잡한 문제를 구조화하고 재구성하는 관점을 확장해왔다.

- 질문을 설계하여 프레임을 조정하는 방식
- 문제의 핵심을 파악하고 분해하는 방식

### 정보 전달
몇 년간 스키 강사 및 고등 수학 과외 활동을 통해,  
정보를 이해하기 쉽게 전달하는 경험을 쌓아왔다.

- 상대의 이해 수준 파악 후 맞춤형 설명
- 핵심을 중심으로 내용을 단순화하여 흐름 제시
