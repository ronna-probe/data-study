# 데이터 분석 학습 기록

2026년 봄, 파이썬을 활용한 자동화와 데이터 분석에 관심이 생겨 공부를 시작했다.
이곳에 하루하루 학습 기록을 쌓아가며 성장 흐름을 남긴다.

- data: 데이터 분석 실습
- study: 자격증 및 역량

---

## 목표

데이터와 기술을 활용하여  
복잡한 문제를 구조화하고,  
의사결정에 필요한 인사이트를 명확하게 전달하는 분석가를 지향한다.

관심 분야:
- BI Analyst
- Data Visualization
- Insight Communication

---

## 관심사

평소:
- 질문 설계
- 사고 구조화
- 정보 전달 방식
- 표현과 문장 설계
- 시각적 정보 구조화 (그래프, 차트 등)

등에 관심이 있다.

《굿 퀘스천》, 《작게 나누어 생각하기》, 《카피책》, 《넘버스 스틱》 등의 책을 흥미롭게 읽었으며,  
“어떻게 하면 더 명료하게 이해하고 전달할 수 있을까?”를 종종 고민한다.

AI 모델링 연구나 논문 중심 이론, 고급 알고리즘 최적화보다는  
실제 데이터를 기반으로 문제를 구조화하고  
의사결정에 도움이 되는 형태로 전달하는 과정에 더 관심이 있다.

---

## 강점

### 구조화 및 문제 정의 능력
복잡한 내용을 단계적으로 정리하고 핵심 문제를 명확하게 정의하는 것을 중요하게 생각한다.

### 설명 & 전달
다양한 수준의 사람들에게 내용을 이해시키는 커뮤니케이션 경험을 통해  
정보를 구조적으로 전달하는 경험을 쌓아왔다.

- 상대 이해수준 및 상대의 언어 맞춤형 설명
- 논리적인 흐름 구성
- 이해 중심 커뮤니케이션
